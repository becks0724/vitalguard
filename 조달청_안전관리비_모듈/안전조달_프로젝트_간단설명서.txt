------------------------------------------------------------
1. 왜 만드나 (문제)
------------------------------------------------------------

  - 공공공사는 산업재해가 많이 나는 영역이다.
  - 그런데 안전 관리는 대부분 "공사가 시작된 뒤"에야 들어간다.
  - 발주(입찰) 단계의 위험 신호 —
      · 안전관리비가 부족하게 잡힌 공고
      · 위험 작업이 많은 공고
      · 무리한 공사기간 / 저가 낙찰
    — 는 공고가 너무 많고 검토 인력은 적어서 사람이 일일이 못 본다.

  => 그래서 "공사 시작 전(발주 단계)"에 위험을 자동으로 골라준다.


------------------------------------------------------------
2. 무엇을 하나 (핵심 기능 3가지)
------------------------------------------------------------

  나라장터(국가 입찰 사이트)의 공사 공고를 자동으로 읽어서:

  (1) 안전관리비 예비검증
      - 법으로 정해진 요율로 "이 공사면 안전관리비 최소 얼마"를 계산.
      - 공고에 적힌 금액이 기준보다 적으면 → "과소계상 의심" 표시.
      - 예) 기준 약 3,169만원인데 공고엔 1,200만원 → 경고.
      - ※ "위반 확정"이 아니라 "의심/검토 필요"로만 표시 (과장 안 함).

  (2) 위험작업 AI 태깅
      - 공고문 글을 AI가 읽고 위험 작업을 뽑아준다.
        (예: 고소작업, 굴착, 밀폐공간, 전기, 중장비, 해체 …)
      - 반드시 "공고문 원문 문장"을 근거로 함께 보여줌
        (AI가 지어낸 게 아님을 확인 가능).

  (3) 종합 위험도 점수 (0~100)
      - 위 내용을 합쳐 점수화 → 위험한 공고를 맨 위로 정렬.
      - 점수가 어떻게 나왔는지 항목별로 분해해서 보여줌(설명 가능).
      - 안전 권고 3가지도 함께 제시.

  화면: 좌측 = 위험도 순 공고 목록 / 우측 = 선택한 공고 상세 카드.


------------------------------------------------------------
3. 공모전 조건과 어떻게 맞나
------------------------------------------------------------

  공모전 필수 조건: "조달청 공공데이터 + 타기관 데이터 + AI" 동시 활용.

  - 조달청 데이터(필수): 나라장터 입찰공고/계약/낙찰 정보 (분석의 주재료)
  - 타기관 데이터       : KOSHA 산업재해, 기상청, 고용노동부 안전관리비 요율
  - AI                  : 공고문에서 위험작업 추출 + 위험도 종합

  특히 "안전관리비"는 원래 조달청이 직접 다루는 항목이라,
  조달청 입장에서 "우리 업무에 딱 맞는 주제"가 된다.

4. 기존 프로젝트(safetymonitor)와의 관계  ★중요
------------------------------------------------------------

  - 이 아이디어는 "모듈화"(방향 A)로 만들었다.
    => 기존 safetymonitor 코드를 한 줄도 고치지 않고,
       새 파일만 추가해서 "끼웠다 뺐다" 할 수 있는 부품으로 구현.

  - 역할 분담:
      · safetymonitor = 공사 "시작된 뒤" 작업자 안전 모니터링 (기존)
      · 안전조달       = 공사 "시작 전" 발주 단계 위험 선별 (이번 추가)
    => "공사 전 → 공사 중" 으로 안전을 처음부터 끝까지 잇는 그림.

  - 키(API 인증키)가 없어도 샘플 데이터로 작동하므로,
    떼어내도 기존 프로젝트에 영향 없음.
