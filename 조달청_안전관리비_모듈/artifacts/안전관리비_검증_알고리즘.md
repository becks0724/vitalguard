# 안전관리비 검증 알고리즘 — 산식에서 뽑히는 것들

`안전관리비_요율_근거.md` 의 산식·불변량으로부터 검증 플랫폼에 적용 가능한 알고리즘을 정리한다.
현재 모듈(`safety-cost.ts`)은 **곱셈 한 번 + 대소 비교**가 전부다.
산식이 실제로 주는 것은 곱셈이 아니라 **구조적 불변량**이고, 그 불변량을 어기는 패턴이 탐지 룰이 된다.

작성일 2026-08-22. 수치 주장은 전부 계산으로 확인했고 재현 코드를 각 절에 붙였다.

## A. 데이터 없이 오늘 되는 것

### A1. 요율표 무결성 가드 ★ 먼저 넣을 것

기초액(4,325천원 등)은 장식이 아니라 **구간 경계에서 기준액이 튀지 않게 하는 장치**다.
이 성질을 테스트로 박으면 요율표를 잘못 갱신했을 때 즉시 빨간불이 뜬다.

불변량 3종.

1. **경계 연속성** — 5억·50억 경계 좌우 기준액 격차가 임계(예 3%) 이내
2. **단조증가** — 대상액이 커지면 기준액도 커진다 (구간을 넘어서도)
3. **공종 서열** — 각 구간에서 중건설 > 토목 > 건축 > 특수

실측 결과다.

| 경계 | 3권 표 28 값 | 현행 모듈 값 |
|---|---|---|
| 5억 (건축/토목/중건설/특수) | +1.1 / +1.3 / +0.1 / +0.5 % | 동일 |
| **50억** | **−16.8 / −19.1 / −21.5 / +1.3 %** | **+0.1 / +0.2 / +0.0 / +0.1 %** |

모듈 값은 8개 경계 전부 1.3% 이내. 책 값은 50억에서 3개 공종이 17~21% 급락한다.
**이 가드가 있었다면 책 표 28을 넣는 순간 빨간불이 떴다.**

가드가 실제로 작동하는지는 [[L-113]] 규율대로 **변이 1종 이상으로 죽여 봐야** 검증된 것으로 친다.
변이 후보 — 50억 이상 열을 책 값(1.97 등)으로 교체하면 연속성 검사가 fail 해야 한다.

### A2. 구간 자기정합 검사 — 캘리브레이션 불필요한 확정 검출

명시된 안전관리비로부터 대상액을 **역산**한다.

```
under5 :  A = declared / r_u
mid    :  A = (declared − base) / r_m
over50 :  A = declared / r_o
```

역산된 A가 **가정한 구간에 실제로 들어가는지** 본다. 세 구간 전부에서 자기모순이면
그 금액은 산식으로 만들어질 수 없다 → **계상 오류 확정**(의심이 아니라).

이건 추정도 가정도 없다. 산식의 정의역만 쓴다.

### A3. 1.2배 캡과 2,000만 원 하한 — 지금 없는 두 규칙

**1.2배 캡** (주2). 관급 포함 시 `min((재+직노+관급)×율, (재+직노)×율×1.2)`.
캡이 걸리는 조건은 `관급 G > 0.2 × (재+직노)` 다. 관급 비중이 대상액의 20%를 넘으면
초과분은 반영되지 않는다.

지금 모듈은 **과소만** 본다. 캡을 넣으면 **과다 방향**이 생긴다.
관급자재가 큰 공사에서 `(재+직노+관급)×율` 로 그대로 계상하면 과다계상이고,
이건 보조금 부정수급 맥락에서 과소 못지않게 중요하다.

**2,000만 원 하한**. 총공사금액(도급금액+관급자설치금액) 2,000만 원 미만은 의무 적용 대상이
아니다. 지금은 이 공고에도 기준액을 부과해 **오탐**이 난다.

## B. 공고 상세 파싱으로 되는 것

### B1. 제비율 연립 정합 검사 ★ 가장 신선한 수단

확정 요율이 여러 개라 **과결정 연립식**이 된다. 미지수는 직접노무비 `L` 하나인데
관측식은 4개다.

```
건강보험료      = L × 3.545%      → L = H / 0.03545
연금보험료      = L × 4.5%        → L = N / 0.045
퇴직공제부금비   = L × 2.3%        → L = T / 0.023
산재보험료      = (L+간접노무비) × 3.56%
노인장기요양보험료 = 건강보험료 × 12.95%   ← 정확히 성립해야 하는 항등식
```

여기서 독립 검사 3개가 나온다.

1. **3경로 산포** — `L←건강`, `L←연금`, `L←퇴직공제` 가 일치해야 한다
2. **노무비 배율** — `(산재/0.0356) / L` 이 `1 + 간접노무비율`(1.113~1.150) 안에 들어야 한다
3. **장기요양 항등식** — `장기요양 / 건강 = 0.1295` 정확히

수치 검증 결과다.

| 케이스 | 3경로 산포 | 노무비 배율 | 장기요양/건강 |
|---|---|---|---|
| 정상 | 0.00% | 1.126 ✅ | 0.1295 ✅ |
| 건강보험료 25% 축소 | **33.3%** ❌ | **1.228** ❌ | **0.1727** ❌ |
| 산재보험료 15% 축소 | 0.00% | **0.957** ❌ | 0.1295 ✅ |

조작한 항목만 잔차가 뜨고 나머지는 깨끗하다 — **어느 비목이 틀렸는지까지 지목**된다.

부수 효과가 더 크다. `L` 이 확정되면 대상액 `A = 재료비 + L` 에서 미지수가 재료비 하나로
줄어 B3의 구간이 크게 좁아진다.

### B2. 재료비 역산 하한 검사 ★ 가정 없는 "확정 과소"

`L` 을 알면 A2의 역산을 한 단계 더 밀 수 있다.

```
대상액 A = declared 로부터 역산
재료비 M = A − L
M < 0  →  물리적으로 불가능  →  과소계상 확정
```

건축 5~50억(2.28% + 4,325천원), 직접노무비 3억 원인 공사로 계산한 결과다.

| 명시 안전관리비 | 역산 대상액 | 역산 재료비 | 판정 |
|---|---|---|---|
| 28.0백만 | 1,038.4백만 | 738.4백만 | 가능 |
| 12.0백만 | 336.6백만 | 36.6백만 | 가능 |
| **6.0백만** | **73.5백만** | **−226.5백만** | **불가 → 확정 과소** |

이 판정에는 추정도 캘리브레이션도 없다. **"과장 금지" 원칙을 지키면서 단정할 수 있는
유일한 경로**다. 현재 모듈이 모든 애매한 케이스를 `검토필요` 로 강등해 실효성을 잃는 문제를
정면으로 푼다.

### B3. 구간 산술 판정 — 등급 재설계

기준액은 대상액에 대해 단조증가하므로(A1 불변량 2) 대상액 구간이 그대로 기준액 구간으로
매핑된다. 점 추정 대신 **구간**으로 판정한다.

```
대상액 구간 [A_lo, A_hi]  →  기준액 구간 [R_lo, R_hi]

declared < R_lo           → 확정 과소   (가장 관대한 가정에서도 미달)
R_lo ≤ declared < R_hi    → 과소 의심
R_hi ≤ declared ≤ R_hi×1.2 → 정상
declared > 1.2배 캡        → 과다 검토
```

`A_lo`/`A_hi` 의 출처는 3단계로 좁아진다.

1. 경성 한계 — `A ≤ 순공사원가`, `A ≥ L`(B1으로 L을 얻은 경우)
2. 문헌치 — 공종별 (재료비+직접노무비)/순공사원가 비율 범위
3. 실측 캘리브레이션 — 나라장터 낙찰 산출내역서로 공종별 A/P 분포를 추정

**공종 불확실성도 같은 구간에 흡수**한다. 분류가 애매하면 후보 공종 전체에 대해
`R_lo = min`, `R_hi = max` 를 잡는다. 지금처럼 정규식이 조용히 하나를 골라 요율을
15% 바꿔 버리는 문제가 사라진다.

> 관련 결함. 현재 `classifyConstructionType()` 은 `댐|항만|방조제` 를 중건설로 보내는데
> 표 28 「해당 시설물 예」는 이들을 **토목**으로 든다 (3.64% vs 3.15%, **15.6% 과대**).
> 예시는 정의가 아니므로 코드를 바로 고치지 않고 고시 별표1 비고로 확정할 항목이다.

## C. 개찰 데이터로 되는 것

### C1. 낙찰하한 역산 검증 ★ 착공 전 → 낙찰 후로 검증 범위 확장

A값의 정의가 그대로 불변량이 된다. **안전관리비에는 낙찰률이 곱해지지 않는다.**

```
낙찰하한금액 = (예정가격 − A) × 하한율 + A
A = 국민연금 + 건강보험 + 퇴직공제부금비 + 노인장기요양보험
    + 산업안전보건관리비 + 건설안전관리비 + 품질관리비
하한율 = 90.5% (50~100억) / 89.25% (10~50억) / 88.25% (10억 미만)
```

두 방향으로 쓴다.

- **정방향** — 제비율로 A를 계산해 하한금액을 구한다. 낙찰금액이 그보다 낮으면
  A값 산정 오류 또는 **안전관리비가 낙찰률에 함께 깎였다**는 신호다.
- **역방향** — 적격심사 공사는 낙찰가가 하한에 몰린다. 이 성질을 이용해
  `A_implied = (낙찰금액 − 하한율 × 예정가격) / (1 − 하한율)` 로 A를 역산하고,
  제비율 기반 `A_기준` 과의 괴리가 큰 공고를 선별한다.

현재 모듈은 공고만 본다. 이 검증은 **공고 시점 기준액과 낙찰 결과를 잇는 유일한 다리**다.

## D. 전수 데이터로 되는 것

### D1. 임계 직하 밀집 탐지 — 분할발주·금액축소

먼저 사실관계를 바로잡는다. **산업안전보건관리비 요율표 자체는 회피 유인이 약하다** —
A1에서 본 대로 5억·50억 경계가 연속이기 때문이다. 진짜 절벽은 다른 데 있다.

| 임계 | 넘으면 생기는 의무 | 절벽 크기 |
|---|---|---|
| **2,000만 원** | 산업안전보건관리비 계상 의무 발생 | **0 → 전액 (100%)** ★최대 |
| 1억 원 | 퇴직공제부금비 반영 | 직접노무비 × 2.3% |
| 3 / 10 / 50 / 100억 | 적격심사 하한율·배점 구간 전환 | 하한율 1~2%p |
| 50억 | 산재예방 보조금 지원 대상(소규모 현장) | 지원 여부 자체 |

탐지는 두 겹이다.

1. **밀집(bunching)** — 공고 금액 분포에서 각 임계 직하의 초과질량을 검정한다.
   정상 분포 대비 유의한 초과가 있으면 그 임계가 조작되고 있다는 뜻이다.
2. **클러스터** — 동일 발주기관 + 인접 위치 + 근접 시기 + 각 공고가 임계 바로 아래인
   공고군을 묶는다. 합산액이 임계를 넘으면 분할발주 의심.

국무조정실 발표(2026-04-29)의 **"소규모 건설현장 지원을 받기 위해 공사금액을 축소하거나
두 개의 현장으로 분할하여 산재보험에 가입신고 — 과다지원 571건"** 과 정확히 같은 패턴이다.

`검토필요` 로 떨어진다. **확정** 등급 2개가 생기는 것이 이 설계의 핵심이다.

## 표현 원칙 유지

`확정` 등급은 **산식의 정의역을 벗어난 경우에만** 쓴다 — 역산 재료비 음수, 구간 자기모순처럼
어떤 가정에서도 성립할 수 없는 것들이다. 추정·캘리브레이션이 개입한 판정은
끝까지 `의심` 이다. 기존 원칙("위반 확정이 아니라 의심 선별")을 완화하는 게 아니라,
**단정해도 되는 경우와 아닌 경우를 산식으로 가른다.**
