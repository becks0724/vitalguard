## 4. 미검증 (사용자 환경 필요)
- Next.js 라우트/컴포넌트 `tsc --noEmit` 및 `next build` — node_modules 필요(INTEGRATION §3 명령 제공).
- 실 조달청 OpenAPI 응답 매핑(엔드포인트/필드) — 키 발급 후 실응답으로 `pick()` 후보키 교정.
- 실 Claude 호출(ANTHROPIC_API_KEY) — 미설정 시 규칙 폴백으로 동작.
- 정적 검토 결과: 라우트는 기존 KOSHA 라우트와 동일 패턴(`NextResponse.json`, 상대 import), Next15 `params` await 적용, `force-dynamic` 명시 → 타입/빌드 무난 예상.

## 5. 보안 점검
- 키(`G2B_SERVICE_KEY`/`ANTHROPIC_API_KEY`)는 서버 라우트·`server-only` lib 에서만 사용, 클라 번들 유입 차단.
- 입력 검증: `id` 화이트리스트 정규식, `kind` 집합 검사, `region`/`page`/`rows` 범위 제한.
- XSS: 공고 텍스트는 React 기본 escape 렌더, `dangerouslySetInnerHTML` 미사용.
- AI 프롬프트: 공고문을 구분자(`<공고과업>`)로 감싸 지시 주입 완화.
