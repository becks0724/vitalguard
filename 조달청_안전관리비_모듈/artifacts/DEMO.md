# DEMO — 안전조달(SafeProcure) 시연 가이드

> 심사/발표 시연용. 키 없이도 전 기능이 샘플 데이터로 동작한다.

## 1. 실행 (1분)
```bash
pnpm install
pnpm --filter @safetymonitor/dashboard-web dev
```
브라우저: **http://localhost:3000/safeprocure**
- 우측 상단 배지가 `샘플 데이터`(키 없음) 또는 `G2B 실시간`(키 연결)을 표시.

## 2. 핵심 시연 흐름 (3분)
1. **목록(좌측)** — 조달 공사 공고 6건이 **사전 위험도 순**으로 정렬. 빨강(≥70)/주황(40~69)/초록(<40) 막대 + `과소계상 의심/검토 필요/정상` 배지.
2. **○○ 교육연구시설 신축 공사 클릭(위험도 91)** — 우측 카드:
   - **위험도 91/100** + 기여도 분해(위험작업/안전관리비/낙찰공기/공종재해) 막대.
   - **안전관리비 예비검증 = 과소계상 의심** — 건축공사, 기준 284,400,000원 vs 명시 120,000,000원, **산정식 그대로 표기**.
   - **위험작업 태그** — "고소작업"에 *원문 근거문장*("거푸집·동바리 설치를 위한 고소작업…") 인용 + AI/규칙 출처 배지.
   - **안전 권고 3개**.
3. **◇◇ 주상복합 신축공사 클릭** — 안전관리비 **정상**(명시 850,000,000 ≥ 기준 829,500,000) 대비 케이스로 비교.
4. **▽▽ 오피스타워 신축공사 클릭** — 대상액 미확보 → **검토 필요**(공개데이터만으로 단정 안 함 = 무결성).

## 3. 심사자가 볼 포인트 (말할 거리)
- **조달데이터가 주인공**: 나라장터 공사 공고(추정가격·공사기간·공종·수요기관)가 모든 분석의 입력.
- **조달청 업무와 직결**: 안전관리비는 조달청 '공사원가계산 제비율 적용기준'이 다루는 항목 — 발주 단계에서 점검.
- **신뢰할 수 있는 AI**: 안전관리비는 결정적 법정요율(산정식 공개), AI는 비정형 공고문→위험 피처 변환. 근거문장 원문검증으로 환각 차단.
- **과장 없음**: "위반 확정"이 아니라 "**의심 선별/예비검증**" — 데이터 부족 시 '검토 필요'로 분류.
- **타기관 데이터 결합**: KOSHA 산업재해·기상청(기존 연동) + 고용노동부 안전관리비 요율.
- **이미 동작하는 제품**: safetymonitor(웨어러블 산업안전 모니터링)에 **무수정 드롭인** — 발주(사전)→현장(실시간) 안전 루프.

## 4. 실데이터 전환(선택, 키 있으면)
- `.env.local`에 `G2B_SERVICE_KEY`(data.go.kr 15129394 활용신청) → 배지가 `G2B 실시간`으로.
- `ANTHROPIC_API_KEY` 추가 → 위험태그 출처가 `규칙`→`AI`로.
- ⚠ 실응답 필드/요율은 INTEGRATION §5로 교정.

## 5. 폴백 안전성
- 조달 API 실패/0건, LLM 실패 → 자동 샘플/규칙 폴백. **시연 중 흰 화면 없음.**
