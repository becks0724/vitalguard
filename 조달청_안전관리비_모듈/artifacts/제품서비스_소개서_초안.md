## 0. 한눈에
- **제품명**: 안전조달 (SafeProcure)
- **슬로건**: *"나라장터 조달데이터와 AI로, 착공 전에 안전관리비 과소계상 의심과 고위험 작업을 선별합니다."*
- **한 줄 정의**: 공공공사 **발주(조달) 단계**의 입찰공고·계약 데이터를 AI로 분석해, 착공 전 **현장 안전 리스크 프로파일**(안전관리비 예비검증 + 위험작업 + 위험도)을 발주기관에 제공하는 서비스.

## 1. 추진 배경 — 문제
- 공공공사는 산업재해 다발 영역이나, 위험은 대부분 **착공 후**에야 관리된다.
- 발주 단계의 위험 신호 — **안전관리비 과소계상**, 위험작업 누락, 무리한 공기·저가낙찰 — 은 공고 건수에 비해 검토 인력이 부족해 사람이 일일이 걸러내지 못한다.
- 안전관리비는 조달청 **'공사원가계산 제비율 적용기준'**이 직접 다루는 항목 → **조달 데이터로 점검 가능한 영역**임에도 자동화 도구가 없다.

## 2. 제품·서비스 상세
발주기관 담당자가 대시보드(`/safeprocure`)를 열면, 진행 중인 공사 공고가 **사전 위험도 순**으로 정렬된다. 공고를 클릭하면:
- **안전관리비 예비검증**: 공사종류·대상액·기간으로 법정 계상요율을 적용해 **기준 안전관리비**를 산정하고, 공고/계약 명시액과 비교해 `정상 / 과소계상 의심 / 검토 필요`로 분류 — **산정식과 근거를 함께 제시**.
- **위험작업 태그**: 공고 과업텍스트에서 고소작업·굴착·밀폐공간·전기·중장비·해체 등을 **원문 근거문장과 함께** 추출.
- **위험도 종합**: 위 요소 + 낙찰/공기 + 공종 재해통계를 **설명가능한 기여도로 분해**해 0~100 점수화하고 **안전 권고 3건**을 제시.

> 핵심 원칙: "위반 확정 탐지"가 아니라 **"의심 선별·예비검증"**. 공개 데이터로 단정할 수 없으면 '검토 필요'로 분류해 사람의 정밀 검토를 유도한다(무결성).

## 3. 데이터 활용 (필수 요건 충족)
| 구분 | 데이터 | 활용 |
|---|---|---|
| **조달청(필수)** | 나라장터 **입찰공고정보서비스**(data.go.kr 15129394) | 공사 추정가격·공사기간·공종(면허)·지역·수요기관 |
| **조달청(필수)** | 나라장터 **계약정보서비스**(15129427) | 계약금액·계약기간·대상액·명시 안전관리비 보강 |
| 조달청(필수) | 나라장터 **낙찰정보서비스**(15129397) | 낙찰률(저가낙찰 위험 프록시) |
| 타기관 | **KOSHA** 산업재해 통계·재해사례 | 공종별 재해 가중·근거 |
| 타기관 | **기상청(KMA)** | 착공기간 기상 리스크(확장) |
| 타기관 | **고용노동부** 산업안전보건관리비 계상기준 | 안전관리비 법정요율 |
| **AI** | LLM(Claude) 공고문 위험작업 추출 | 비정형 과업텍스트 → 안전 리스크 피처 |
| AI | 설명가능 위험도 스코어링 | 조달 피처 + 재해통계 종합 |

→ **조달청 데이터를 핵심 입력**으로, 타기관 데이터와 AI를 결합. (조달청 데이터가 '보조키'가 아닌 분석의 주인공)

## 4. 핵심 기능 3
1. **조달 공고 표준화 수집** — 나라장터 OpenAPI를 표준 스키마로 정규화(키 없으면 샘플로 무중단 데모).
2. **안전관리비 예비검증 엔진** — 법정요율 기반 **결정적 계산**(산정식 공개) → 과소계상 의심 공고 조기 선별.
3. **AI 위험작업 태깅 + 위험도 종합** — 공고문에서 위험작업을 근거문장과 함께 추출하고 설명가능 점수로 통합.

## 5. 기술 구성 · 완성도 (기술성)
- 스택: Next.js 15 / React 19 / TypeScript, pnpm 모노레포(기존 `safetymonitor` 플랫폼에 **무수정 드롭인**).
- 아키텍처: `lib`(수집·룰엔진·AI태깅·스코어) + `api/g2b/*`(서버 프록시, 키 은닉) + 대시보드 컴포넌트. **새 패키지 0개**.
- **검증 완료**: 안전관리비 룰엔진 단위테스트 9/9 통과, 목업 통합 파이프라인 5건 검증(판정 3분기·근거문장 원문검증·기여도 합=점수). *(상세: qa-report.md)*
- 신뢰성: 외부 API/LLM 실패 시 자동 폴백(샘플/규칙) — 시연·운영 무중단.

## 6. 독창성 · 차별성
- **발주 단계 안전**: 기존 안전 솔루션은 착공 후(현장 모니터링)에 집중. 본 제품은 **조달 단계에서 사고를 사전 차단**.
- **조달 텍스트 → 안전 피처 변환**: 단순 LLM 요약이 아니라 비정형 공고문을 구조화된 위험 태그로 변환.
- **신뢰할 수 있는 AI**: 안전관리비는 법정요율 결정적 계산(산정식 공개), AI는 텍스트 이해에 한정 + 근거 원문검증 → 블랙박스/환각 배제.

## 7. 기대효과 · 사회적 가치 (효과성)
- 공공 발주기관의 **안전관리비 적정 집행** 유도 → 현장 안전예산 실효성↑.
- 한정된 검토 인력을 **고위험 공고에 우선 배분** → 산업재해 예방 효율↑.
- 발주(사전) → 착공(실시간 모니터링)으로 이어지는 **공공공사 안전 데이터 루프** 구축.

## 8. 발전 가능성 · 사업화 (발전가능성)
- **발주기관 SaaS**: 공고 모니터링·알림·리포트 구독형. 나라장터 연계 확대(계약·낙찰·변경계약).
- **확장**: 전국 공고 자동 스캔, 공종별 모델 고도화, KOSHA 실시간 통계 연동, 기존 웨어러블 현장 모니터링과 결합.
- **공공성**: 조달청·발주기관 대상 B2G, 안전관리 컨설팅 연계.
