# 저장소 공개 전환 점검표

작성 2026-10-07. 저장소는 현재 **비공개**이며, 포트폴리오 열람을 위해 공개 전환 또는 열람자 초대를 할 때 이 표를 따른다.
점검은 추적 트리 2,244파일 + 이번 추가분(태블릿 기록·아티팩트 1,168파일) + 전체 커밋 히스토리에 대해 패턴 검색으로 수행했다. 패턴 검색은 "없다"를 증명하지 못하므로, 공개 직전에 **같은 명령을 다시 돌려** 확인한다.

## 1. 자격증명 — 통과 (발견 0건)

| 항목 | 결과 | 비고 |
|---|---|---|
| `.env` 류 추적 여부 | `.env.example` 2개만 추적, 실값 파일 없음 (히스토리 포함) | `.gitignore` 가 `.env`, `.env.*` 차단 |
| API 키·토큰 패턴 (AIza·AKIA·ghp_·sk-·PRIVATE KEY·JWT·Bearer) | 현재 트리 0건 · 히스토리 0건 | 히스토리의 DB URL 은 전부 `비밀번호`·`****`·`USER:PW` 자리표시자 |
| 비밀번호 대입문(한·영) | 0건 | `password_hash` 같은 컬럼명·해시 설명만 존재 |
| 키스토어·인증서·서비스계정 JSON (`.jks` `.p12` `.pem` `google-services.json`) | 0건 | 앱 서명키는 레포 밖(`Desktop/개인 정보`) |
| Wi-Fi SSID/비밀번호 | 펌웨어에 `<WIFI_SSID_n>`/`<WIFI_PW_n>` 자리표시자만 | `Final_GasPod/firmware/*.ino` |

## 3. 공개 직전 재검사 명령

```bash
# 자격증명 파일명
git ls-files | grep -i -E '(^|/)\.env($|\.)|\.jks$|\.keystore$|key\.properties$|google-services\.json$|\.p12$|\.pem$|service[-_]?account.*\.json$' | grep -v '\.env\.example$'
# 키·토큰 패턴 (현재 트리)
git grep -I -n -E 'AIza[0-9A-Za-z_-]{35}|AKIA[0-9A-Z]{16}|ghp_[A-Za-z0-9]{30,}|sk-[A-Za-z0-9]{32,}|BEGIN [A-Z ]*PRIVATE KEY|eyJ[A-Za-z0-9_-]{20,}\.eyJ|postgres(ql)?://[^ ]+:[^ @]+@' -- . ':!*.lock'
# 비밀번호 대입문
git grep -I -n -i -E '(비밀번호|password|passwd)\s*[:=：]\s*\S{4,}' -- . ':!*.lock' | grep -v -i -E 'example|hash|해시|\$\{|process\.env'
# 히스토리까지
git log --all -p -G'AIza|AKIA|ghp_|sk-[A-Za-z0-9]{32}|PRIVATE KEY|postgres(ql)?://[^ ]+:[^ @]+@' -- . ':!*.lock' | grep -E '^\+' | head
```

## 4. 공개 전환 절차

1. 위 2절 1·2·3번 결정·조치 → 3절 명령 재실행 → 0건 확인.
2. 데모 계정 비밀번호 교체, Cloud Run 환경변수 중 노출 의심 키 회전(의심 없어도 공개 시점에 한 번 회전 권장).
3. GitHub Settings → Danger Zone → Change visibility → Public. 또는 Settings → Collaborators 로 열람자만 초대.
4. 유튜브 영상을 **일부 공개(unlisted)** 로 바꾸고 README 대문 링크 갱신.
