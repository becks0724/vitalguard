# 통합가이드 — 앱 담당용 (30분 작업)

모듈 내부는 수정하지 않는다. 아래 배선만 하면 끝.

## 1. 파일 탑재
`Sources/` 6파일 + `Models/` mlmodel 3개 + `Verification/ml_selfcheck.json`을 워치 타깃에 추가.
(mlmodel은 Xcode가 자동 컴파일. Appendix는 넣지 않는다.)

## 2. 배선 — 코드 4조각

**① 캡처 로거** (충격 전2s+후10s = 12초 윈도, 게이트 1.5G):
```swift
let logger = IMUWindowLogger(preSec: 2.0, postSec: 10.0, logThresholdG: 1.5, refractorySec: 2.0)
let ml = FallMLModule()          // nil이면 모델 미탑재 — ML 기능 비활성 처리
let guard_ = CountdownGuard()    // 기본 30초·지속움직임 5초 자동취소
```

**② deviceMotion 콜백에 2줄** (기존 모션 스트림 안):
```swift
logger.ingest(ax: ax, ay: ay, az: az, gx: r.x, gy: r.y, gz: r.z, totalG: totalG, at: now)
guard_.feed(totalG: totalG, now: now)
```

**③ 윈도 판정** (충격 +10초에 자동 호출됨):
```swift
logger.onWindow = { window in
    guard let ml else { return }
    let v = ml.assess(window)                 // 판정 + 추적정보
    if v.decision == .danger {
        guard_.start()                        // 카운트다운 개시 (UI: 진동+버튼 표시)
    }
    log(v.trace)                              // ★ 추적성 — 반드시 로그/서버에 남길 것
}
```

**④ 카운트다운 결말 3종**:
```swift
guard_.onAutoCancel   = { /* 지속 움직임 → 조용히 취소 (회복) */ }
guard_.onManualCancel = { /* "낙상 아님" 버튼 → 취소 */ }
guard_.onConfirm      = { /* 무반응 → 낙상 확정: 서버 신고 + trace 동봉 */ }
// UI의 "낙상 아님" 버튼 → guard_.cancelByUser()
```

## 3. 확인 (필수)
- 디버그 화면에 `MLSelfCheck.run()` 결과 표시 → **6줄 전부 ✅** = 탑재 성공
- 시나리오: 세게 쓰러져 가만히 → 카운트다운 → 무반응 → 확정 / 쓰러졌다 걸으면 → 자동취소 / 망치질 → 무반응(기각)

## 4. 모듈 업데이트 받는 법
새 버전 태그를 pull → 폴더 교체 → 자가검증 ✅ → 배포. 통합 코드 변경 없음.
`FallMLModule.version`이 로그에 찍히므로 어떤 빌드가 어떤 모듈인지 항상 추적된다.

## 금지 사항
- `Sources/` · `Models/` 내부 수정 (요청은 ML 담당에게 — 이슈/연락)
- impact 확률로 알림을 **억제**하는 로직 추가 (fail-open 위반 — v5 사태의 원인)
- 임계값 하드코딩 복제 (임계는 모듈 안에만 존재해야 교체가 안전)
