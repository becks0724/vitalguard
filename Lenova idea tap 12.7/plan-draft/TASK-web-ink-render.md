## 1. 잉크 렌더러 — ★ 앱과 픽셀이 같아야 한다

**새 파일**: `app/components/InkOverlay.tsx`

잉크 JSON:
```json
{ "v": 1, "strokes": [ { "tool": "pen", "color": 4278190080, "width": 0.004, "points": [[x, y, pressure], ...] } ] }
```

- 좌표 `x`,`y` 는 **0~1 정규화**다. 어떤 크기로 띄워도 원본 위에 정확히 얹힌다.
- `width` 는 **원본 너비 대비 비율**이다.
- `color` 는 **ARGB 32비트 정수**다(예: `4278190080` = `0xFF000000` = 불투명 검정).
  → CSS 로 바꿀 때 **A 를 빼서 `rgba()`** 로 만들어라. `#RRGGBB` 로만 쓰면 투명도가 사라진다.

### 렌더 규칙 — `record_editor.dart:37-62` 를 그대로 옮긴다

```
공통:  선끝 둥글게(round) · 채움 없이 선만
형광펜(marker):  색의 알파를 0.35 로
사각형(rectangle):  굵기 = width * 표시너비.  첫 점과 끝 점을 두 모서리로 사각형
펜·형광펜 선:
   ★ 굵기가 점마다 다르다(필압):  width * 표시너비 * (0.45 + 0.9 * clamp(pressure, 0, 1))
   첫 점(i=0):  반지름 = 굵기/2 인 원을 채워 찍는다
   그 뒤(i>0):  이전 점 → 현재 점 으로 선분 하나. 굵기는 현재 점 기준
```

⚠ **한 획을 `polyline` 하나로 그리지 마라.** 굵기가 점마다 달라서 **선분을 하나씩** 그려야 한다.
이걸 어기면 필압이 사라져 앱과 다르게 보인다.

⚠ **지우개(`eraser`)는 오지 않는다.** 앱이 2026-09-13 부터 지우개를 "획 통째 삭제"로 바꿔서
지우개 획을 저장하지 않는다. 혹시 옛 데이터에 섞여 오면 **그냥 건너뛰어라**(그리지 마라).

### `v` 로 갈라라

지금은 `v: 1` 뿐이다. **`v` 가 1 이 아니면 그리지 말고 "이 앱 버전에서 만든 표시입니다" 같은 안내를 띄워라.**
렌더 규칙이 바뀔 때 옛 데이터를 잘못 그리는 것보다 안 그리는 게 낫다.

### 구현 수단

`<canvas>` 든 `<svg>` 든 네가 골라라. **선택 이유를 보고해라.**
원본 `<img>` 위에 **정확히 겹쳐야** 한다 — 이미지가 `object-fit: contain` 으로 letterbox 되면
잉크도 같은 사각형에 맞춰야 한다. **그 계산을 빠뜨리지 마라.** 여백만큼 잉크가 어긋난다.

## 2. 뒤집기

- 목록 매핑(`:3137`)에 **`annotationId`** 를 실어라. 타입(`:1076`)에도 추가.
- **`annotationId` 가 있을 때만** 뒤집기 버튼/힌트를 보여라. 없으면 지금과 똑같이 동작해야 한다.
- 클릭하면 **Y축 회전 애니메이션**으로 뒤집혀 잉크본이 나온다. 다시 누르면 되돌아온다.
  - 앞면 = 원본 사진 그대로
  - 뒷면 = **같은 원본 사진 + 그 위에 잉크**
  - 태곤 님 표현: *"원본 사진이 한바퀴 뒤집어지는"*
- 잉크 JSON 은 **뒤집을 때 가져와라**(미리 다 받지 마라 — 목록에 수십 장이 있다).
  한 번 받으면 캐시해서 다시 안 받게 해라.
- ⚠ **`prefers-reduced-motion` 을 존중해라.** 켜져 있으면 회전 없이 즉시 전환한다.

## 3. 하지 않는 것

- 웹에서 잉크를 **그리거나 고치는 기능** — 편집은 앱(담당관)만 한다. **보기 전용이다**
- 옛 잉크 버전 열람 — 최신만 보인다(확정 사항)
- 앱 코드 · 서버 라우트 변경
