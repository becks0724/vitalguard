// app/api/calendar/media/route.ts:67-69  (이미 동작한다)

### 재생 UI

- **글 댓글과 한 목록에 시간순으로 섞여** 보인다. 따로 모으지 마라 — 태곤 님이 "댓글 하나로"라고 정했다.
- 작성자·시각·삭제 버튼은 **글 댓글과 똑같이** 보여라. 본문 자리만 재생기로 바뀐다.
- **길이를 `0:07` 형태로** 표시해라. `audio_ms` 가 `null` 이면 길이를 빼고 그려라(`0:00` 으로 찍지 마라).
- 구현 수단(`<audio controls>` vs 직접 만든 버튼)은 네가 골라라. **고른 이유를 보고해라.**
  직접 만들면 **기존 디자인 토큰**을 써라 — 색을 새로 정하지 마라.

### ★ 동시에 하나만 재생

여러 음성 댓글이 **동시에 울리면 안 된다.** 하나를 누르면 다른 것은 멈춰라.

### ★ 만료 처리

`audio_url` 은 만료형이다. 오래 열어둔 화면에서 재생하면 **실패할 수 있다.**
실패하면 **조용히 두지 말고** "다시 불러오세요" 같은 안내를 띄워라.
⚠ 만료 시 자동 재조회를 구현할지는 네가 정하되, **한다면 무한 재시도가 되지 않게** 해라.

### 편집 — 음성은 글 수정이 없다

`:4849` 의 편집 버튼은 `body` 를 고치는 것이다. 음성 댓글은 본문이 빈 문자열이라
**편집이 의미가 없다. 버튼을 숨겨라.** 삭제는 그대로 둔다(기존 권한 규칙).
