# 작업 지시 8 — 배경을 **이미지가 아니라 코드로** 그린다

작성: Claude / 수신: 코덱스(astra) / 2026-09-12

## 결정 — 태곤 님이 **코드 방식**을 골랐다

네가 쓴 `artifacts/bg-prompt.md` 는 좋았다. **버리지 마라** — 이미지로 돌아갈 때 쓴다.
다만 그 프롬프트가 요구하는 것이 **전부 도형**이다:

> 넓고 부드러운 그라데이션 · 국소 대비 아주 낮게 · 아주 흐린 등각 격자 ·
> 부드러운 등고선 · **사진 같은 디테일 없을 것** · 구조는 가장자리에만

→ **`CustomPainter` 로 그리면 된다.** 그게 이 작업이다.

| | 이미지 파일 | **코드** |
|---|---|---|
| 앱 용량 | 500KB × 2 | **0** |
| 방향 전환 | 정사각 마스터 + 센터크롭 필요 | **매 프레임 화면 크기로 다시 그린다. 크롭 문제 자체가 없다** |
| 밝은/어두운 | 파일 교체 | **파라미터 하나** |
| 대비 조정 | 재생성 | **숫자 조정** |

⚠ **새 패키지를 쓰지 마라.** `dart:ui` 와 `package:flutter` 만으로 된다.

---

## ★★ 이 작업의 합격 기준은 "예쁨" 이 아니다 — **휘도 폭이다**

배경 위에 **반투명 카드**가 오고, 그 위에 **글자**가 온다.
카드가 반투명이면 **배경 밝기가 글자 대비에 그대로 새어든다.**

→ **배경의 휘도(relative luminance) 범위를 좁게 묶어야 대비가 보장된다.**
   예쁜 그라데이션을 만들어 놓고 어두운 구석에서 글자가 죽으면 **실패다.**

### 반드시 할 것 — 스스로 재서 숫자로 보고해라

배경을 그린 뒤 **실제 픽셀의 상대휘도 최소·최대**를 구해 보고해라.
(`Color.computeLuminance()` 를 격자 표본으로 훑으면 된다. 테스트로 만들어도 좋다.)

| 안 | 목표 휘도 범위 |
|---|---|
| **어두운 안** | **0.01 ~ 0.05** 안에 들 것 |
| **밝은 안** | **0.75 ~ 0.92** 안에 들 것 |

⚠ **이 값을 못 맞추면 맞출 때까지 조정해라.** 그리고 **실제 측정값을 보고해라.**
⚠ **추정치를 쓰지 마라.** 내가 검증한다.

### 왜 이 범위인가

우리 색 토큰은 이미 대비가 계산돼 있다(`design-constraints.md` §2):
`ink #171717` 은 흰 배경에서 **17.93:1**, 흰 글자는 `primary #0D74CE` 에서 **4.77:1**.
**카드가 반투명해지면 이 값이 흔들린다.** 배경 휘도 폭을 좁히면 흔들림이 작아진다.

## 그릴 것

`lib/ui/shell/vg_background.dart` (새 파일)

### 구성 — `bg-prompt.md` 의 구도를 그대로 따른다

1. **바탕** — 넓고 완만한 그라데이션. `LinearGradient` 또는 `RadialGradient` 를
   **아주 낮은 대비**로. 순검정·순백 금지.
2. **중앙 70% 는 조용하게** — 여기 카드가 온다. **형태를 두지 마라.**
3. **등각 격자** — 아주 흐리게, **가장자리·모서리에만.** 중앙으로 갈수록 사라지게
   (반지름 기반 알파 감쇠).
4. **등고선** — 부드러운 곡선 2~4개. 역시 **가장자리에만.**
5. ⛔ **하지 마라** — 광택·발광·비네트·그림자·네온·입자·노이즈·날카로운 초점.
   (`V-9` 장식 금지와 같다)

### 파라미터

```
enum VgBackdrop { dark, light }
```
**두 안이 같은 구도**여야 한다. **색만 바뀐다.** 기하는 공유해라.

### ★ 성능 — 매 프레임 다시 그리지 마라

등고선·격자를 프레임마다 그리면 **펜 입력이 끊긴다.** 실측으로 확인한 것이 있다 —
팜 리젝션이 사후 취소 방식이라 **프레임이 밀리면 획이 상한다.**

- `shouldRepaint` 를 **크기·모드가 바뀔 때만 true** 로.
- 가능하면 **`RepaintBoundary`** 로 격리해라.
- 그래도 무거우면 **한 번 그려 `ui.Image` 로 캐시**하고 크기 바뀔 때만 다시 만들어라.

## 어디에 붙이나

### ① 셸 배경으로

`lib/ui/shell/field_shell.dart` 의 `Scaffold` 아래 깔아라.

### ② ★ 반투명 카드 — 배경만 넣으면 확인이 안 된다

배경이 보이려면 **그 위 면이 반투명해야 한다.** 같이 해라.

- `R-02` 목록 카드 · `R-03` 메타 패널 — **반투명**으로
- 알파는 **하드코딩하지 말고 상수 하나**로 빼라(`vg_theme.dart`). 내가 조정한다

### ③ ⛔ 반투명을 **올리면 안 되는 곳** — 규칙이다

`design-constraints.md` `V-8`:

> 사진·영상·펜 캔버스 위에는 반투명을 올리지 않는다.

- **`R-04` 펜 캔버스와 그 툴바는 불투명 면 위에 둔다.** 뒤가 현장 사진이라 대비를 계산할 수 없다
- **`R-03` 의 사진 자체**도 마찬가지
- 배경이 **캔버스 뒤로 비치게 하지 마라**
