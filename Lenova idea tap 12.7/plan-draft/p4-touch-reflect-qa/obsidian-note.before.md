### ★ 설계를 지배하는 제약 3가지

1. **셀룰러 없음**(`telephony` feature 자체 부재) → **끊김이 정상 시나리오**. 오프라인은 예외가 아니라 기본 설계.
2. **나침반 없음** → 지도에 방위를 못 그린다.
3. **통화·문자 불가** → 관제웹 SOS 모달의 통화 버튼을 그대로 옮길 수 없다.

### ★ P4 실측으로 추가된 제약 3가지 (2026-09-12)

4. **`SafeArea` 는 좌우 제스처 띠를 안 막는다.** `padding.left/right` 가 **0.0** 인데
   `systemGestureInsets` 는 **29.6dp** 다. 서로 다른 인셋이라 **직접 읽어야** 한다.
5. **가로에서 키보드가 화면의 43.5% 를 먹는다.** IME 368dp 는 방향 무관 동일한데
   안전 높이만 811.8dp 로 줄어서다. **가로일수록 키보드를 더 피한다.**
6. **팜 리젝션은 "차단" 이 아니라 "사후 취소" 다.** 손바닥이 일단 `touch` 포인터로
   **들어온 뒤** `PointerCancel` 로 거둬진다. 취소되는 건 `touch` 이고 **`stylus` 는 살아남는다.**
   → ⓐ **잉크는 `stylus` 만 그린다**(`touch` 로 그리면 취소 전 몇 프레임이 손바닥 점으로 남는다)
     ⓑ **`onPointerCancel` 로 획을 되돌린다** ⓒ **동시 접촉 2를 전제**로 짠다.

> 실증 사례 — 손글씨 언어팩 다운로드 버튼을 눌렀더니 **Wi-Fi 설정으로 튕겼다.**
> "네트워크 필요 기능이 조용히 실패하면 안 된다"가 이렇게 실증됐다.

### ★ 제외 판단 기준 (새 기능을 넣을지 정할 때 먼저 던지는 두 질문)

1. **역할 불일치인가** — `site_manager` 의 업무인가, 다른 부류의 업무인가
2. **현장 비직결인가** — 현장에 서서 하는 일인가, 책상에서 하는 사무·회계인가

둘 중 하나라도 걸리면 **태블릿에 넣지 않는다.** 관제웹에서 하면 된다.

### D-2 를 A안으로 정한 이유

> 태곤 님: *"한 현장 하나에 한명의 현장 안전 담당관이 배치됨. 태블릿도 한 현장 하나당 한 태블릿."*

**"다른 기기에서 열기"가 구조적으로 발생하지 않는다** → B안(벡터 분리 저장)의 결정적 이점이 무의미.
서버에 주석 저장소를 **신설하지 않는다.**

**보완 2가지로 A안 약점을 서버 변경 없이 막는다**
- `dateKey` 를 **원본 날짜**로 지정 → 주석본이 원본과 **같은 캘린더 칸**에 놓인다
- `title` 에 **원본 식별자** → `현장 이미지 (주석) — 원본 08-28 14:38`

D안을 안 쓴 이유 — D 는 `사진 + 연결 댓글` **2건**이라 *사진만 성공하고 댓글 실패*가 가능하다.
그러면 연결이 없는데 **사용자는 연결됐다고 믿는다.** A+보완은 **전송 1건**이라 이 실패가 없다.

## 3. ★ 함정 — 다시 겪지 않으려고 적는다

### 3-1. 개발자 옵션 진입 경로가 표준과 다르다
`설정 → 태블릿 정보` 에 **빌드 번호가 없다.** **`소프트웨어 버전`을 7회 탭**해야 개발자 모드가 켜진다.

### 3-2. 레노버 OS 손글씨는 한글을 못 조합한다 (실측 기각)
`설정 → 펜 → 손글씨` 에 한국어 팩을 받아 켜고 시험한 결과:

| 쓴 글자 | 결과 | 실패 |
|---|---|---|
| 네 | `네` | 정상 |
| 이 | `ㅇ` | 중성 누락 |
| 버 | `뻐` | 자음 오인식 |
| 구 | `7ㄱㅜ` | **숫자 혼입** |
| 글 | `그리` | **종성 분리** |

전체 = **`네ㅇ뻐7ㄱㅜ그리`**. 설정 문구가 원인을 말한다 — *"**영어, 숫자 및 구두점 기호와 함께** 선택한 언어를 인식"*.
→ **요구사항 14 의 주력 수단으로 쓸 수 없다.** 대안은 ML Kit Digital Ink(한국어 `ko`·20MB·오프라인·무료)이나 **실측 전 확정 금지**.
→ 부작용: 손글씨를 켜면 **IME 가 기본 입력기로 승격**된다(Gboard 로 원복함). **앱은 IME 를 강제하지 않는다**가 규칙이 됐다.

### 3-3. peers 브로커가 메시지를 자주 삼킨다
`check_messages` 가 "No new messages" 인데 상대 화면에는 보낸 흔적이 있다.
→ **`cmux read-screen --scrollback`** 으로 직접 읽는다. 코덱스는 큐가 쌓여도 **자동 처리하지 않을 때가 있어** `cmux send` + `Enter` 로 깨워야 한다.

### 3-4. 분류기가 에이전트 기동을 막는다
`cmux new-workspace --command "codex -p astra"` 가 `[Create Unsafe Agents]` 로 차단됐다.
→ **태곤 님이 `!` 로 직접 실행**해야 한다. 우회하지 않는다.

### 3-5. LibreOffice 는 HTML→DOCX 에 필터를 명시해야 한다
```bash
soffice --headless --convert-to 'docx:MS Word 2007 XML' --infilter="HTML (StarWriter)" --outdir <dir> <file.html>
```
필터 없이 `--convert-to docx` 만 주면 `no export filter` 로 죽는다. pandoc 은 이 맥에 없다.

### 3-6. CSS `transform: scale` 은 레이아웃 공간을 안 줄인다
HTML 시안 축소에 `transform` 을 썼더니 하단이 잘렸다. **`zoom`** 으로 바꿔야 공간까지 줄어든다.

### 3-7. 웹폰트(Material Symbols)가 로드 실패하면 아이콘 이름이 글자로 노출된다
→ **인라인 SVG 스프라이트**로 바꿔 외부 의존을 없앴다. 각 아이콘에 대응하는 Flutter `Icons.*` 이름을 주석으로 남겼다.

### 3-8. ★ 합성 터치(`adb input`)로는 펜을 측정할 수 없다 — 오히려 판정을 오염시킨다

`adb shell input swipe` 는 **UP 이벤트에서 `pressure 0` 을 보낸다.** 그래서 `pressureMin 0.000`
이 기록됐고 **"진짜 필압이다 ✓" 가 잘못 켜졌다.** 그건 필압이 아니라 손가락이었다.

→ **펜 축은 `stylus`·`invertedStylus` 이벤트에서만 기록**하도록 고쳤고,
**펜 표본이 0이면 "미측정" 으로 표시**하게 했다. `–` 와 `미측정` 은 다른 말이다.

**교훈: "값이 나왔다" 와 "그 값이 재려던 것이다" 는 다르다.** 어떤 입력이 그 값을 만들었는지 본다.

### 3-9. ★ `Listener` 에는 exit 콜백이 없다 — 호버 포인터가 유령으로 남는다

`onPointerHover` 로 받은 포인터를 `_live` 맵에 넣었더니 **지울 방법이 없었다**
(`onPointerExit` 는 `MouseRegion` 쪽이고 `Listener` 에는 없다).
결과로 펜을 뗀 뒤에도 **"동시 포인터 1"** 이 유지되고 **최댓값이 2로 부풀어**
**팜 리젝션 판정이 오염됐다.**

→ 호버를 `_hoverPt` 로 **접촉과 분리**하고, 팜 리젝션은 **`PointerCancel` 횟수**로 센다.
   `PointerCancel` 이 팜 리젝션의 진짜 신호다.

**교훈: 숫자가 이상하면 기기를 의심하기 전에 내 계측 코드를 의심한다.**

### 3-10. 측정 중 OS 창이 우리 앱을 덮는다 — 앱을 재시작하면 측정값이 날아간다

펜 조작 중 `com.zui.notes` 플로팅 창이, 펜 버튼에 `com.lenovo.penservice` 메뉴가 떴다.
**우리 앱을 재시작하면 안 된다**(상태 초기화). 덮은 앱만 골라 끈다.
```
adb shell am force-stop com.zui.notes     # 우리 앱은 그대로
```
펜 메뉴는 **메뉴 바깥을 탭**하면 닫힌다(`adb shell input tap 400 150` — 헤더 영역).

## 4. 코덱스가 잡아낸 것 (검증이 실제로 작동했다)

| 지적 | 내용 |
|---|---|
| **인증 포함관계** | `verifyMobileAccessJwt` ⊂ `verifyAppJwt` — **v2 토큰은 기존 12개 API 를 그대로 통과**한다 |
| **v2 ≠ 안전** | 세션 DB 를 조회하지 않아 **로그아웃해도 access 토큰이 만료 전까지 산다**. `twoFactorPending` 계정도 v2 로그인이 막지 않는다 |
| **계산 오류** | 내가 쓴 "IME 로 29% 소실"이 틀렸다 → **26.5%**(전체 높이와 안전 영역 기준을 섞었다). `ime` 인셋에 네비바가 **이미 포함**돼 중복 차감 위험 |
| **전경색 오류** | "상태색 배경 위 잉크 **또는 흰색**"이 틀렸다 — **흰 글자는 상태색 3종에서 전부 실패**. 위험 배경 위 잉크는 **4.76:1**(7~8.4 아님) |
| **인과 오류** | "색을 바꾸면 판정이 어긋난다"는 틀렸다 — **판정은 서버 규칙, 색은 표현** |
| **과장** | "네 모서리를 OS 가 점유" → 확인된 건 **아래 두 모서리 + 펜 버튼**뿐 |
| **근거 없는 수치** | 시안의 "남은 시도 2회" — **API 가 남은 횟수를 주지 않는다**. 잠기면 `429`+`retryAfterSec` 만 준다 |
| **기본 선택 위험** | 입력 칩에 "이상 없음"이 미리 선택돼 있었다 → **확인 없이 저장돼 안전 기록이 왜곡**된다. 기본 선택 제거 |
| **중복 방지 부재** | `app-media` 핸들러에 **클라이언트 작업 ID 중복방지 계약이 없다**. 지연 전송을 채택한 이상 **선행 과제** |
| **권한 오해** | `mediaWriteScope` 는 **소유자 또는 본인**만 — "admin·owner 수정 가능"은 부정확 |

## 5. 관제웹(라이브) 분석 요약

- 라이브 = `vitalguard-dashboard-569797426568.asia-northeast3.run.app` · Next.js · **API 108개** · 컴포넌트 72개
- 실물 레이아웃 = **상위 6탭 + 하위 4탭 2층** + 알림 모달 + 어시스턴트 챗
- **앱 토큰이 닿는 API 는 12개뿐** — 담당관 주 업무(생체·알림·가스·AED·CCTV)는 **관제 세션 전용**
  → **서버 확장(D-4)이 이 프로젝트 최대 리스크**
- **CCTV** — `00006-svz` **단발 JPEG 스냅샷 엔드포인트**(`/cctv/snapshot`)로 **MJPEG 장기연결을 대체해 과금이 사라졌다**(태곤 님 정정).
  → Flutter 는 multipart 파싱 없이 **JPEG 한 장씩** 받으면 된다. **RTSP 직접 재생은 권하지 않는다**(media_kit 약 2초 지연).
  → 교체 예정 카메라 = **TP-Link VIGI C340S**(RTSP `rtsp://IP/stream1` 554 · ONVIF)

## 7. 지켜야 할 원칙 (문서에 박아둔 것)

- **등급 없는 단정을 쓰지 않는다** — `[관측]/[계산]/[문서]/[확정]/[가설]/[미검증]`
- **`조회 0행`을 `정상 0건`으로 표시하지 않는다**
- **서버가 주지 않는 수치를 화면에 만들어내지 않는다**
- **상태는 색 + 모양으로 말하고 글자를 덧붙이지 않는다**(모양이 곧 라벨)
- **경보 목록 행 탭 = 확인 처리로 만들지 않는다** — 상세에서 명시적 1회
- **오프라인에서 대응 확인을 예약하지 않는다** — 누가 언제 확인했는지가 안전 기록이다
- **"로컬 저장됨" ≠ "전송 완료"**
- **결과 불명이면 재전송이 아니라 서버 상태 재조회가 먼저**
- **펜 작업 중 레이아웃이 변하면 안 된다** — 경보 스트립 슬롯을 항상 예약
- **앱은 IME 를 강제하지 않는다**
- **md 가 정본이고 docx 는 생성한다** — 사람이 둘을 따로 고치면 반드시 어긋난다
- **잉크는 `stylus` 만 그린다** — `touch` 로도 그리면 팜 리젝션 취소 전 몇 프레임이 손바닥 점으로 남는다
- **`onPointerCancel` 을 반드시 처리한다** — 팜 리젝션은 차단이 아니라 **사후 취소**다
- **인셋은 런타임에 읽는다** — `29.6` `368.0` 같은 관측값을 상수로 박지 않는다
- **`SafeArea` 를 믿지 않는다** — 좌우 제스처 띠는 `systemGestureInsets` 에만 있다
- **핵심 동작을 펜 버튼·모서리 제스처에 걸지 않는다** — OS 가 선점한다(실물 확인)
- **관리자가 적는 기록과 서버 판정을 섞지 않는다** — 색도 같이 쓰지 않는다(코덱스 지적)
- **계측 코드를 먼저 의심한다** — 숫자가 이상할 때 기기 탓하기 전에 내 측정 로직을 본다
