# 상단 상태 띠 색상·세로 정렬 — 2026-09-28

사용자가 지적한 갈색 띠와 아래로 처진 오프라인 문구·Wi-Fi 제한 아이콘·오른쪽 원형 안내 아이콘을 수정했다.

## 변경

- 오프라인 띠를 `#2F444D`, alpha `179/255`의 반투명 청회색으로 변경했다. 사진의 철골 색과 파란 강조색에 맞추고, 연결 제한 아이콘의 황색은 유지한다.
- 64dp 상태 띠의 위아래 여백을 각각 8dp에서 4dp로 조정했다. 오른쪽 안내 버튼의 최소 높이 56dp를 수용해 왼쪽 현장명과 오른쪽 상태 요소의 세로 중심을 맞춘다.
- 전체 반투명 패널·카드·불투명 사이드바, 상태 상세 안내 동작은 유지한다. 통신·세션·저장·전송 코드는 변경하지 않았다.
- 버전은 **1.3.1 / versionCode 6**이다.

## 검증

- JVM **296/296**, 오류·실패·건너뜀 0. 사진의 최대 밝기 위에서도 상태 띠의 본문·보조·버튼 글자 대비 **4.5:1 이상**을 확인한다.
- 프리뷰 **22/22**, 오류·실패·건너뜀 0. 가로·세로·큰 글꼴·오프라인 및 설정의 버전 표시를 갱신했다.
- 실기기 관련 검사 **9/9**, **26.174초**. `CommonStatesComposeTest`, `FieldAppComposeTest`를 실행했다. 현장명 대비 Wi-Fi 제한 아이콘·오프라인 문구·안내 버튼의 세로 중심 차이가 1px 이내인지 확인하며, 안내창 열기와 기존 화면 전환도 통과했다.
- 직전 1.3.0의 전체 실기기 **52/52** 결과는 [사진 배경 검증](wallpaper-layout-verification.md)에 있다. 1.3.1에서 전체 52개를 다시 실행했다는 뜻은 아니다.
- 원본의 `app/src` 전체와 검증용 ASCII 복사본의 파일이 일치한다. 중지·재개 사이 코드 변경이 없어 통과한 검사를 반복하지 않았다.

## 설치 상태

개발 앱 `com.vitalguard.field.dev`에 1.3.1을 데이터 보존 설치해 위 계측을 실행했다. 재개 시 `adb devices -l`에 연결 기기가 없어 주 앱 `com.vitalguard.field`의 1.3.1 설치는 **USB 재연결 대기**다. 마지막 확인된 주 앱은 1.3.0 / code5이며, 이번 변경을 주 앱에서 보았다고 기록하지 않는다.
