# 1.3.16 기상 상세·로그인·편집 배치 — 2026-09-30

## 기능

- 기상 위젯 중앙 구분선은 서버 metricLevels에 따라 주의=노랑·위험=빨강 정적 네온이다. 정상은 무채색 선, 미수신/오래됨/실패도 네온을 켜지 않는다. 관제 임계를 앱에 복제하지 않았다. 체감온도·풍속·강수량·자외선·PM2.5만 기존 판정이 있으며 기온·습도·PM10·WBGT는 참고값이다.
- 실외 환경과 가스포드 실내 환경을 구분했다. 실내는 같은 최신 표본의 온도℃·습도%·기압hPa, 기기ID/마지막 수신 시각이다. 외부 API 실패와 독립이다. 서버가 계산한60초 유효기간에서 서버 응답 대기 및 수신 후 경과시간만 빼며 만료·실패 시 —로 바꾼다. 기존 현장조회60초 주기를 유지한다.
- 현재 기상 요약에서 PM2.5를 분리하고 PM10/PM2.5 대기질 위젯을 별도 표시한다. 기존 종합 weather.level/summary는 현장 대시보드용으로 유지하고, 별도 conditions 응답을 기상 상세에 쓴다.
- 기존 서버 daily7의 실제7일 예보(날씨 아이콘/상태·최고/최저·강수확률)를 현재 기상 오른쪽에 둔다. 큰 글꼴/좁은 폭에서는 아래로 재배치하고 예보는 가로 스크롤한다. 없는 날짜/값을 생성하지 않는다.
- 로그인에 같은 현장 사진과 반투명 흐림 카드(제목/입력/로그인 버튼)를 적용했다. 유효한 최근 날씨 효과도 사진 배경에 공유한다. 로그인 전 보호 API를 새로 호출하지 않으며 표시모드/만료시각/부팅번호만 저장한다. 계정·위치·측정값·미리보기는 저장하지 않고5분 만료·재부팅 시 효과를 끈다.
- 펜 편집은 도구 영역을 하단 한 줄로 축소해 남은 공간을 사진에 할당했다. 그리기/굵기/색상/편집/보기/저장 그룹을 라벨과 수직선으로 구분한다. 저장은 작업 손 쪽에 고정, 좁은 화면의 나머지 도구는 가로 스크롤이다. 펜/손가락 판정과 원본 좌표·초안 저장·확대/이동은 유지한다.
- 새로고침 회전은 응답이 빨라도 시작한360도를 마치고 멈춘다. 실제 공통 버튼에서210ms 뒤 로딩 종료 시 각도가 즉시0으로 돌아가는 현상을 수정 전 픽셀 검사로 재현했다. 원인은 busy 분기에 묶인 InfiniteTransition 제거였다. Animatable을 요청 상태와 분리해 완전한 회전을 이어가고 빠른 연속 탭도 처리한다. 네트워크 중복 차단/실패 상태는 기존대로다.
