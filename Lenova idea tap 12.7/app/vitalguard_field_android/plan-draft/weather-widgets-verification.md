## 반영

- 기상 상세의 캐시/서버 오래됨 설명 카드를 제거했다. compact 예제의 구조를 Compose로 구현해 아이콘·작은 괄호 항목명·큰 수치·단위를 분리한 9개 위젯을 1~4열로 표시한다. 기상 관측 출처·시각, 실제 특보·오류는 유지하며 임의 예보를 만들지 않는다.
- 기상 배경은 단일 Canvas의 비·눈·위험 강풍 효과다. 비/눈은 KMA PTY, 강풍은 기존 서버 판정이다. 기상 상세 전면/온라인/수신 성공/신선한 서버 수신 자료일 때만 동작하고 백그라운드와 다른 탭에서 멈춘다. 기존 흐림 이미지는 캐시를 유지한다. 맑음은 상시 효과가 없다.
- 사이드바 다른 탭 왕복은 상세 화면·선택을 유지하고, 이미 선택된 탭을 다시 누르면 해당 초기 화면으로 복귀한다. 현장은 대시보드, 경보는 기본 목록, 기록은 오늘의 캘린더, 전송 이력은 기본 목록, 설정/사용 방법은 맨 위다. 기록 재선택은 초안을 저장한 뒤 상세를 닫고 기존 전송을 이어간다. 계정·작업 손·갱신 간격은 초기화하지 않는다.
- 공통 원형 조작의 보이는 지름을 86%로 줄이고 기존 장갑 터치 영역은 유지했다. 하단 경보 닫기는 78%, 손 선택 원136dp·손44dp·윤곽1dp다. CCTV 카메라 칩은 넓은 화면에서 우측 상단, 좁은 화면에서 다음 행 우측으로 정렬한다.
- 전송 카드 i는 오른쪽 위, 왼쪽 테두리에 맞닿는 사각 말풍선으로 표시한다. 다시 i 또는 화면 터치로 닫고 원래 카드 높이는 바꾸지 않는다.
- 로그아웃 위 회원정보는 본인 계정만 조회하며 전화번호는 서버/클라이언트 모두 앞3·뒤2자리만 허용한다. 새 읽기 API `/api/app/admin/profile`을 사용하며 실패가 로그아웃을 유발하지 않는다.
- 경보 목록 오른쪽 초록 체크는 현재 필터에 보이는 미대응 전체를 순차 확인한다. 처리 애니메이션/중복 차단, 결과 불명 시 정지, 실제 사건 식별/서버 재조회 보호를 유지했다. 개별 대응도 유지한다. 새로고침 화살표는 요청 중에만 회전한다.
