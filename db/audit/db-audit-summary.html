핵심 메시지

DB 계층 방어(RLS·암호화·접속로그·GRANT/REVOKE)가 전부 0건이다. 현재 멀티테넌트 격리와 민감정보 보호가 전적으로 앱 코드 단일 의존이라, DB 직접접속·신규 라우트 한 곳만 우회하면 작업자 건강·생체·위치가 평문으로 노출된다. 이것이 최대 구조적 리스크다.

긍정 소견. 앱 인증(users)은 scrypt 해시·fail-closed·IP 잠금 양호. 전 경로 파라미터라이즈드로 SQL 인젝션 표면 없음. 주민번호 컬럼 없음. SECURITY DEFINER 0건.
