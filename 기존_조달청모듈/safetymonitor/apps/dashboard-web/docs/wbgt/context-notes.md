# WBGT(습구흑구온도) 산출 — 결정과 근거

2026-08-14 · 온열 B안 Phase 1. **산출·검증까지만** 하고 화면·판정은 다음 단계로 미룬다.

## 왜 지금 할 수 있게 됐나

두 가지가 오늘 갖춰졌다.

1. **일사량 확보** — Open-Meteo 가 `shortwave_radiation`·`direct_radiation`·`diffuse_radiation` 을 준다(실측 확인 · 흐린 날 direct 7.1 / diffuse 179.9 W/m² 로 특성이 정확히 갈린다).
2. **MET 실측 도착** — 작업 강도를 대사율로 쓸 수 있게 됐다(다만 TLV 결합은 Phase 3).

## 채택 — Liljegren et al. (2008)

OSHA 공식 WBGT 계산기가 쓰는 모델이고, 표준 기상 관측만으로 WBGT 를 산출하는 방법 중 **가장 검증된 것**이다(문헌 정확도 95% 확률로 ±1.8℃). 습구·흑구 센서의 에너지 균형을 풀어 자연습구온도(Tnwb)와 흑구온도(Tg)를 각각 구한다.

```
WBGT = 0.7·Tnwb + 0.2·Tg + 0.1·Ta      (실외·일사 있음)
```

**간이 근사식을 쓰지 않는다.** 검색으로 나온 `Tg = Ta + (sol − 14.92)/(0.078·sol + 12.84·wind + 16.89)` 류는 물리적으로 그럴듯하고 값도 합리적 범위였지만 **출처가 단일 검색 결과이고 논문 인용이 없다**. 체감온도 때 기상청 공식을 두 출처에서 계수까지 교차 검증한 것과 질이 다르다 — 그 수준을 못 맞추면 "우리가 정한 숫자"가 된다.

## 참조 구현

`anacv/HeatStress` R 패키지의 `wbgt.Liljegren`(원 Fortran → VBA → R 이식)을 참조로 삼는다. 소스가 공개돼 있고 함수가 잘게 쪼개져 있어 대조가 쉽다.

- `fTg` 흑구온도 · `fTnwb` 자연습구온도 · `calZenith` 태양 천정각
- 헬퍼 = `esat`·`emis_atm`·`thermal_cond`·`viscosity`·`diffusivity`·`h_sphere_in_air`·`h_cylinder_in_air`·`h_evap`

## 결정 1 — 직달 비율은 가정하지 않고 실측을 쓴다

참조 구현은 `propDirect <- 0.8`(직달/(직달+산란) = 0.8) 로 **고정 가정**한다. 우리는 Open-Meteo 가 direct·diffuse 를 나눠 주므로 **실측 비율**을 쓴다.

```
propDirect = direct / (direct + diffuse)
```

흐린 날(오늘 광주)엔 이 값이 0.04 수준이라 0.8 가정과 크게 다르다. **가정을 실측으로 대체하는 것이므로 원 모델보다 정확해지는 방향**이고, 표준에서 벗어나는 변경이 아니다(그 파라미터는 원래 관측값을 넣는 자리다).

## 결정 2 — 반복은 고정점 반복으로

참조 R 구현은 `optimize()` 로 |Tglobe − Tglobe_prev| 를 최소화한다. 우리는 원 Liljegren 방식대로 **고정점 반복**(수렴 판정 후 종료)으로 푼다 — 의존성 없이 순수 함수로 유지되고, 수렴 실패 시 상한 반복 후 포기하도록 만들 수 있다.

## 결정 3 — Phase 1 은 산출·검증까지만

화면에 붙이지 않는다. **검증되지 않은 값을 표시하면 그것이 곧 근거 없는 판정**이 된다. 순수 함수 + 테스트만 만들고, 검증 통과 후 별도 결정으로 표시한다.

## 검증 계획

참조 데이터(`data_obs.rda` 입력 · `data_wbgt.Liljegren.rda` 출력 — 살라망카 2003 여름)가 존재하나 **이 맥에 R·pyreadr 이 없어 직접 읽지 못한다**.

대신 **OSHA 공식 WBGT 계산기**로 대조한다. 권위가 더 높고(연방 기관 공개 도구) 웹에서 바로 값을 얻을 수 있다. 체감온도 때 라이브 API 응답과 독립 계산을 대조해 `차이 0.000000` 을 얻은 것과 같은 방식이다.

- 서로 다른 조건 3~5 케이스(맑음/흐림 · 고온/중온 · 강풍/약풍)로 대조
- 통과한 값을 **단위 테스트에 스냅샷으로 고정**(회귀 방지)
- 허용 오차는 문헌 정확도(±1.8℃)가 아니라 **구현 일치**를 본다 — 같은 모델이므로 소수점 수준으로 맞아야 한다

## 한계 (구현으로 해결되지 않는 것)

- **한국 법정 기준이 아니다.** 폭염작업 기준은 체감온도이고 WBGT 는 참고 지표다. 법정 판정을 대체하지 않는다.
- 문헌 오차 ±1.8℃ — 실측 WBGT 계와 다를 수 있다.
- **ACGIH TLV 결합에는 체표면적이 필요하다.** MET → 대사율(W) 환산에 키·체중이 들어간다. WBGT 를 얻어도 이 문제는 남는다(Phase 3 에서 사업주 입력 vs 표준 체형 가정 중 결정).
