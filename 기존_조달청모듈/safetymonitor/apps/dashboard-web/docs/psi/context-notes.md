# PSI(생리적 부담 지수) 도입 — 결정과 근거

2026-08-14 · 온열 알고리즘 트랙 A안. 체감온도 산출식 교체(`00270-8dw`) 다음 단계.

## 왜 PSI 인가

기존 온열 판정은 **우리가 고른 숫자**로 돈다 — 주의 37.8℃·경고 38.0℃는 참고값이지 의학 기준이 아니라서 "왜 그 숫자냐"에 답하기 어렵다. PSI 는 다르다.

```
PSI = 5·(Tc − Tc0)/(39.5 − Tc0) + 5·(HR − HR0)/(180 − HR0)
```

Moran(1998, Am J Physiol) 논문식이고 0~10 스케일이다. **임계까지 문헌에 있다** — PSI ≥ 6 = 높은 생리적 부담 구역, ≥ 7.5 = 열손상 고위험. 즉 **우리가 정할 숫자가 하나도 없다.** 체감온도를 기상청 식으로 바꾼 것과 같은 원칙(표준을 구현할 뿐 발명하지 않는다)이다.

추가 수집도 필요 없다. 입력 두 개(심부체온·심박)를 **이미 갖고 있다**.

## 결정 1 — Tc0 는 37.1℃ (칼만 초기값 재사용)

원 논문의 `Tre0` 는 열 노출 시작 전 직장온도다. 우리 시스템에서 그에 대응하는 것은 **칼만 필터가 세션을 시작하는 기준점**이고, 그 값은 이미 `packages/analyzers/src/core-temp-estimator.ts` 에 `CT0 = 37.1`(Buller 2013 문헌값)로 박혀 있다.

**같은 숫자를 두 곳에 쓰지 않는다** — `CT0` 를 export 해서 `psi.ts` 가 그것을 읽는다. 흩어놓으면 한쪽만 바뀔 때 조용히 어긋난다.

⚠ 원 논문 `Tre0` 는 보통 36.5~37.0 범위라 우리 37.1 과 다르다. 분모(39.5−Tc0)가 2.4 로 논문(2.5~3.0)보다 작아 **같은 체온에서 PSI 가 약간 높게 나온다**(안전측). 표기에 명시한다.

## 결정 2 — HR0 는 개인 안정심박, 없으면 60

논문 가정은 HR 60~180 상승폭이다. 우리는 **`restingHeartRate` 를 이미 수집**하므로(워치가 하루 단위로 갱신·샘플에 sticky 유지) population 상수 60 대신 개인 실측을 넣는다. 체력이 좋은 사람과 그렇지 않은 사람이 갈린다.

없으면 논문 기본값 60 으로 폴백하되, **그 사실을 표기에서 구분**한다(개인화 여부가 값의 의미를 바꾼다 — L-58 계열).

## 결정 3 — 클라이언트 계산(표시 전용)

1차는 표시 전용이므로 서버 응답에 필드를 추가하지 않는다. `coreTempEst`·심박·안정심박이 이미 vital GET 응답에 있어 **화면에서 조합만 하면 된다**.

순수 함수는 `lib/psi.ts` 에 둔다 — 나중에 알림으로 승격하면 서버가 같은 함수를 import 하면 된다(계산이 두 벌이 되지 않는다).

## 결정 4 — 판정·알림 미주입

기존 원칙 유지. PSI ≥6/7.5 는 **색상과 표기만** 바꾸고 신호등·텔레그램에는 넣지 않는다. 이유는 입력인 심부체온이 추정치이기 때문이다 — 추정 오차가 지수로 전파되고, 그 전파량을 검증할 정답 데이터가 없다.

승격하려면 별도 결정이 필요하다. 온열 ②(저활동·고심박)가 표시 주석으로 시작해 ③에서 알림이 된 경로와 같다.

## 결정 5 — 표시 위치는 체온 셀 병기

작업자 표에 열을 늘리지 않는다(직전에 열 폭 문제를 고친 참이고, 12번째 열은 폭을 다시 압박한다). PSI 는 체온과 심박에서 나온 값이라 **체온 셀에 병기**하는 것이 의미상으로도 맞다.

스트레스 지수와의 관계는 이번에 손대지 않는다 — 스트레스는 심박 파생(HRV 0건), PSI 는 체온+심박 문헌 지수로 근거 강도가 다르지만, 대체 여부는 사용자 결정 사항이다.

## null 규칙

- 심부체온 추정이 없으면(워밍업 30분 미달·미착용) PSI 도 **null = 판정 불가**
- 심박이 없으면 null
- **0 과 null 을 구분한다** — 0 은 "부담 없음", null 은 "모름"(온열 ② 에서 세운 원칙)

## 검증 기준

- 논문 예시 조건에서 값이 문헌 범위 안에 든다
- 단조성 — 체온↑ → PSI↑ · 심박↑ → PSI↑
- 개인 안정심박이 낮을수록 같은 심박에서 PSI 가 높다(초과분이 크므로)
- 0~10 클램프
- 입력 결측 시 null (0 이 아니다)
