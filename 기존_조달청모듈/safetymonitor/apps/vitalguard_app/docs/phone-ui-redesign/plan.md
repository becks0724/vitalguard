# 폰 앱 UI/UX 개편 — 계획 (2026-08-18 수립)

목적 = **참고 디자인(사용자 제공 3장)의 시각 언어를 폰 앱에 적용한다.**
데이터 배관은 `docs/phone-vitals-ui/plan.md` 에서 이미 끝났다(08-16). 이번은 **표현만** 바꾼다.

## 1. 사용자 결정 (2026-08-18)

| 항목 | 결정 | 비고 |
|---|---|---|
| 테마 | **라이트 고정** | 참고 디자인은 다크지만 현장 직사광선 가독성을 택함 |
| 범위 막대 | **임계 있는 것만** | 심박·SpO₂ 만. 나머지는 값·단위·측정 시각 |
| 색 | VitAlGuard 기존 비율 | 중립 지배 · 브랜드 파랑 액센트 · 상태색은 판정에만 |

## 2. ★ 만들지 않는 것 — 데이터가 없다

참고 디자인 카드 중 아래는 **폰에 값이 없다.** 그리면 없는 값을 지어내는 것이고,
이 레포가 반복해 고쳐 온 결함(화면이 사실과 다른 것을 말한다)이다.

| 참고 카드 | 왜 못 만드나 (코드 근거) |
|---|---|
| 손목 온도 / 체온 | 워치·폰 전체에 온도 수집 코드 **0건** (`WatchStreamer.swift` HKQuantityType 목록) |
| 에너지(kcal) | `ae` 는 받지만 상시 워크아웃으로 **약 4배 과대** — `heat-activity-axis` 미해결. 기존 가드가 표시를 금지한다 |
| VO2 Max · 생체 나이 | HealthKit 수집 목록에 없음 |
| 수면 · 회복 · 신체 에너지 · 스트레스 | 수집 없음 |
| 훈련 부하 (TSB/ATL/CTL) | 파생 지표 · 원천 데이터 없음 |

## 3. 만드는 것

```
히어로   실시간 심박 — 큰 숫자 + 가로 밴드 막대 + 상태 배지
신체지표 2열 타일 — SpO₂(막대) · HRV · 안정 심박 · 보행 심박 · 호흡수 · 운동 강도 · 일광
활동     2열 타일 — 걸음 · 오른 층 · 정지 지속
전송     큐·업로드 상태 (VitAlGuard 고유 — 참고 디자인엔 없지만 안전 앱의 핵심)
신원     이름·사번
```

측정 안 된 종류는 **타일 자체가 없다** — 기존 `buildVitalRows` 의 생략 규칙을 그대로 잇는다.

## 4. 밴드 근거 — 새로 만들지 않는다

`packages/analyzers` `THRESHOLDS` + `dashboard-web/lib/severity.ts` 에서 그대로 가져온다.

```
심박   위험 ≥130 · ≤40   주의 110–129 · 41–50   정상 51–109      (표시 구간 30–170)
SpO₂   위험 <88          주의 88–91             정상 ≥92          (표시 구간 80–100)
```

⚠ **폰은 활동 게이트가 없다.** 대시보드는 `isWorking()` 으로 작업 중 심박을 완화하지만
(작업 중 135/155), 폰이 가진 걸음·층은 **누계**라 구간 강도를 못 낸다. 그래서 폰은
**안정 기준**을 쓰고 그 사실을 막대 아래에 적는다 — 안 적으면 벽돌 나르는 작업자에게
"주의"가 뜬다.

## 5. 색 — 기존 비율

대시보드 `globals.css` 토큰을 1:1 로 옮긴다. 지금 폰만 시드가 빨강(`#D32F2F`)이라
버튼·입력·앱바까지 붉게 물들어 로고(`#1860c0` 네이비블루)·관제웹과 어긋나 있다.

```
중립  캔버스 #FFFFFF · 카드 #FAFAFA · 헤어라인 #F0F0F3 · 값 #171717 · 라벨 #60646C · 보조 #999999
브랜드 #0D74CE  (앱바·버튼·인디케이터 점·링크)
상태  정상 #10B981 · 주의 #F59E0B · 위험 #EF4444   ← 판정에만
심박  #D32F2F 유지 (하트 아이콘 — 참고 디자인도 심박은 빨강)
```

비율 목표 = 중립 ~85% · 브랜드 ~10% · 상태 ~5%.
