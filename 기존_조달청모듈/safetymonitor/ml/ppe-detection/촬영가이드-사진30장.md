## 0. 왜 찍는가 — 목적이 셋이다

**① 안전화 판정을 가능하게 한다 (최우선)**
6차에서 안전화는 인도메인 `R 0.961`, 예약 현장 `R 0.000` 으로 끝났다.
507 에는 **"같은 작업 유형의 다른 현장"이 존재하지 않아** 일반화를 잴 방법이 없다(17-7절).
**이 사진이 유일한 시험지다.**

**② 거리별 검출 단절점을 찾는다**
4차에서 근거리 머리(정규화 높이 0.19~0.31)를 통째로 못 잡았다 — 학습 분포
(E63 head 중앙값 0.051 · 최대 0.141) 밖이었기 때문이다. **몇 미터부터 무너지는지가
배포 조건**인데 아직 모른다.

**③ 상용 데이터 자산의 시작점**
현행 학습 데이터는 SH17(비상업) · AI Hub(학습 전용)라 상용 반입이 막혀 있다.
**자체 촬영분은 그 제약이 없다.** 성능 문제와 라이선스 문제를 동시에 푸는 유일한 재료다.

> ⚠️ 30장은 **학습용이 아니라 시험지**다. 학습에 넣으면 시험지가 사라진다.
> 5차에서 홀드아웃을 학습에 넣어 채점 불능이 된 사고(4절)를 반복하지 않는다.

## 1. 촬영 구성 — 30장 배분

**PPE 조합 4종**

| 코드 | 안전모 | 신발 | 의미 |
|---|---|---|---|
| `A` | 착용 | **안전화** | 정상 (음성) |
| `B` | **미착용** | 안전화 | 안전모 미착용 |
| `C` | 착용 | **운동화** | 안전화 미착용 |

**배분**

```
① 기본 격자   4조합 × 3거리(3·6·10m)        12장   ← 핵심
② 함정: 안전모를 손에 듦      3·6·10m        3장
③ 함정: 안전모를 바닥에 둠    3·6m           2장
④ 2명 동시 (상태가 서로 다름) 6m 중심        4장
⑤ 발 가림 (쪼그림·자재 뒤)    3·6m           3장
⑥ 뒤돌아선 자세               3·6m           2장
⑦ 역광 · 그늘                 6m             2장
⑧ 예비 (재촬영·추가 각도)                    2장

                                             30장
```

**②③이 중요하다** — 현행 모델이 "안전모를 들고 있는 사람"을 착용으로 오판하는지는
공개셋으로 잴 수 없다. 실제 현장에서 흔한 장면이다.

**⑤는 안전화 판정 전용이다** — `no_safety_shoes` 박스는 무릎~발이라 발이 가려지면
어떻게 되는지 알아야 한다.

## 2. 거리와 구도 — 숫자로 맞춘다

거리는 목표가 아니라 **수단**이다. 실제로 맞춰야 하는 것은 **화면 안 크기**다.

| 거리 | 사람 전신이 화면 세로에서 | 예상 `head` 정규화 높이 | 학습 분포와 |
|---|---|---|---|
| **10 m** | 약 **35%** | ≈ 0.05 | **중앙값 부근** (E63 0.051) |
| **6 m** | 약 **60%** | ≈ 0.08 | 95백분위 부근 (0.086) |
| **3 m** | **화면을 꽉 채움** | ≈ 0.14 이상 | **학습 최대치(0.141) 경계** |

> 머리는 신장의 약 1/7.5 다. 전신 비율만 맞추면 머리 크기는 따라온다.

**`no_safety_shoes`(무릎~발)는 신장의 약 29%** 이므로

```
10 m  사람 35%  →  무릎~발 ≈ 0.10   ← 6차 학습 중앙값(0.098)과 일치
 6 m  사람 60%  →  ≈ 0.17
 3 m  사람 100% →  ≈ 0.29           ← C06 실패 지점(0.191)보다도 크다
```

**즉 3m 는 확실히 학습 분포 밖이다.** 그게 목적이다 — 단절점을 찾는 것이지
잘 나오게 찍는 것이 아니다.

### 첫 장을 찍고 반드시 재본다

거리는 화각에 따라 달라진다. **10m 한 장을 먼저 찍어 사람이 화면 세로의 35% 근처인지
확인**하고, 아니면 거리를 조정한 뒤 본 촬영에 들어간다. 세 거리 모두 같은 방식으로 맞춘다.

## 3. 촬영 조건 — 고정할 것과 바꿀 것

### 고정 (전 30장 동일)

```
기기        같은 스마트폰 한 대. 중간에 바꾸지 않는다
렌즈        후면 메인 카메라 1× 고정   ← 초광각(0.5×)·망원(2×) 금지
            화각이 바뀌면 "거리 ↔ 박스 크기" 관계가 깨져 ②번 목적이 무의미해진다
방향        가로(landscape)            ← CCTV 와 같은 방향
비율·해상도 16:9 · 1920×1080 이상
카메라 위치 삼각대나 고정 지점. 카메라는 두고 사람이 이동한다
카메라 높이 눈높이(약 1.5m) 또는 가능하면 2.5~3m 부감(CCTV 유사).
            어느 쪽이든 30장 내내 같게 하고 파일에 기록
끄기        인물 모드 · 배경 흐림 · 플래시 · 필터
```

**인물 모드를 반드시 끈다** — 배경 흐림은 실제 CCTV 에 없는 효과이고 검출을 왜곡한다.

### 바꿀 것 (도메인 다양성)

```
배경   실외 1세트 + 실내 1세트   ← 가능하면 실제 현장 유사(콘크리트·비계·자재)
조명   주광 + 그늘/역광(⑦)
복장   상의·하의를 도중에 한 번 바꾼다
```

⚠️ **복장을 바꾸는 이유** — 507 은 검정 트레이닝복 + 파란 줄무늬 양말이 반복돼
**"신발이 아니라 복장을 외웠을 가능성"** 이 계속 따라다녔다(6차에서 부분 반증했으나
같은 현장 안에서였다). 복장을 바꿔 찍으면 그 질문에 직접 답할 수 있다.

### 신발

```
안전화   발목 보호 · 두꺼운 밑창 · 끈 있는 중목 작업화
운동화   얇은 밑창 · 발목 노출 · 밝은 색이면 더 좋다(대비 확인용)
```

두 켤레를 **같은 사람이 갈아신고** 찍는다. 사람이 바뀌면 변수가 둘이 된다.

## 5. 현장 체크리스트

촬영 중 이것만 확인하면 된다.

```
□ 렌즈가 1× 인가 (0.5× 로 바뀌어 있지 않은가)
□ 인물 모드·필터가 꺼져 있는가
□ 가로 방향인가
□ 사람 전신이 화면 세로에서 목표 비율인가 (10m 35% · 6m 60% · 3m 100%)
□ 발이 화면 안에 들어와 있는가        ← 안전화 판정에 필수
□ 머리 위가 잘리지 않았는가
□ 카메라 높이가 처음과 같은가
□ 파일명 규칙대로 저장했는가
```

**발이 잘리면 그 장은 안전화 시험에 못 쓴다.** ⑤(발 가림)는 의도적으로 가리는 것이지
프레임 밖으로 나가는 것이 아니다.

### 함께 기록할 것 (메모 한 장이면 충분)

```
촬영일시 · 장소(실내/실외) · 카메라 높이 · 기종
장별 비고 — 2명일 때 각자의 착용 상태, 특이사항
```

## 7. 어떻게 채점하나

라벨이 준비되면 **학습 없이** 바로 잴 수 있다. 6차 가중치는 이미 맥에 있다
(`YOLO ML DATA/ppe_yolo26s_640_v6_nc_best.pt`).

```
① 거리별 검출률        head · no_safety_shoes 각각 3m·6m·10m
② 박스 크기 실측       정규화 높이를 학습 분포와 대조 (in_train_range 비율)
③ 단절점              검출률이 무너지는 거리
④ 조합별 판정          A~D 4조합에서 알림이 맞게 울리는가
⑤ 함정                안전모를 손에 든 장면을 착용으로 오판하는가
⑥ 복장 교차           복장을 바꿔도 안전화 판정이 유지되는가
```

**성공 기준 (제안)**

```
안전모 미착용 알림   6m 이내에서 R ≥ 0.90 @ P ≥ 0.85     ← 5차 게이트와 같은 잣대
안전화 미착용 알림   6m 이내에서 R ≥ 0.85 @ P ≥ 0.85
단절점               10m 에서 검출되면 CCTV 부감 화각에 쓸 수 있다
```

**여기서 안전화가 통과하면 6차의 "잴 수 없다"가 해소된다.**
미달이면 이 30장을 **7차 학습에 넣지 말고**, 같은 조건으로 200~300장을 더 찍어
학습셋을 만들고 30장은 시험지로 남긴다.
