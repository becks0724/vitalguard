## 확정된 것 (다시 읽지 않아도 되게)

- **목표** — 현행 라이브 모델(CAM-03 Hexmon `vyra_ppe.pt`)을 **교체할 수 있는지** 숫자로 판정
- **클래스 8종** — `person head helmet safety_vest foot shoes hands gloves`
  미착용은 클래스로 두지 않고 `head`(맨머리) + person 포함관계로 코드 판정
- **젯슨 배포 가능성 = 확정** — TensorRT FP16 @960 에서 yolo26s 27.0 fps / **yolo26m 17.1 fps**
- **SH17 은 비상업** — 산출 가중치에 `-nc` 접미사가 자동으로 붙는다
- **엔진 변환은 젯슨에서만** — 코랩에서 만든 `.engine` 은 못 쓴다

## 1차 결과와 2차가 필요한 이유

| 지표 | 값 | 판정 |
|---|---|---|
| 인도메인 mAP50 | 0.677 | — |
| helmet 교차 홀드아웃 | R 0.633 → 0.511 (19.3%↓) | 양호 |
| **head 교차 홀드아웃** | **R 0.874 → 0.259 (70.4%↓), P 0.181** | **심각** |

**모델이 안전모 쓴 머리를 `head`(맨머리)로 예측한다.** 학습 데이터가
`head 14,413 : helmet 4,478 = 3.2 : 1` 로 치우친 결과다.
실사용 시 **안전모 착용자가 미착용 위반으로 오탐**되므로 현 상태 관제 투입은 불가하다.

2차는 **Hard Hat Workers(helmet 19,744)를 학습에 편입**해 이 불균형을 뒤집는다.

## 확인 포인트

### 리매핑 직후 — 가장 중요

```
★ helmet : head = 1 : 0.64
```

**1:1 근처면 성공**이다. 여전히 `1 : 3` 대면 HHW 편입이 안 된 것이니 멈추고 확인한다.

`증강사본 제외 N` 도 함께 나온다. HHW 는 16,866장 중 약 9,800장이 증강본이라 제외돼야 한다.

### 학습 중

- 첫 에포크가 끝났을 때 찍히는 **실제 소요**를 본다
- **화면의 ETA(`n:nn<n:nn`)는 무시할 것.** 순간 속도라 정체를 반영하지 못해 실제보다 빠르게 나온다
- `Size` 가 `640`, `GPU_mem` 이 6~7G 대면 정상

### 평가 — 2차 성공 조건

```
helmet recall 상승        (1차 0.633)
head precision 유지·개선   (1차 교차 홀드아웃 0.181)
```

노트북이 1차 수치를 표에 병기하므로 바로 대조된다.

### 홀드아웃 — 2단 확인

후보 탐색 셀이 **클래스 목록과 원본 장수**를 출력한다. 여기서 반드시 확인한다.

- `helmet` 과 `head` 가 **분리**돼 있는가 (병합본이면 허상 결과가 나온다)
- 원본(valid+test)이 500장 이상인가

**클래스 이름이 같아도 뜻이 다를 수 있다.** SHWD 계열의 `person` 은 "사람 전체"가 아니라
"헬멧 안 쓴 머리"인 경우가 있다. 매핑을 확정하기 전에 프로젝트 설명을 확인할 것.

## 막혔을 때

| 증상 | 대응 |
|---|---|
| `ModuleNotFoundError` | 셀 순서를 건너뜀. `%pip install` 셀 실행 (v2 는 자동설치 가드가 있다) |
| `NameError: 'rf' is not defined` | **런타임이 회수됨.** 아래 재개 절차 |
| `CUDA out of memory` | `BATCH` 16 → 8. 그래도 나면 `IMGSZ` 640 → 512 |
| 리매핑 후 클래스 0건 | 클래스 이름 불일치. 구조 확인 셀의 `names` 를 매핑표에 반영 |
| `collect_pairs` 0장 | `images` 디렉터리가 없는 레이아웃. `find` 출력 보고 `root` 수정 |
| Kaggle 403 | 데이터셋 페이지를 브라우저로 열고 Download 를 눌러 규정 동의 |
| Kaggle 401 | 토큰은 **한 번만** 표시된다. Expire Token 후 재발급 |
| 홀드아웃 하락률이 이상하게 큼 | 병합본·증강본 의심. 클래스 목록과 장수를 다시 볼 것 |

**학습이 끝난 뒤에는 90분 유휴로 런타임이 회수된다.** 학습 중에는 실행 중이라 안 죽는다.

| 순서 | 할 것 |

완료된 에포크는 Drive 에 남아 버려지지 않는다. 마지막 미완료 에포크만 손실된다.
