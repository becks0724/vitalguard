# 대응 D-0 — 수집 조합표

계획 = [RUNBOOK-7차.md](RUNBOOK-7차.md) 「대응 D」 · 수집기 = `cctv-ai/edge/cam03_collect.py`

**장수가 아니라 조합을 센다.** 같은 영상의 연속 프레임은 독립 표본이 아니다(507 함정 ·
ppe.sample 59장도 독립 장면은 30개). 조합당 10장이 10장 값을 하려면 **촬영 중 천천히
움직여** 자세·거리를 바꿔야 한다. 수집기 기본 간격은 2초다.

## 태그 어휘

파일명·manifest 의 `tag` 는 아래 어휘를 `-` 로 이은다. 예 `P1-Hw-Tday-Dnear-Lin`.

```
인물    P1  P2  P3 …      P1 = 사용자. 이후 참여 순번
안전모  Hw   흰색 · 부착물 없음
        Hc   유색 · 부착물 없음
        Ha   부착물 있음 (랜턴 · 턱끈 · 스티커 · 이름표)
        H0   미착용 (맨머리)          ← head 축. 착용 격자와 따로 센다
시간대  Tday   주간 자연광
        Tdusk  석양 · 역광
        Tnight 야간 실내조명
거리    Dnear  근접   머리 정규화 높이 0.25 이상   ← 지금 무너지는 구간
        Dmid   중간   0.12 ~ 0.25
        Dfar   원거리 0.12 미만
장소    Lin   실내 (현행 CAM-03 거치)
        Lout  실외
시선    Vfront 앞모습 — 얼굴이 카메라를 향한다      ← 09-09 신설
        Vback  뒷모습 — 뒤통수가 카메라를 향한다
        Vside  측면
```

**`V`(시선) 축을 왜 더했나 — 09-09.** 사용자 지적 = 「배포 현장에서 작업자는 대부분 **앞모습**으로
탐지되는데 학습이 앞모습에 부족하다」. 그래서 CAM-03 화각을 뒷모습에서 앞모습으로 돌렸다.
축을 명시하지 않으면 **어느 쪽으로 찍힌 표본인지 모르는 채 쌓인다** — 4·5차의 도메인 얽힘과 같은 자리다.

⚠ **기존 CAM-03 기회 수집분은 전부 `Vback` 이다**(09-08 화각). 태그에 소급 표기가 없으므로
파일명 대신 **촬영일로 가른다 — 09-08 이전 = Vback, 09-09 이후 = Vfront.**

거리는 눈대중이 아니라 **엣지 `/health` 의 머리 정규화 높이**로 확인한다. 촬영 전
`gopro_ppe_edge.py` 를 한 번 띄워 거리별 위치를 표시해 두면 이후 세션이 재현된다.

## 태그 부가 규칙

- 같은 조합을 다른 세션에 다시 찍으면 `-s2` `-s3` 를 붙인다. 파일명 충돌을 막고
  세션을 구분한다. 예 `P1-H0-Tday-Dclose-Lin-s2`
- 거리 구간은 **촬영 시 눈대중이 아니라 사후 실측**으로 확정한다. 기준 = v5 `head` 박스
  정규화 높이(`scratchpad/session_report.py`). `person` 박스는 근거리에서 프레임에
  잘려 0.76~0.80 으로 포화하므로 거리 지표로 **쓰면 안 된다**(2026-09-02 실측).

## ★ 검수 규칙 — 교사 검출률 0% 는 데이터 오류 경보다

1회차에서 **두 번** 발생했다. `Hw`(착용) 태그로 찍었는데 개방어휘 교사가 0% 였고,
프레임을 눈으로 보니 **안전모를 쓰지 않은 상태**였다. 교사가 실패한 게 아니라
찾을 안전모가 없었다. 태그를 `H0` 로 정정했다.

→ D-1 검수에 넣는다. **`Hw` 태그인데 교사 검출률이 10% 미만이면 라벨링 전에 눈으로 본다.**
   (원거리에서도 교사는 18~30% 는 나온다. 0% 는 다른 종류의 신호다.)

⚠ **그러나 정작 필요한 것은 못 쟀다.** 사무실이라 안전모 착용자가 0 명이라 `helmet` 검출이 20프레임

사용자가 걱정하는 자리가 바로 거기이므로, **2회차 `Hw`·`Hc`·`Ha` 를 `Vfront` 로 찍는 것이

★ **확인된 진짜 구멍은 앞/뒤가 아니라 크기다.** 앞모습에서 학습 대역 밖이 41%, 학습 최대 초과가 11%.
09-08 근접 미탐지 실측(리서치 §2-6)과 같은 결론이다.

⚠ **부수 손실 — 자세 판정이 죽었다.** 앞모습에서는 앉은 사람의 허벅지가 카메라를 향해 눌려
수직처럼 보인다(허벅지 중앙 뒷모습 93.8도 → 앞모습 38.2도). 94 사람-프레임 전원 착석인데 앉음 판정 0.
**오탐이 아니라 기권이다**(서있음 오탐도 0). 낙상 판정은 몸통만 쓰므로 무영향(엉덩이 관측 81.4%).
→ 자세 축은 화각 의존적이라는 것이 드러난 것이고, 임계 조정으로 해결되지 않는다.
