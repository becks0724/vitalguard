## 확정

1. **원인 = `sh17_head_filter` 가 SH17 의 helmet 박스를 전부 버리는 것.**
   버린 자리에 아무 박스도 안 남아 그 화소가 **배경**이 된다 → 「착용 안전모는 아무것도 아니다」.
   pilot6→pilot8 은 **476개 박스만** 다른데 helmet 이 2 → 65.
2. **237장이 라벨 11,274개를 이긴다.** 「있다」는 한 곳을 가리키고, 「없다」는 사진 전체에 대고 한다.
3. **시작 가중치는 무죄** (pilot4 — COCO 출발도 90/100).
4. **E63 은 무죄** (pilot5 — 더하니 90→94). E63 에 무라벨 착용 안전모가 **있는 것은 사실**이지만
   제대로 붙인 helmet 4,359개가 그것을 압도한다. **기전이 있다 ≠ 그 기전이 지배한다.**
5. **처방은 「사진째 빼기」(77)가 「박스 살리기」(65)보다 안전모에 낫다.**
   박스 정의가 다르기 때문(SH17 = 모자만 · 우리·GDUT = 머리 영역 w/h 0.79).
