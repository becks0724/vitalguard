5차와 동일하다. 셀을 위에서부터 순서대로 돌린다.

**5차 대비 달라진 것은 두 곳뿐이다.**

| 셀 | 확인할 것 |
|---|---|
| 설정 | `USE_A507 = True` · `A507_HOLDOUT_SITE = 'C06'` · `RUN_NAME` 에 `v6` |
| 데이터 연결 | `[a507]` 블록이 `no_safety_shoes` 를 0 이 아닌 값으로 출력하는가 |

**멈춰야 할 신호**


⚠️ **에포크 시간이 5차(3.04분)보다 크게 늘면 멈추고 확인할 것.**

## 3단계 — 판정

### 통과 조건

```
□ 507 현장 홀드아웃(C06)  안전화 알림 R ≥ 0.85 @ P ≥ 0.85
□ E63 홀드아웃            head·helmet 이 5차 수준 유지
□ 안전모 알림             R ≥ 0.90 @ P ≥ 0.85 유지
```

### ★ 통과해도 완결이 아니다

```
안전화는 "게이트 통과 = 완결" 이 아니라 "통과해도 현장 검증 전까지 보류" 다.
```

이유는 데이터에 있다(리포트 15-3).

```
WO-07 현장 분포   A03 82%  ·  C06 13%  ·  A04 5%  ·  A10 0
C06 을 홀드아웃으로 빼면 학습은 사실상 A03 단독이다
박스가 무릎~발이라 바지·양말·자세가 함께 들어간다
UA-03 작업자는 검정 트레이닝복 + 파란 줄무늬 양말이 반복된다
→ 신발이 아니라 복장을 외웠을 수 있다
```

**507 을 전량 받아도 해결되지 않는다.** 확인 수단은 하나뿐이다 —
**직접 촬영 시험지(거리 3·6·10m)에 안전화/운동화 대비를 넣는 것.**

5차 안전모가 GoPro 도메인 교차 검증을 통과하고서야 완결된 것과 같은 기준이다.

## 막혔을 때

5차 런북의 「막혔을 때」가 그대로 유효하다. **6차 고유 항목만** 여기 적는다.

| 증상 | 원인 · 대처 |
|---|---|
| `no_safety_shoes 가 0개다` assert | 변환기가 8클래스로 돌았다. `data.yaml` 에 `8: no_safety_shoes` 가 있는지 확인 |
| `507 현장 'C06' 에 해당하는 프레임이 없다` | `A507_HOLDOUT_SITE` 오타. 유효값 `A03`·`A04`·`C06` (`A10` 은 `WO-07` 이 없다) |
| 507 홀드아웃에 `no_safety_shoes` 0개 | 현장 선택이 잘못됐다. `C06` 은 259개가 나와야 한다 |
| `a507` 이미지가 person 을 못 배움 | person 자동 라벨 셀의 접두사에 `a507` 이 있는지 확인 |
| tar 해제 후 `._*` 파일 오류 | 맥에서 `COPYFILE_DISABLE=1` 없이 만들었다. 다시 만들 것 |
