# 판정 대상 규칙 (구역 + 추적 지속) — 09-15 설계 · **착수는 09-16**

사용자 결정 09-15 — **Ⓐ「CCTV 화면의 현장 영역에 있는 인원은 전부 작업자」 + Ⓒ 추적 지속**.

## 왜 — 오경보의 주범이 모델이 아니라 규칙이다

`gopro_ppe_edge.py:297` 이 `violation_count = cnt["head"]` 다. **행인의 맨머리가 그대로 위반이 된다.**

현장 35장에서 `head` 라벨 9개를 전수 육안 확인했다. **9개 전부 행인**이고 작업자는 0명이다
(검은 티에 배낭 멘 무리 · 크로스백 멘 사람이 5장에 걸쳐 찍힘).

```
                조끼 O   조끼 X
helmet (착용)      96       3
head   (미착용)     0       8      ← 안전모 미착용으로 잡힌 사람 중 조끼 입은 사람 0명
```
⟹ **모델이 완벽해도 위반 9건 중 8건이 행인이다.** 모델 쪽 노력으로는 원리적으로 못 내린다.

## 오경보 31건의 출처 — 정답 라벨로 하나하나 셌다

v7d(현 라이브) · 현장 35장 · conf 0.30 · imgsz 960 · **진짜 위반 0건**이므로 검출 전부가 오경보다.

| 출처 | 건수 | 처방 |
|---|---|---|
| ② 작업자인데 안전모를 **쓰고 있다** (이중검출) | 19 (61%) | 배타 규칙 + helmet recall |
| ① 조끼 없는 사람 = 행인 | 9 (29%) | **구역 규칙** |
| ④ 사람 라벨 밖 유령 박스 | 3 (10%) | 판정불가 |

v5(어제 배포본)는 주범이 반대다 — 행인 9건(64%) · 이중검출 3건(21%).
**v5 는 안전모를 아예 못 봐서(0/100) 이중검출이 생길 수 없었다.** v7d 가 안전모를 보게 되면서
(74/100) 이중검출이라는 새 오경보를 얻었다.

⚠ **배타 규칙이 19건 중 6건밖에 못 잡는다.** 나머지 13건은 사람이 안전모를 쓰고 있는데
**모델이 그 안전모를 못 봤다.** 규칙에 `helmet` 박스가 없으니 버릴 근거가 없다.
⟹ **오경보의 42%(13/31)는 규칙으로 못 고친다. 안전모 인식률(7차-E)이 올라야 사라진다.**

## ⛔ 조끼 단독 판별은 채택하지 않는다 — 최고위험 조합을 놓친다

처음 제안은 「조끼 있으면 작업자」였다. CAM-03 수집분이 그 결함을 드러냈다.
```
조끼를 벗은 작업자가 안전모도 안 썼다
  → 조끼 규칙은 그를 「행인」으로 보고 판정을 건너뛴다
  → ★ 가장 위험한 경우를 놓친다.  해당 창 vest0_*_맨머리 = 정상분 126프레임
```
**오경보를 줄이려다 미탐을 만든다.** 구역은 조끼와 독립이라 이 결함이 없다 — 그래서 Ⓐ다.

## 설계

```
① 구역 판정
   worker_now = person 박스의 **발밑 중심**(x중앙 · y하단)이 zone 안인가
   ⚠ 박스 중심이 아니라 발밑을 쓴다. 사람은 서 있으므로 바닥 위치가 「어디에 있는가」를 답한다.
     박스 중심을 쓰면 멀리 선 사람이 구역 위로 떠서 잘못 걸린다

② 추적 지속 (Ⓒ)
   worker = worker_now OR (직전에 worker 였고 경과 < TTL)
   추적기 = pose_fall.py:347-374 의 중심거리 매칭을 그대로 따른다
           (tid → {seen, worker, centroid} · MATCH_DIST · TRACK_TTL)
   TTL 기본 3초 — 길면 구역을 지나간 행인이 오래 작업자로 남는다

③ 판정
   violation = worker 로 판정된 사람 안의 head 박스 수
   + 배타 규칙 — 그 사람에게 helmet 이 이미 잡혔으면 head 를 버린다
     (실측: 미탐 위험 0 — v7d 의 현장 35장 helmet 오검이 0건이라 진짜 위반을 놓칠 경로가 없다)

④ 판정불가
   사람 박스에 안 들어간 head → 위반이 아니라 **판정불가로 따로 센다**
   ⚠ zone 이 None 이면 현행대로 전부 판정한다 — 기능이 조용히 꺼지지 않게
```
