## cctv-ai 404 의 정체 (09-22)

404 를 다섯 경로에서 받고도 「죽었다」로 적지 않았는데, 그게 맞았다. **서비스는 살아 있다.**

```
서비스      cctv-ai-00083-qq7 · 트래픽 100% · Ready
공개 접근   allUsers invoker 없음  ← 이것이 막는다
```

★ **Cloud Run 은 인증 헤더가 없으면 404 를 주고 로그도 안 남긴다**(서비스 존재를 숨기는 동작).
인증이 붙었지만 권한이 모자라면 403 을 주고 **로그에 남긴다.** 그래서 밖에서 본 404 와
안에서 본 403 이 같은 사건이다. 404 하나만 보고 판정하면 죽은 것으로 읽는다.

가른 방법 = **밖에서 재지 말고 로그를 본다.** 내 curl 은 로그에 한 줄도 안 찍혔고(=닿지 않았다),
5분 간격 요청만 403 으로 찍혀 있었다.

⚠ **새로 찾은 것 — 무언가가 5분마다 `/cctv/stats2` 를 부르고 계속 403 으로 튕긴다.**

```
00:27:28  /cctv/stats2  403
00:32:28  /cctv/stats2  403
00:37:30  /cctv/stats2  403
00:42:31  /cctv/stats2  403
```

09-18 에 서버 중계를 껐는데 **부르는 쪽이 남아 있다.** 주인을 찾아야 한다.
`deploy-dashboard.sh:26` 의 `AI_URL` 기본값이 이 주소라 대시보드 번들에도 박혀 있다.

⟹ **시연 폴백으로 쓰려면 IAM 에 `allUsers` invoker 를 붙여야 하고, 그건 팀원만 할 수 있다**
(사용자 계정은 editor 로 강등돼 IAM 을 못 바꾼다).

## 아직 안 정한 것 — 화면에 그리는 쪽

수리는 **세는 층**만 바꿨다. **그리는 층은 그대로**라 가구에 안전모 상자가 계속 그려진다.
사용자가 화면을 보고 「여전히 의자를 안전모로 인식한다」고 지적했고, 그 말이 맞다.

```
보는 층   모델이 상자를 그린다        안 바뀜
세는 층   그 상자를 누구 것으로 볼까   바뀜 — 사람 위가 아니면 안 센다
```
