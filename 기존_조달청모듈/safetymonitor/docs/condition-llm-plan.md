# LLM 작업자 컨디션 보고서 계획 (2026-07-21 검토 완료 · 코드 0 · 착수 결정 대기)

HyperCLOVA 를 이용해 작업자 누적 생체데이터를 주간/월간 컨디션 보고서로 분석하는 기능의 타당성·구조·비용 검토 기록. 사용자와 확정한 판단 기준을 보존한다.

## 1. 제품 정정 — CLOVA Chatbot ≠ LLM

- NCP **CLOVA Chatbot** 은 시나리오(질문-답변 쌍) 빌더라 생체데이터 추론 불가.
- 올바른 제품 = **CLOVA Studio (HyperCLOVA X API)**. 기존 NCP 계정·Secret Manager 패턴에 API 키만 추가(콘솔 이용 신청 필요).

## 2. 확정 구조 — "알고리즘화 → LLM 해석" 2단 (필수 구조)

```
[DB: vital_samples·alerts·스트레스 입력]
   → ① 서버 내부 조회 (LLM 은 DB 접근 경로 자체가 없음 = 읽기 전용 구조적 보장)
[알고리즘 계층 — 결정적 코드가 파생 지표 계산]
   → ② 비식별 피처 JSON (~300–500토큰 · 이름/사번/GPS/원시 파형 미포함)
[LLM — 숫자 계산 없이 해석·브리핑만]
   → ③ 보고서 (대시보드 표시 + 이력 DB 저장 = 감사 추적)
```

원시 DB 직접 주입은 성립 불가 — 작업자 1명 하루 ~1.6만 샘플 ≈ 80만 토큰(컨텍스트 한도 6배·회당 1,000원+·산술 환각 위험). 알고리즘화가 비용·정확성·보안·감사 전부의 전제.

**1단계 기존 부품 재사용**: `lib/severity`(임계 판정·활동 게이트) · `packages/analyzers`(computeStressIndex) · `alerts` 테이블(SOS/낙상 이력) · WORK_HR 밴드 · 연결끊김 상태머신(수신 품질). 신규 = 피처 집계 함수(`lib/condition-features.ts`) + 개인 베이스라인 편차(7일 이동평균 대비 — 품질 핵심) + LLM 프록시 라우트.

**CSV v2 와의 관계**: stress 입력·지수는 CSV 로도 내보내지만(2026-07-21 v2), LLM 피처는 CSV 경유가 아니라 DB 직접 조회로 뽑는다(같은 서버 내부).

## 3. 활용 계획 6항목 판정 (사용자 제시 · 전부 성립)

| # | 항목 | 판정 | 핵심 장치 |
|---|---|---|---|
| 1 | 누적 데이터 주간/월간 보고서 | 최적 형태 | 배치 생성(주간 월요일 아침 권장)+이력 저장, 호출량 월 ~100콜 |
| 2 | 생체데이터 읽기 전용 | 구조적 보장 | LLM 의 DB 경로 부재 |
| 3 | 원시 생체값 비노출 | 가능 | 피처 계층 + **등급·상대값 표현 권장**("평소 대비 +15%") + 출력 후처리 |
| 4 | 의료 진단 아님·작업 컨디션 용도 | 기존 정책 정합 | 프롬프트 가드 + "참고용·의료진단 아님" 상시 표기 |
| 5 | 판단 기준 제안 기능 | 가능 | LLM 은 **제안만** → 관리자 승인 → 코드(THRESHOLDS)에 반영. 기준의 진실 소스는 항상 코드 |
| 6 | 병원 진찰·업무 배제 제안 | 가능 | 3단계 권고(가능/조건부/의료기관 확인 권고+업무 조정 검토)까지만 — 최종 결정은 관제자(human-in-the-loop), 확인/조치는 기존 ack 패턴으로 감사 기록 |

추가: 온보딩 동의서에 "생체데이터 AI 컨디션 분석 활용" 항목 추가 필요(민감정보 처리 확장).

- 실시간 브리핑까지 확장(20명·30분 캐시): DASH ~1.1만/HCX-005 ~5.7만 원/월. 권장 = 정기 DASH-002 + 이상 전이 시 HCX-005 2단 운용.
- 무료 제공량 조항 없음(전액 종량) · 단가는 실시간 위젯 값이라 계약 시 재확인.

## 5. 미결 결정 (착수 전 확정 필요)

1. **경로** — A안: CLOVA Studio + 비식별 피처(권장·국내 리전·구축 빠름) vs B안: 온프레미스 로컬 LLM(2026-06-24 "외부 유출 금지" 결정 원안·GPU 필요). A안은 기존 결정의 완화 승인 필요.
2. **근거 표현 수위** — 완전 비노출 / **등급·상대값(권장)** / 수치 노출.
3. **생성 주기·시점** — 권장 = 주간 매주 월요일 아침 자동 + 수동 재생성 버튼.
4. **팀원 조율** — 팀원이 CLOVA 기반 "작업 배치 어시스턴트"(`068d911`~) 착수함. 피처 스키마(비식별·베이스라인 편차)·프롬프트 가드·요금 계정을 공유하도록 조율 권장(중복 구현 방지).
