## ③ 실기기 검증 — 무엇을 봐야 하나

DB 를 끊을 수는 없으므로 **503 을 인위적으로 받게 해야 한다.** 확인할 것은 폰 로그 세 줄이다.

```
업로드 실패(HTTP 503) — 30초 후 재시도
잔여 큐 N건            ← 줄지 않아야 한다(원본 유지)
[UP] N건 업로드 성공    ← 복구 후 큐가 소진되는지
```

성공 조건 = **503 구간의 샘플이 복구 후 DB 에 들어온다.** 중복 행 0 도 함께 본다
(`worker_id` + `heart_rate_measured_at` 로 대조).

**기존 계정 로그인**은 `b327223` 이 로그인 라우트에 403 분기를 추가했기 때문이다. 기존 계정은

(코드 확인 완료·피어). 다만 **실제 로그인은 자격이 있는 사람만 볼 수 있다**(L-11 계열).
