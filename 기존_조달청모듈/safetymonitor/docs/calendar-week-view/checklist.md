# 일정 캘린더 — 주간 격자 개편

사용자 지시(2026-08-20) = 구글 캘린더 레이아웃 참고. 결정 근거는 [context-notes.md](./context-notes.md).

## 확정된 배치

```
┌───────────────────────────────────────┬────────────────┐
│  주간 격자 (07~19시)                    │  미니 월간      │
│  종일 띠  [이미지 6건] ← 하루 단위 묶음   ├────────────────┤
│  ─────────────────────────────────    │  선택 상세      │
│  09시  ▓ 타워크레인 H빔 이동             │  ┌──────────┐  │
│  17시  ▓ 대전 조달청 시상식              │  │ 큰 이미지 │  │
│                                       │  └──────────┘  │
│                                       │  📷 14:07 …    │
└───────────────────────────────────────┴────────────────┘
  ↑ 좌측 332px 은 기존 현장 환경 패널 — 쓰지 않는다(실측 fixed left-0 top-44)
                                     우측 하단 LLM 버튼은 이 탭에서 숨김
```

## 단계

- [ ] **1. LLM 위젯 숨김** — 캘린더 탭에서만. 다른 탭은 그대로.
- [ ] **2. 우측 사이드 셸** — 미니 월간(상) + 선택 상세(하). 좌측은 안 건드린다.
- [ ] **3. 주간 격자** — 시간축 07~19시 · 7열 · 일정 블록을 시각 위치에.
      ⚠ `end_time` 이 없을 수 있다(실측 50%) → 기본 1시간 블록.
      ⚠ 종일 띠 필요 — `start_time` 이 nullable 이라 스키마상 종일이 가능하다(현재 0건).
- [ ] **4. 주/월 전환** — 월간 격자는 유지(오늘 손봐서 잘 돈다). 전환만 얹는다.
- [ ] **5. 사진 묶음** — 종일 띠에 `[이미지 N건]`. 클릭 → 우측 목록.
- [ ] **6. 주간에서 등록·수정** — 빈 칸 클릭 = 그 시각으로 등록.

## 남은 위험

- **일정이 2건뿐** — 어느 주를 열어도 빈 격자일 수 있다. 기능이 안 되는 것처럼 보인다.
- **`title` 이 비어 있다** — 앱이 안 보내는 것일 수 있다. 라벨은 시각+도로명으로 대신하되,
  앱이 제목을 보내기 시작하면 `title → 도로명` 순으로 바꾼다.
