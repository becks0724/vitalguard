# 결정과 근거 — 주간 격자 개편

## C-01 · 좌측을 쓰지 않는다 (2026-08-20)
초안이 구글 화면을 그대로 베껴 **미니 월간·라벨 필터를 좌측**에 뒀다. 사용자가 지적했고
실측으로 확인했다 — 좌측은 이미 차 있다.
```
좌측  fixed left-0 top-44   현장 환경 패널   332 × 721px
우측  fixed right-5         배치 어시스턴트(LLM)  56 × 56
```
⟹ **참조 화면의 배치를 대상 화면의 성질로 읽었다.** 미니 월간·상세를 전부 우측으로 옮겼다.

## C-02 · 사진은 파일명이 아니라 시각+도로명으로 부른다
사용자 제안 = 주간 격자에 파일명을 놓고 클릭하면 우측에서 본다. **구조는 옳다**(썸네일을
40~50px 시간 칸에 넣으면 판독 불가). 다만 **라벨 소스가 성립하지 않는다.**
```
title      최근 5건 전부 (제목없음) · 과거는 "사진 촬영 증빙" 반복   → 구별 불가
ocr 첫줄   전부 "페이지 1"·"페이지 2"                            → 구별 불가
road_address  계림동 546-18 / 금남로3가 / 하남산단6번로            → ✅ 구별됨
시각       23:38 · 18:41 · 17:17 ×2 · 17:16 · 14:07             → ✅ 구별됨
```
⟹ 격자에는 묶음만, **구별 정보(시각·도로명)는 우측 목록**이 담는다.

## C-03 · 묶음 단위는 하루다 (시간 아님)
```
시간(1h) 단위 묶음   1건이 56% (14/25 시간대)  → 묶는 의미 없음·정보만 잃는다
하루 단위 묶음       평균 3.2건 · 최대 6건       → 묶는 값이 있다
```
하루 묶음은 시간이 없으므로 **종일 띠**에 둔다 — 6건이 14~23시에 흩어져 어느 칸에도 못 놓는다.

## C-04 · 월간 뷰를 남긴다
`주/월` 전환. 월간 격자는 2026-08-20 에 구글식으로 손봐서 잘 돈다(브라우저 실측 —
행 균등 [114×5] · 셀 비율 1.52 · 내부 스크롤 0 · 잘림 없음). 버리면 그 작업이 사라진다.

## C-05 · 헤더 아이콘·팝업은 걷어냈다 (선행 작업)
탭이 유일 진입점. ★ 아이콘이 달고 있던 **새 현장 사진 배지·토스트**를 함께 잃지 않도록
탭 이동(`gotoSignal`)으로 옮겼다. `calendarOpen` 의 의미도 "캘린더 탭 활성" 으로 이전.

## C-06 — 일정 클릭을 팝업에서 사이드바로 (2026-08-20)

**왜 팝업이 틀렸나.** 기능이 없어서가 아니라 **규칙이 둘이라서**다. 같은 격자에서
사진은 사이드바, 일정은 팝업이었다. 사용자는 사진에서 배운 규칙을 일정에 적용했고
화면이 다른 것을 했다. 게다가 수정은 사이드바 ✏️ 로 이미 갈 수 있어 **중복 경로**였다.
클릭 한 번이 편집 모드로 들어가는 것은 읽으려던 사람에게 되돌릴 것을 만든다.

**사진 구현을 그대로 본뜬다.** 새 패턴을 만들지 않는다 — `focusMediaId`/`scrolledForRef`
쌍이 이미 있고, 그 안에 **초점당 1회 스크롤**이라는 값비싼 교훈이 박혀 있다(폴링이 2초라
조건만 보고 스크롤하면 사용자가 아래로 내려도 계속 위로 끌려간다 · 같은 날 실측).

**초점 유지 판정은 `selectedEvents` 로 한다.** `eventsByDate[selectedKey]` 로 하면
**기간 일정이 걸친 날에서 즉시 초점이 풀린다** — 그 일정은 시작일 키에만 들어 있기 때문이다.
사진 쪽 이펙트를 그대로 복사하면 정확히 이 함정을 밟는다.

**기간 띠를 눌렀을 때 선택 날짜를 옮기지 않는다.** 시작일로 점프하면 8/16~8/22 일정을
8/20 에서 눌렀을 때 화면이 8/16 으로 튄다. 이미 걸친 날이면 그대로 두고 초점만 준다.

**deps 는 문자열 서명으로 준다.** `selectedEvents` 는 매 렌더 새 배열이라 deps 에 넣으면
이펙트가 매 렌더 돈다. `id` 를 이어 붙인 문자열이면 값이 같을 때 안 돈다.
