# 경로 정확도 필터(R-33) — 결정과 근거

- **상한 50m** — 오늘 84점의 위성 점 p90 ≈ 40m, 기지국 점 최소 93~100m. 그 사이 값. 정확도 고유값에 `100·200·300·1366` 처럼 딱 떨어지는
  값이 섞인 것이 기지국 추정의 지문이다(FUSED 공급자 · 08-26 실내 fix 0건을 고친 대가).
- **null 은 선에 남긴다** — 컬럼 도입 이전 행·애플 옛 행. 모르는 것을 나쁜 것으로 취급하면 이력이 통째로 사라진다(sanitizeTrack 원칙과 동일).
- **서버에서 가른다** — 지도는 그리기만. 분할 규칙이 한 곳(track.ts)에 살고, 응답은 additive(`coarse` 추가)라 옛 클라이언트는 그대로 동작한다.
- **원의 반경 = 보고된 정확도** — 줌을 바꿔도 지리적 크기가 맞다. 최소 4px 은 시각적 존재 보장.
- **캡션에 제외 사실을 적는다** — 점이 사라진 이유를 관제자가 알아야 "GPS 가 죽었다" 로 오독하지 않는다.
- 기각 = 워치 쪽 필터(ⓑ) 선행 — 표시 문제를 데이터 손실로 풀게 된다. ⓑ 는 "더 나쁜 fix 가 좋은 fix 를 덮지 않게" 로 별건.
