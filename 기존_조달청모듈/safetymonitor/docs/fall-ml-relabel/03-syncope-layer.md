# P-SYNC — 실신·무충격 붕괴 계층 (낙상 계획 통합)

> 출처 리서치: `dist/syncope-collapse-detection/index.html` (STORM 5관점·임상 1차 문헌 70여 건).
> 이 문서는 `00-plan.md`의 낙상 3분류 계획에 "충격 없는 쓰러짐(실신)" 계층을 얹는다.

## 왜 별도 계층인가 (코드로 확인)

`packages/analyzers/src/fall.ts:18-21` — 낙상 감지는 **`accel ≥ 임계 AND still ≥ 임계`** 로,
고G 충격과 무동작을 **동시에** 요구한다. 실신·서서히 주저앉음은 충격이 약하거나 없어 이 게이트를
**원리적으로 통과하지 못한다.** 게다가 `detectFall`은 死코드(CLAUDE.md: 실동작은 워치 `fallDetected`
플래그)라, 실신 감지는 "기존 무동작 알람 재사용"이 아니라 **고G에 종속되지 않는 독립 무동작 감시
계층을 새로 만드는 것**이다. (동료평가 "가장 약한 고리"의 코드 검증 결과)

## 핵심 결론 (리서치 5관점 수렴)

1. 실신은 단일 이벤트가 아니라 **상태 사슬**: 전조 → 자세 붕괴 → 무동작 → 응답 실패.
2. 검증된 종착 구조는 **무동작 감지 + 사용자 취소 + 관제 응답 루프**(PERS 50년·상용 4사 수렴).
3. 손목 PPG로 실신 "예측"은 함정 — 실신 순간 말초 저관류로 PPG 신호가 붕괴. 예측은 예방 알람 보조층으로만, 자동 출동엔 금지.
4. 단일 심박 임계(서맥)로는 못 가름 — 혈압 주도형·열실신을 놓침.

## ★ 이 시스템의 명시적 천장 (과대약속 방지)

우리는 **혈압·뇌관류를 측정하지 못한다**(손목 IMU+PPG만). 따라서:
- **혈압 주도형 실신**(서맥 없이 저혈압), **무전조 심장성 실신**(수 초 내 방실차단)은 **원리적으로 감지 불가**.
- 목표는 "실신 완벽 감지"가 아니라 **"무응답 사건을 놓치지 않기"**.
- 표현도 "실신 확정"이 아니라 **"무응답/무충격 붕괴 감지"**로 낮춘다(의료기기 규제·법적 책임 회피).

## 라벨 확장 (01-label-spec.md 에 추가)

기존 낙상 3분류(작업충격/넘어짐/추락)에 **충격 없는 경로**를 별도 축으로 추가:

| primary_label | 정의 | 결정 신호 |
|---|---|---|
| `presyncope` | 의식 있는 전조(어지럼·시야흐림·메스꺼움) — 자기 신고 or 사후 문진 | SOS 자기신고, HR/HRV 이상(신호품질 양호 시) |
| `no_impact_collapse` | 충격 없이 주저앉음·미끄러짐·기댐 후 무동작 | 저G + 장시간 무동작 + 자세 변화 |
| `post_event_immobility` | 사건(충격/무충격) 후 지속 무동작 | motion_still_sec 지속 |
| `non_event_immobility` | 정상 무동작(휴식·앉은작업·기대기) — 음성 | 취소됨 / 정상 맥락 |

신호품질 라벨(별도): `ppg_dropout`, `device_off_body` — PPG 끊김을 "서맥"으로 오해 방지.
심각도(기존과 공유): `recovered` / `collapsed`.

## 계층 구조 (통합 최종)

```
[충격 경로]  고G 게이트 → 회전 3분류(작업충격/넘어짐/추락)      ← 기존 낙상 계획 P0~P4
[무충격 경로] 저G + 장시간 무동작 + 자세변화 → no_impact_collapse  ← 신설 독립 계층
     둘 다 ↓
공통 응답 루프:  무동작 확인 프롬프트 → 취소 or 무응답 → 관제 escalation
     +
자기신고 채널:   SOS 버튼 "어지러움/쓰러질 것 같음" → 예방 경보 + 위치
     +
열 맥락 결합:    WBGT/체온 위험(기존 폭염 시스템) AND 무동작 → heat-context possible collapse
```

## 데이터 (파이프라인 검증용, gold label 아님)

PhysioNet 후보 — 양성 실신 학습셋이 아니라 **정상 자세반응·신호품질 음성 기준선** 검증용:
- PRCP (자세 변화 정상 HR/ABP 반응)
- Pulse Transit Time PPG (PPG+IMU 19채널 동기 — 신호품질 QA)
- Cerebral Vasoregulation in Diabetes/Stroke (HUT 59·120건 ECG+ABP)
- Two-tiered orthostatic response (정상 기립 대조군)

## 우선순위 (낙상 계획과의 순서)

- **S2(자기신고)·S3(열맥락)는 지금 즉시 가능** — 새 데이터·새 모델 0, 기존 자산 조합. 가장 싸고 확실.
- **S1(독립 무동작 계층)은 낙상 P4(계층형 판정기)와 함께** — 같은 무동작 로직 근처.
- **S4(라벨)는 낙상 재라벨링에 흡수** — 워치 수집 시 실신 클래스 동시 라벨.
- **S5(PPG 예측)는 로드맵** — 현장 오경보 로그 축적 후 오프라인 연구.
