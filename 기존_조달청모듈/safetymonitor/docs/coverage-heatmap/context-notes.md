# 수집 커버리지 히트맵 — 결정과 근거

## H-01 · 칸 값으로 다른 후보를 쓰지 않은 이유

| 후보 | 판정 |
|---|---|
| **수집 커버리지(분/일)** | ✅ 채택 — 항상 있고, 우리가 실제로 겪는 문제(관측 공백)에 직접 답한다 |
| 활동 에너지 kcal | ⛔ **4배 과대**라 표시 금지 가드가 이미 걸려 있다. 히트맵에 넣으면 그 가드를 우회하는 셈 |
| 평균 심박 | ⛔ 하루 착용 시간이 2,101행~11,501행으로 **5배** 차이라 평균이 착용 시간에 끌려간다 |
| 걸음 수 | △ 실측이지만 **5,566행에만** 있어 칸이 대부분 빈다 |
| 경보 건수 | △ 거의 0이라 히트맵이 통째로 비어 보인다 |

## H-02 · "분 단위 distinct" 로 재는 이유

시간 단위(`COUNT(DISTINCT hour)`)로 재면 **한 시간에 샘플 하나만 와도 그 시간이 꽉 찬 것으로** 계산된다 — 정체·버스트가 잦은 우리 데이터에서 커버리지를 과대평가한다.

워치는 **분당 12건**을 보내므로 "그 분에 샘플이 하나라도 있었다"는 실제로 수집된 분이라 볼 수 있다. 그래서 `COUNT(DISTINCT date_trunc('minute'))` 로 재고 0~1440 을 얻는다. 화면에는 시간으로 환산해 적는다.

## H-03 · ★★ 빈칸 세 종류를 가른다 — 이 트랙의 핵심

GitHub 히트맵은 **"기여 0건"과 "그날이 없음"을 같은 연회색**으로 그린다. 우리에겐 그게 이 레포가 반복해 고쳐 온 **false-OK** 다 — **미수신이 "활동 없음"으로 읽힌다.**

1년 창에서는 여기에 세 번째가 붙는다. 사용자 계정 기준 **365칸 중 39칸(11%)만 채워지고**, 빈 326칸의 대부분은 *"그날 미수신"* 이 아니라 **애초에 이 시스템이 없던 날**이다. 그걸 미수신으로 칠하면 없는 사고를 326건 그리는 것이다.

```
운영 이전   첫 수집일 이전            무채색 · 아주 옅게      "운영 이전"
미수신     운영 기간 중인데 데이터 0   빗금 + 점선 테두리      "미수신"
수집됨     분 > 0                    5단계 색 강도           "N시간 M분"
```

`heat-pattern.ts` 의 *"판정 불가(null) ≠ 정상(false)"* 과 같은 처방이고, **히트맵은 한 화면에 수백 칸이라 이 구분이 없으면 오독이 수백 배가 된다.**

## H-04 · 1년 범위는 사용자 결정이다

권고는 8~12주였다(현재 채움률 12주 46% vs 1년 11%). 사용자가 1년으로 결정했고 그대로 간다. 대신 H-03 의 3상태 구분이 **권고안일 때보다 더 중요해진다** — 빈칸이 압도적이라 그 빈칸의 의미가 화면의 주 메시지가 되기 때문이다.

측정 근거(2026-08-17).

| 워커 | 관측일/기간 | 관측률 |
|---|---|---|
| EMP-admin6861 | 33 / 47 | 70% |
| EMP-admin3470 | 16 / 25 | 64% |
| EMP-6861 | 10 / 53 | 19% |
| 사용자 계정(별칭 병합) | **39 / 53** | 74% |

전체 데이터는 2026-06-23 에 시작한다 — 그 이전은 어떤 워커도 "운영 이전"이다.

## H-05 · 색 단계는 교대 시간을 기준으로 자른다

균등 분위수로 자르면 데이터가 적을 때 경계가 매일 바뀌어 **어제와 오늘의 같은 색이 다른 뜻**이 된다. 8시간 교대라는 고정 기준이 있으므로 절대 임계로 고정한다.

```
1단계  0 초과 ~ 1시간      잠깐 켜졌다
2단계  1 ~ 4시간
3단계  4 ~ 8시간
4단계  8 ~ 12시간          교대 1회분
5단계  12시간 초과
```

## H-06 · 서버 부하

한 워커 1년치를 `date_trunc('minute')` + `GROUP BY` 로 훑는다. 현재 최대 워커가 24.5만 행이라 문제없지만 **행이 자라면 이 쿼리가 가장 먼저 무거워진다.** 인덱스 점검 트리거(인덱스합 150MB)에 이 쿼리도 함께 본다.

## H-07 · 표시 전용이다

커버리지가 낮은 날을 **알림으로 올리지 않는다.** 이 값은 "감시가 얼마나 됐나"이지 작업자 상태가 아니고, 알림으로 만들면 퇴근·휴일마다 울린다. 근무 시간 개념이 생기기 전에는 판정 경로에 넣지 않는다([gps-phone-collection](../gps-phone-collection/context-notes.md) G-07 과 같은 이유).
