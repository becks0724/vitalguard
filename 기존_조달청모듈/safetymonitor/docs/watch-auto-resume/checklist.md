# 워치 자동 재개 — 체크리스트

목표 = **"자동 재개가 왜 한 번도 안 걸렸나" 를 추론이 아니라 관측으로 답한다.**
근거·결정 = [context-notes.md](./context-notes.md) R-01~R-08.

성공 기준 — 다음 세션 종료 **1회**에서 R-05 의 네 지문 중 하나가 DB 에 찍힌다.
찍히지 않으면 계측이 실패한 것이고, 그때는 계측부터 고친다(가설을 바꾸지 않는다).

## 0단계 — 착수 전 재확인

- [ ] 현재 `session_auto_resumed` 가 여전히 전건 0 인지 재조회(그 사이 발동했으면 트랙 성격이 바뀐다)
- [ ] 설치된 워치 빌드에 `autoResume` 이 실제로 있는지 바이너리로 확인
      ⚠ `strings` 로 한글 문자열을 찾지 말 것 — Swift 는 15바이트 이하를 인라인한다(L-67).
      충분히 긴 기존 문자열을 **통제군**으로 함께 잡는다

## 1단계 — 서버 (먼저 배포해 둔다 · R-08)

- [ ] 스키마 4필드 — `sessionEndSeenAt` · `sessionEndByUser` · `sessionResumeTriedAt` · `sessionResumeGaveUp`
- [ ] DB 컬럼 4개 `ALTER TABLE … ADD COLUMN IF NOT EXISTS`
- [ ] insert 매핑 4개 — **트리오가 함께 가야 한다**(R-07)
- [ ] 스트립 허용목록 등록 — 빠뜨리면 샘플 전체가 거부된다
- [ ] `ExportRow` 에는 **넣지 않는다** — 진단 필드다. 빠뜨린 것이 아니라 뺀 것이므로 가드로 못 박는다
- [ ] 가드 — 트리오 3자 동시 존재 · 허용목록 포함 · ExportRow 제외 · **판정/경보/화면 무유입**
- [ ] 음성 대조 — 각 결함이 자기 가드만 실패시키는지(기준선 같은 실행에 출력)
- [ ] `/verify` 3종 → 사용자 `/deploy`

## 2단계 — 워치 계측 (설치 기회에 얹는다)

- [ ] `.ended` 델리게이트 **진입 즉시** UserDefaults 에 `endSeenAt`·`endByUser` 기록
      ★ 중첩 클로저 **바깥**이어야 한다 — 그 안에 두면 H1 을 관측할 수 없다(의심 대상 그 자리다)
- [ ] `autoResume()` 진입 즉시 `resumeTriedAt`, 포기 시 `resumeGaveUp` 기록
- [ ] 다음 세션 첫 배치에 네 값을 실어 보내고 **보낸 뒤 지운다**(다음 세션에 옛 값이 새지 않게)
- [ ] `didFailWithError` 경로에도 같은 기록(경로별로 갈리는지 봐야 한다)
- [ ] `xcodebuild` VitalWatch Release BUILD SUCCEEDED · 내 파일 경고 0
- [ ] 설치 → 사람이 [시작] → 첫 배치에 필드가 실제로 오는지 DB 확인

## 3단계 — 판정 (관측 대기)

- [ ] 세션 종료 1회 관측 → R-05 표로 H0~H3 중 하나로 확정
- [ ] 결과를 context-notes 에 R-09 로 기록(추측 금지 — 지문 그대로)

## 4단계 — 처방 (판정 뒤에만 착수)

- [ ] **H0** → 고칠 것 없음. 질문이 "왜 사람이 중지를 누르는가" 로 바뀐다
- [ ] **H1·H2** → ⓐ 재개를 중첩 콜백 밖으로 ⓑ 활성화 시 자가 복구(R-06)
- [ ] **H3** → 포기 조건 재검토(3회·60초가 맞는 값인지 실측으로)
- [ ] 처방 후 **자동 재개 첫 발동을 실제로 관측**해야 완료다 — `session_auto_resumed = 1` 이
      DB 에 한 번이라도 찍힐 때까지 이 트랙은 열려 있다

## 열린 위험

- ⚠ 워치 설치는 세션을 끊고 자동 재개되지 않는다 — **매 설치마다 사람이 [시작]** 을 눌러야 한다
- ⚠ 재서명 만료 08-25(캐시 삭제 후 Run 하면 08-27) — 설치를 그 창에 묶으면 비용 0
- ⚠ 이 트랙은 **원인 규명이지 피해 제거가 아니다.** 규명 전까지 세션이 끊기면 여전히 사람이
      알아채야 한다. 알아채는 수단 = 설정 화면 `워치 수신 끊김 — N분 전`(08-20 추가).
      그것도 사람이 열어 봐야 보인다 — **푸시 알림은 아직 없다**
