2. 취약점 (Security)

MEDIUM · M1. 미인증 GET /api/mock/vital — 작업자 PII 평문 노출
보안 · apps/dashboard-web/app/api/mock/vital/route.ts:12-19
export async function GET() {
  return NextResponse.json({
    latest: latestByWorker(),   // guardianName, guardianPhone, latitude, longitude 포함
    recent: recentSamples(),
    totalPersisted: totalPersisted(),
    countsByWorker: countsByWorker(),
  });
}
모든 /api/admin/* 라우트는 verifyBasicAuth를 거치지만 이 GET은 인증이 전혀 없다. 반환값에 보호자 이름·전화, 위·경도, 작업자 이름이 그대로 실린다(스키마 vital-stream.ts:17-20). dev 서버가 공개 *.trycloudflare.com 터널로 노출되므로 URL만 알면 누구나 실시간 작업자 위치·보호자 연락처를 무인증 조회할 수 있다.
MEDIUM 근거: 합성/직원 데이터 + 세션마다 회전하는 추측불가 임시 URL. 실서비스·고정 URL이면 HIGH.
보완 GET에 verifyBasicAuth 적용, 또는 공개 응답에서 PII 필드(전화·좌표·이름) strip 후 인증 요청에만 전체 제공. 최소 터널 공유 시크릿 헤더.
MEDIUM · M2. 기본 관리자 자격증명 admin / safety2026 보안 + 의존성 독립 2회 검출
보안·의존성 · apps/dashboard-web/lib/admin-auth.ts:5-7
const ADMIN_ID = process.env.ADMIN_ID ?? "admin";

ADMIN_PASSWORD 미설정 시 코드가 "safety2026"으로 fallback. .env.example도 빈 placeholder가 아니라 실동작값을 그대로 출하(같은 파일 KOSHA_SERVICE_KEY=는 비어 있는 것과 대조). 이 자격증명이 보호하는 /api/admin/export(CSV: guardian_phone·heart_rate·spo2·latitude·longitude)·export-xlsx·workers·site-info가 공개 터널에서 리포지토리에 적힌 비밀번호로 접근 가능.
MEDIUM 근거: 터널 활성 + env override 미설정이 동시 성립해야. 인증 자체는 timingSafeEqual 사용. 문서상 의도된 프로토타입 동작이나 노출은 실재.
보완 .env.example은 빈 placeholder로, 코드 fallback은 미설정 시 fail-closed(throw/인증거부). 소스에 리터럴 기본값 출하 금지.

토큰이 곧 평문 비밀번호이며 sessionStorage에 저장 후 매 요청 재생된다. XSS·확장프로그램이 읽으면 관리자 비밀번호가 영구 복원되고, 별도 폐기 가능 세션이 없다.

MEDIUM · M4. dashboard tsconfig.json이 base 미상속 → noUncheckedIndexedAccess 누락
타입 안전성 · apps/dashboard-web/tsconfig.json
tsconfig.base.json은 noUncheckedIndexedAccess: true를 켜고 packages/analyzers·schemas는 이를 extends한다. 그러나 dashboard tsconfig는 extends 없이 옵션을 처음부터 정의해 strict: true만 있고 이 플래그가 빠졌다. 데모가 실제 렌더하는 가장 큰 런타임 표면에서 모든 배열 인덱스 접근이 타입 미검사가 된다.
예: VitalHistoryPanel.tsx:366 points[idx].label, typhoon.ts:185 group[0]이 definitely-present로 취급(오늘은 in-range지만 off-by-one/빈배열 회귀를 못 막음).
보완 dashboard tsconfig를 "extends": "../../tsconfig.base.json"로 하고 Next.js 옵션만 override(또는 noUncheckedIndexedAccess: true 명시).
