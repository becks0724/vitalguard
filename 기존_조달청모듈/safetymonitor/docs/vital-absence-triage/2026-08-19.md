## 2. ★★★ `mv` 착용 판별 **기각** — 통제군 실측

| 구간 (유효 표본 = `still` ≥ 70초) | n | mv |
|---|---|---|
| 착용 + 완전 정지 | 44 | **1 ~ 5** |
| 책상 (미착용 + 정지) | 23 | **1 ~ 3** |

**완전히 겹친다.** 12:04 에는 착용 바닥이 **1** 까지 내려가 책상 최소값과 같아졌다.

- ★ **메커니즘** — `mv` 는 표준편차라 **이상치에 지배**된다. 스파이크 1개(0.40g)가 창에 남은
  60초 동안 mv≈51 을 만들고, 빠지면 0 이 된다(산술 재현 일치). ⟹ **큰 값 = "최근 60초 내
  움직임" = `motion_still_sec` 과 중복.** 착용 정보는 바닥에만 있는데 그 바닥이 겹친다.
- ★ 중간에 봤던 **"착용 바닥 4~6" 은 수렴값이 아니었다** — 전부 `still` 60~74초 구간의
  **정착 꼬리**(임계 0.03g 미달 미세 움직임 잔재)였고, 70초를 넘기자 2 로, 2분 뒤 1 로 내려앉았다.
- ★ **MAD·소수 자릿수 보존도 못 구한다** — 물리 신호 자체가 책상과 1~2 밀리g 차이라
  응답 속도(60초 대기 제거) 개선일 뿐 분리가 생기지 않는다.
- ⚠ **화면에 썼다면 안전 역전이었다** — 가만히 있는 착용자와 책상 위 워치가 같은 값이므로
  **쓰러진 작업자의 화면이 "미착용" 으로 바뀐다.** 본인이 보는 화면이라 관제 false-OK 보다 나쁘다.
  아침에 걸어 둔 "판정·경보·화면 금지" 가드가 임시 조심에서 **실측 근거를 가진 영구 규칙**이 됐다.

**처분** — 착용 판별 용도 기각. 수집은 유지(코드 변경 0). `mv` 는 **움직임 강도**는 잘 잰다
(정지 2 ↔ 평상 30~100 ↔ 격렬 334). `still` 이 이진인 데 비해 강도를 주므로 온열 활동 축·
작업 강도 재료로 남긴다. **착용 판별은 대리 신호로 못 푼다 — 08-18 결론으로 회귀.**

> 부수 관측 — 의도적 정지 10분 중에도 불수의 미세 조정이 1~3분마다 임계를 넘어 `still` 이
> 리셋됐다(최장 무중단 172초). 책상은 리셋 없이 275초+ 단조. "still 연속 길이" 가 후보처럼
> 보이지만 **의식 잃은 작업자도 긴 연속을 만들어** 같은 안전 역전을 가지므로 제안하지 않는다.

## 3. `mv` 사슬 재검증 — "벗음 → 심박 끊김 → 행 없음" 은 성립하지 않는다

사용자 요청으로 재확인한 결과, 오전에 제가 세운 사슬의 **두 고리가 틀렸다**.

1. **벗어도 심박이 안 끊길 수 있다** — `WatchStreamer.swift:131` 의 08-15 실측(벗은 채 70분간
   68~78bpm 지속·고유값 11개). **`HKWorkoutSession` 활성 중에는 watchOS 가 PPG 를 연속 가동**해
   손목 접촉에 게이트되지 않는다. 그 값은 측정이 아니라 **PPG 잡음 고착**이다.
2. 우리 코드에 "일정시간 못 재면 끊는" 능동 로직은 **없다**(수동 수신 + 반대 방향의
   `heartbeatMaxAge=30초` 값-복사-방지 만료뿐).
3. **심박이 끊겨도 행은 생긴다** — `still`·에너지 단독 행(실DB 36h: 심박 NULL 35건 =
   ae 30 + still 8 + stp 2).
4. `mv` 가 안 실리는 것은 행 부재가 아니라 **bpm 행에만 얹는 게이트**(`:414`) 때문 — 계약상 선택.

★ **심박 소스가 워크아웃 빌더 하나뿐**(`hrType` 사용처 전수 = `:80` 정의 · `:256` 권한 ·
`:799` 빌더)이므로, **우리 DB 에 심박이 있다는 것 자체가 세션 생존의 증거**다.

★ **"벗으면 수집을 끊는 게 정상 아닌가"(사용자 질문)** — 두 겹으로 불가하다.
① watchOS 는 서드파티에 손목 접촉 API 를 주지 않는다(세션 중 연속 가동은 밴드 느슨·일시
접촉불량에서 끊김을 막으려는 애플의 설계). ② 안전 도메인에서 "미착용 추정 → 수집 중단" 은
판별이 틀렸을 때 — **쓰러져 안 움직이는 작업자 = 저변동** — 가장 위험한 순간의 데이터를 우리
손으로 끊는다. ⟹ 정상 로직 = **수집 유지 + 신뢰도 라벨**(관제가 "정상" 대신 "미착용 추정").

## 계측 구현 계약 (다음에 필드를 추가할 때 재사용)

오늘 추가한 3필드(`sessionStartedAt`·`sessionAutoResumed`·`motionVariabilityMg`)가 지킨 규칙.
**하나라도 빠지면 값이 조용히 사라진다.**

1. **트리오를 함께 넣는다**(BND-CONTRACT-01) — Zod 스키마 · DB 컬럼(`ALTER TABLE … IF NOT
   EXISTS`) · insert 매핑. 셋 중 하나만 빠져도 필드가 무음으로 버려진다.
2. ⚠ **스트립 허용목록(`NON_SAFETY_STRIPPABLE_KEYS`)에 넣는다** — 기본값이 "샘플 전체 거부" 라
   **진단 필드 하나가 범위를 벗어나면 그 행의 생체를 통째로 날린다.** 순수 관측값은 버려도
   안전하므로 허용목록이 맞다.
3. ⚠ **`ExportRow`(CSV 내보내기)에는 넣지 않는다** — 진단 필드이지 사용자에게 주는 값이 아니다.
   빠뜨린 게 아니라 뺀 것이라 가드로 못 박았다.
4. **못 잰 것은 0 이 아니라 키 생략** — `mv` 는 창이 60개 미만이면 키를 뺀다(`motionStillSec`
   과 같은 규칙). "변동이 없다"(0)와 "못 쟀다"(없음)를 가른다.
5. **심박 항목에 얹고 단독 행을 만들지 않는다**(`lastIndex(where: bpm)`) — 단독 행은 배치 내
   `ts` 중복으로 서버가 조용히 버리고, "생체는 없는데 진단만 있는 행" 이 미수신 판별을 흐린다.
   ⚠ **그 대가가 §3 에서 드러났다** — 심박이 없는 구간에는 `mv` 도 없다. 예외는 `motionStillSec`
   으로, 그 값은 벗어둔 구간이 핵심 용도라 단독 행을 허용한다.
6. **판정에 올리지 않는 필드는 금지 가드를 앵커와 함께 건다** — `severity.ts`·`telegram.ts`·
   `worker-signal.ts`·`DemoDashboard.tsx` 넷을 길이 앵커까지 검사한다(파일이 비면 금지가 조용히
   통과하는 것을 막는다). ★ `mv` 기각으로 **이 가드가 실제로 사고를 막은 것이 증명됐다.**

ⓑ 델리게이트는 불렸는데 `autoResume` 이 건너뛰어졌다(`byUser` 가 참이어야 하는데 그럴 경로가
   코드에 없다 — `stopRequestedByUser = true` 는 `stop()` 안 한 곳뿐)
가르려면 워치 `os_log` 가 필요한데 도달 불가다. **다만 조치는 둘 다 같다** — 워치 델리게이트에
기대는 구조로는 안 되고, **폰이 공백을 감지해 워치를 깨우는 별도 경로**가 필요하다.

★ **부수 — 부재 알림이 전 주기를 완주했다.** 발화(15:30) → **해제(15:35)** 가 텔레그램 실물로
찍혔고 사후 판정이 **"수집이 멈춰 있었다"** 로 정확했다(전달 단절 아님). 오늘 아침 김태곤 건으로는
못 본 해제 경로가 관측됐다. **이 알림이 없었으면 15:16 끊김을 아무도 몰랐다.**

⚠ 세션 2가 **16분** 만에 죽은 것은 §4-5 의 "5분 만에 죽고 · 11배 편차" 와 같은 계열이다.

## 방법론 교훈 (이 세션에서 실제로 밟은 것)

1. **도구가 낸 빈 결과를 대상의 성질로 읽지 않는다** — `system_profiler SPUSBDataType` 이
   아이폰뿐 아니라 **허브·수신기까지 전부** 0 을 냈는데 "기기가 없다" 로 읽었다. `ioreg` 로
   바꾸니 통제군(벨킨 허브·무선 수신기)이 잡혔다. 하루에 세 번 밟은 형태다(L-67).
2. **라벨은 데이터에서만 잡는다** — "다시 착용 완료" 메시지 시각으로 착용 구간을 추정해
   "착용한 채 25초 연속 mv=1" 이라 적었으나, 데이터의 착용 서명은 2분 뒤였다. 라벨 미상으로 정정.
3. **두 변수가 함께 바뀐 비교는 판정이 아니다** — "책상 1 vs 착용 64.5" 는 착용 여부와
   움직임을 **교락**시킨 비교였다. 옆 세션 지적으로 판정을 철회하고 통제군을 다시 잡았다.
4. **통제군은 실험 안에도 필요하다** — `nm` 심볼 검증에서 신규 심볼만 봤다면 "0건 = 코드 없음"
   으로 오판했을 것이다. 기존 심볼을 함께 재서 도구 유효성을 먼저 세웠다.
