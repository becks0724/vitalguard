# idea.md — VitAlGuard (4축 통합판)

> 2026-06-17 갱신. 부문: **아이디어 기획 + 동작 구현(PoC)**. 마감 2026-06-19 18시.
> 대회: 2026 공공조달데이터·AI 활용 창업경진대회(조달청).
> 이력: 안전조달(발주단계 위험선별) → VitAlGuard(안전관리비 실집행 검증). 3축 → **4축**(증액 검증 추가).

## 0. 한 줄 정의

**VitAlGuard** = 조달청·국세청 공공데이터 + 웨어러블 IoT로
**건설현장 안전관리비가 "장부가 아니라 작업자에게 실제로 도달했는가"를 계상·사용·실집행·증액 4단계로 교차검증**하는 플랫폼.

## 1. 출발점 (방향 정렬)

- safetymonitor는 **착공 후** 현장을 관제(웨어러블 생체·GPS). 그 위에 조달 데이터를 얹어 **안전관리비 집행을 검증**한다.
- 조달 데이터는 **입찰공고(발주 전)** 가 아니라 **계약(체결=진행 중 현장)** 을 핵심으로 쓴다 → 이미 돌아가는 현장과 정합.
- 기존 SafeProcure 자산(`safety-cost.ts` 공사종류×대상액 요율 = 법정 계상 기준)은 **①계상축으로 재활용**.

## 2. 4중 교차검증 (핵심 설계)

| 축 | 데이터 출처 | 검증 질문 | 구현 |
|---|---|---|---|
| **① 계상(예산)** | 조달청 계약정보(15129427) + `safety-cost.ts` 요율 | 안전관리비가 고시 기준대로 계상됐는가 | ✅ |
| **② 사용(지출)** | 국세청 사업자 상태조회(15081808 status) | 세금계산서 발급처가 정상(계속)사업자인가 | ✅ |
| **③ 실집행(물증)** | 웨어러블 출역·GPS(`vital_samples`) | 안전인력이 실제 투입·가동됐는가(worker-day) | ✅ |
| **④ 증액(변경)** | 계약변경이력(15129427) + 관리자 입력 + ③실인원 | 계약 후 증액 청구가 실인원에 비춰 타당한가 | ✅ |

## 3. 핵심 유스케이스 — 유령 인원 과다청구 적발 (킬러)

**시나리오**: 현장 실인원 7명(웨어러블 착용·신원확인 일용직 포함)인데, 시공사가 **10명분** 안전장비(안전모·안전화) 비용을 청구.

- **부정 수법**: 사진 증빙은 같은 사람을 색·장비 바꿔 입혀 찍으면 **사람 수를 못 센다** → 속이기 쉽다.
- **우리 무기**: 웨어러블은 개인별 생체신호 + 신원확인(주민등록증)이라 **1기기 = 1실존인물**, 같은 사람을 중복 카운트 못함 → **실인원은 못 속인다.**
- **산출**: `과다액 = Σ max(0, 청구수량 − 실측인원) × 단가`
  - 예: (10−7)×안전모 25,000 + (10−7)×안전화 60,000 = **255,000원 과다 산정**.
- **판정**: 청구/실측 비율 >1.5 의심 · >1.2 주의 · 그 외 정상 · 증빙·실측 없으면 검증불가.

## 4. 핵심 산식

- **실집행 환산**: `계상액 ÷ 누적 worker-day = 1인·1일당 명목 안전예산`
- **과다 산정**: `Σ max(0, 청구수량 − 실측인원) × 단가`
- **증액 정당성**: 인력 증가율 vs 청구 증가율 (인력 정체인데 청구 급증 → 의심)

## 5. 자산 vs 신규

- **재활용**: `safety-cost.ts`(요율→계상액), 조달 OpenAPI 연동, 웨어러블 생체·GPS(`vital_samples` DB 영속), 관제 플랫폼.
- **신규**: 워치 출역 집계(worker-day·distinctWorkers), 국세청 상태조회, **실인원 vs 청구 과다분 산출**, 4축 통합 화면.

## 7. 부문

**아이디어 기획 + 동작 구현(PoC)**. 풀 상용화가 아니라 **"한 현장 PoC로 안전관리비 누수·과다청구를 정량 적발"** 시연이 핵심.

## 8. 정직성 / 한계 (과장 금지)

- 웨어러블 출역은 **데모데이터**(실 현장 미착용) → "검증 로직 데모"로 표기.
- 안전관리비 **세목은 어느 OpenAPI에도 없음**(원가계산서 첨부) → ②④는 **관리자 입력 보강**.
- 실인원 검증 성립 전제: 전원 착용 의무화 + 1기기=1신원(운영 정책 영역).
- 적정성의 **최종 판정은 발주처·감독기관 권한** — 우리는 리스크 기반 사전 스크리닝(추정·보조).
