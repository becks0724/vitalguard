# 하드웨어 섹션 — 현장 설치 물리 장치

VitAlGuard의 현장측 하드웨어 2종. 둘 다 관제서버(대시보드)와 연동된다.

| 장치 | 역할 | 플랫폼 | 위치 |
|---|---|---|---|
| **AED 알람 장치** | AED 상태(배터리·패드 교환주기)를 현장에서 빛·소리로 경보 | Raspberry Pi | [`AED_alarm/`](AED_alarm/) |
| **가스포드 (GasPod)** | 밀폐공간 가스 감지(O₂·CO·H₂S) + 온습도, 현장 경보 + 서버 전송 | ESP32-S3 | [`../Final_GasPod/`](../Final_GasPod/) |

## AED 알람 — 요약
관제서버 8초 폴링 → CLEAR/WARNING/DANGER를 LED 2색 + 부저 4개 순차 사이렌으로 표시.
강제활성화 버튼(1분 래치)·전원 스위치·systemd 자동시작. 상세: [`AED_alarm/README.md`](AED_alarm/README.md)

## 가스포드 v4.2 — 요약 (빌드 기준: `../Final_GasPod/가스포드_v4.2_종합.md`)
- 센서: SEN0322(O₂, I2C) · MQ-7(CO) · MQ-136(H₂S) · BME280(온습도·기압)
- 전원: 삼성 30Q 2셀 → V9 승압(5V) — 구동 7~8h, 펌웨어 배터리 감시(3.2V 경고/3.0V 종료, GPIO7 배터리단 분압)
- 경보: 부저 + LED 2색 + ACK 버튼(음소거·LED 유지), 진동모터는 v4.2에서 제외
- 케이스: 세로 4칸 아크릴 타워(180×113×195, 5T) 완성
- ⚠️ 표현 제한: 교육용 프로토타입 — 정량 ppm·산업안전 인증(검교정/방폭/IP) 주장 안 함
- 서버 연동: `../Final_GasPod/1_엔드포인트_구현가이드.md` · `2_대시보드_데이터명세.md` 참조

> `Final_GasPod/`는 팀 참조 경로 유지를 위해 루트에 그대로 두고 여기서 링크한다.
