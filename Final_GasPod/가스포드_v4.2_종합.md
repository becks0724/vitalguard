# 가스포드 회로 v4.2 — 종합 (실물 반영: 배터리 2셀 · 진동모터 제외 · 케이스 완성)

> **표현 제한:** 교육용 프로토타입. 정확 ppm 정량·산업안전 인증(검교정/방폭/IP)을 주장하지 않습니다. SPICE/CFD 미수행, 옴/RC 1차 해석 기반. EDA 정밀 스키매틱 아님.

> **작성 근거:** v4.1 종합(`가스포드_v4.1_종합.md`) + 실물 재고·케이스 완성 반영 + 적대적 검증(2026-07-05) 결과.
> **대상 보드:** ESP32-S3-WROOM-1 **N16R8** (확보 완료)
> **변경 범위:** 실물 반영 4건(§0) — 5V 레일 이후 회로 토폴로지·펌웨어 구조는 v2 유지.

### v4.1 → v4.2 변경 4건 (적대적 검증 반영)

| # | 변경 | 이유 |
|---|---|---|
| 1 | **배터리 30Q ×4 → ×2** (실보유) | 4셀 미확보. 21.6Wh ÷ 2.52W ≈ **명목 8.6h, 보수 7h** (17~20h 아님). V9=1S병렬이라 2셀 동작 OK — **장착 전 두 셀 만충으로 전압 매칭 필수** |
| 2 | **GPIO7 분압 탭: 5V단 → V9 배터리 베이 (+)단자** | 부스트는 셀이 죽기 직전까지 5V 유지 → 5V단 측정은 저전압을 감지 못함. 비보호셀에서 펌웨어 전압감시가 사실상 유일한 과방전 보호 |
| 3 | **진동모터(MB-0903V, GPIO11) 제외** | 3V 정격 모터를 5V 레일로 과구동(duty 80%도 실효 4V). 부저+LED로 경보 충분 — 실패 모드 제거. 1N5819·GPIO11·2.0kΩ 1개분 미사용 |
| 4 | **케이스 = 완성** | 세로 4칸 타워(180×113×195+보스35, 5T 아크릴) 재단·조립 완료. 남은 것은 전자부 장입·UI 패널 마운트뿐 |

## 1. 전원부 (v4.2 확정)

- **구성:** 삼성 30Q(비보호·플랫탑 65mm) **×2** → V9 실드(1S병렬, 5V/3A 승압) → 5V 레일
- **에너지:** 2 × 3.0Ah × 3.6V = **21.6Wh** / 부하 2.52W → **명목 8.6h · 보수 ~7h**
- **충전:** V9 USB in-place. 셀 2개뿐이라 셀당 충전전류 여유(≤1.5A/셀 준수). **미충전 배송 → 빌드 첫날 아침 충전 시작**
- **안전(비보호셀):**
  - V9 저전압컷 신뢰 불가 전제 → **펌웨어 감시: 3.2V 경고(LED+부저 패턴) / 3.0V 안전종료**
  - 측정: **V9 배터리 베이 (+)단자 → 100k/100k 분압 → GPIO7** (4.2V→2.1V, ADC 안전)
  - 2셀 병렬 장착 전 **만충 매칭** (전압차→셀간 돌입전류 방지)

## 2. 회로 구성 (v4.2)

| 구간 | 구성 | 비고 |
|---|---|---|
| 보드 | ESP32-S3-WROOM-1 N16R8 | 확보 |
| I2C | GPIO8(SDA)/GPIO9(SCL) — SEN0322(0x73)·BME280(0x76, SDO=GND) | VCC=3.3V 레일 |
| MQ ADC | MQ-7→GPIO1, MQ-136→GPIO2 · 5V 가열 · **10k직렬/20k접지 분압 + 0.1µF** | 분압 없이 직결 금지(ADC 손상) |
| 부저 | S8050, Rb 2.0kΩ, 100kΩ 풀다운, **GPIO10** | 능동부저 |
| ~~진동모터~~ | **v4.2 제외** (GPIO11·1N5819 미사용) | 3V 정격·5V 과구동 리스크 |
| LED·버튼 | 빨강 GPIO4 / 노랑 GPIO5 (각 330Ω) · ACK버튼 GPIO6 + 0.1µF (내부풀업, 누르면 LOW) | ACK=음소거, LED는 위험 지속 표시 |
| 배터리 감시 | **GPIO7 ← 배터리단 100k/100k** (v4.2 변경) | 3.2V 경고 / 3.0V 종료 |
| 전원 레일 | 좌 5V / 우 3.3V 분리, star ground, 디커플링 330µF∥47µF∥0.1µF | 캡 정격 35V/25V(1차 재활용) |
| ADC 참고 | S3 11dB 유효 ~3.1V → 분압 출력 최상단 ~7% 클리핑 | 경보 임계값엔 무영향 |

## 3. 케이스 (완성)

- **세로 4칸 타워** 180×113×195 + 삼각대 보스 35 (5T 아크릴): 위→아래 = 센서칸(3분할: MQ-7·SEN0322·BME280) / MCU칸(브레드보드+V9+ESP32, 측벽 루버) / H₂S칸(MQ-136) / 보스(1/4"-20 너트)
- 뒷도어 = 위로 슬라이드. 앞판 UI 구멍: 부저 Ø12.4(중앙) · LED Ø5.2 ×2(우상) · 버튼 6.2각(우상)
- **남은 케이스 작업 = 없음.** 전자부 장입 시 확인: ① 칸 간 배선 경로(선반 통과구 or 뒷면 라우팅 — 없으면 Ø8 드릴) ② UI 부품은 연장 점퍼로 앞판 위치에 마운트(글루 고정) ③ 도어 개폐 간섭
- DXF 이력: 커팅기(LaserWork)=R12 전용 → `gaspod_dxf/r12/` 사용 (상세: 레이저 DXF 함정 메모)

### 3일 내 보장 불가(명시)
- MQ **정량 ppm 정확도** — 교육용 프로토타입 한계(§최상단 표현 제한)
- **전체 7h 방전시험** — 부분(2~3h) 곡선으로 외삽
