# 2. 대시보드 데이터 명세 — 가스포드가 보내는 것

## 전송 규칙
- **주기**: 5초마다 1회 POST
- **즉시 전송**: 상태 변화(CLEAR↔WARNING↔DANGER) 순간 + ACK 버튼 누른 순간
- 단말: `gaspod-01` (ESP32-S3, WiFi: 현장 AP 2개 — 실제 SSID/비번은 팀 채널)

## Payload 필드
| 필드 | 타입 | 의미 | 예시 |
|---|---|---|---|
| device_id | string | 장치 ID | "gaspod-01" |
| o2 | number | 산소 농도 % (SEN0322) | 19.5 |
| temp | number | 온도 ℃ (BME280) | 23.4 |
| humidity | number | 습도 % | 56 |
| pressure | number | 기압 hPa | 1000.9 |
| mq7_raw | number | CO 센서 원시값 0~4095 (클린에어 ~40) | 39 |
| mq136_raw | number | H₂S 센서 원시값 0~4095 (클린에어 0~100) | 45 |
| vbat | number | 배터리 전압 V (만충 4.2 / 경고 3.2 / 임박 3.0) | 3.82 |
| state | string | **CLEAR / WARNING / DANGER** (AED와 동일 3단계) | "CLEAR" |
| acked | bool | 현장 ACK 버튼 눌림 여부 (음소거됨, 위험은 지속) | false |

## 상태 판정 기준 (장치 내 임계값, 현재 데모값)
| 항목 | WARNING | DANGER |
|---|---|---|
| O₂ | < 19.2% | < 18.5% |
| MQ-7 (CO) raw | > 500 | > 1000 |
| MQ-136 (H₂S) raw | > 1800 | > 2200 |

> raw는 무보정 원시값입니다 (교육용 프로토타입 — ppm 아님). 임계값은 클린에어 베이스라인 튜닝 후 조정될 수 있음.

## 대시보드 구현 제안
- 상태 배지: state 그대로 (AED 신호등과 동일 색: CLEAR=초록, WARNING=노랑, DANGER=빨강)
- 시계열: o2·mq7_raw·mq136_raw·vbat 라인차트 (GET ?n=720 = 최근 1시간)
- ACK 표시: DANGER + acked=true → "현장 확인됨" 뱃지
- 오프라인 판정: 마지막 수신 15초 초과 시 "연결 끊김"
