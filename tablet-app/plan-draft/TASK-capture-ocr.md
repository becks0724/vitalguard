## ★★★ 각인 4줄 — **서버 파서가 읽는 계약이다. 형식을 바꾸지 마라**

`apps/dashboard-web/lib/ocr-stamp.ts` 가 **각인이 찍힌 사진의 OCR 텍스트**에서 값을 되뽑는다.
앱이 구조화 필드를 함께 보내지만 **그 필드가 빠지면 서버가 이 스탬프를 파싱해 채운다.**

### 원본 형식 (`MediaCapture.swift:253-282`)

```
[2026-08-19 14:07:17]
전남 순천시 …                                  ← 주소. 없으면 이 줄 자체를 뺀다
35.12345, 127.12345 (±44m) (3분 전 좌표)        ← 좌표. 없으면 "위치 미확보"
작업자/ID: 홍길동, EMP-6861
```

### 파서가 요구하는 것 — 어기면 값이 통째로 안 읽힌다

| 값 | 정규식 | 지켜야 할 것 |
|---|---|---|
| 촬영시각 | `(\d{4})[-./](\d{1,2})[-./](\d{1,2})[ T]+(\d{1,2}):(\d{2})` | `YYYY-MM-DD HH:MM:SS` · **KST 고정** |
| **GPS** | `(-?\d{1,3}\.\d{4,})\s*[,·]\s*(-?\d{1,3}\.\d{4,})` | ★ **소수 4자리 이상.** 3자리로 내려가면 **좌표를 못 읽는다** |
| 작업자ID | `\bEMP[-_]?[A-Za-z0-9]{2,}` 우선 · `\badmin[A-Za-z0-9]{2,}` 폴백 | JWT `workerId` 를 그대로. **가공하지 마라** |
| 도로명 | 한 줄에 **시/도 토큰 + 구/군/동/로/길 토큰**이 같이 | 주소를 **한 줄로** 찍어라. 줄을 쪼개면 못 읽는다 |

원본 주석이 자릿수 근거를 남겨 뒀다 — **정확도 10m 초과면 5자리, 이하면 6자리.**
6자리(≈0.11m)는 44m 오차에 붙일 정밀도가 아니지만 **파서 하한(4자리)에 여유 한 자리를 남긴다.**

### ★ 각인은 증빙이다 — 모르는 것을 아는 척하지 마라

원본이 이렇게 한다. **그대로 옮겨라.**

| 상황 | 각인 |
|---|---|
| 좌표가 60초 이상 묵음 | `(3분 전 좌표)` 를 덧붙인다 |
| 정확도를 아는 경우 | `(±44m)` 를 덧붙인다 |
| **위치를 못 받음** | **`위치 미확보`** 한 줄. ⛔ 두 줄을 그냥 비우지 마라 — *"위치가 안 찍히는 사진"* 과 *"위치를 못 받은 사진"* 이 같은 모양이 된다 |
| 주소를 기기 추정으로 얻음 | **그렇다고 적는다** |

원본 주석: *"각인은 증빙이라 옛 값을 지금 값처럼 보이게 두면 안 된다"* ·
*"기록을 지키는 것은 **밝히는 것**이다"*. 실측 사례도 있다 — 44m 짜리 좌표가 지번을 틀리게 찍었는데
각인에 불확실성이 한 글자도 없어 **읽는 사람이 확정으로 받았다.**

## 만들 것

### ① 촬영 진입 — `기록` 목적지 안에

⛔ **목적지를 5개로 늘리지 마라.** 4개는 확정이다(`screen-inventory.md:19-32`).
`R-01`/`R-02` 화면에서 촬영으로 들어가게 해라.

**두 모드를 나란히 둔다** — 폰 앱과 같다(`record_screen.dart:246-256`):

| 모드 | 무엇 | 구현 |
|---|---|---|
| **사진 촬영** | 현장 사진 1장 | `camera` 패키지 |
| **서류 스캔** | 여러 장 · 자동 보정 · 원근 교정 | ML Kit Document Scanner |

⚠ `T-6` — **펜으로도 도달**해야 한다. 두 버튼 다 56dp 이상.

### ② 처리 순서 — 원본이 정한 순서를 지켜라

```
촬영 → 좌표 요청 → 주소 해석 → OCR(원본) → 각인 → 리사이즈 → 업로드 → 사진첩(선택)
```

**★ 순서가 중요한 두 가지:**

- **좌표는 촬영 시점에 요청한다.** 원본 주석(`:99-101`): *"정지 상태에서는 `currentFix()` 가 nil 이라
  여기서 요청하지 않으면 각인의 위치 두 줄이 통째로 빈다(2026-08-19 실측)."*
- ★ **OCR 은 원본으로 돌리고 업로드본만 줄인다.** 원본 주석(`:33-38`):
  *"줄여서 인식하면 작은 글자가 먼저 사라진다."*
  리사이즈 기준: **긴 변 2400px · JPEG 0.85**

### ③ 주소 해석 — 서버 우선, 기기 폴백

원본(`:113-190`)은 **서버 역지오코딩을 먼저** 쓰고 실패하면 기기 추정으로 떨어진다.
**기기 추정일 때는 각인에 그렇게 적는다.**

⚠ **오프라인에서는 서버를 못 탄다.** 그때 주소 줄이 비거나 기기 추정이 된다.
이건 원래 그런 설계다 — **숨기지 말고 각인이 밝히게** 해라.

### ④ ★ 스캐너 모델 준비 확인 — `N-1`

문서 스캐너는 **모델·스캔로직·UI 를 Play 서비스가 최초 1회 내려받는다.**

⚠ **문제는 "셀룰러가 없어서" 가 아니다.** 원인은 **번들이 아니라 런타임 다운로드**라는 것이다.
셀룰러 부재는 그 상황을 **더 자주 만들 뿐**이다 — 폰이라면 Wi-Fi 밖에서도 받지만
이 기기는 **Wi-Fi 가 닿는 곳에서만** 받는다. 그래서 순찰 중 첫 사용이 실패할 수 있다.

**대조**: OCR 모델(`com.google.mlkit:text-recognition-korean`)은 **APK 에 번들**이라
네트워크와 무관하다. 같은 ML Kit 이라도 **전달 방식이 다르다** —
Digital Ink 를 기각한 것도 번들 옵션이 없어서였지 셀룰러 때문이 아니었다.

- 앱이 **준비 여부를 확인**해라. 안 됐으면 **`인터넷에 연결해 한 번 준비해 주세요`** 라고 말해라
- ⛔ **조용히 실패하지 마라.** 버튼을 눌렀는데 아무 일도 안 일어나면 안 된다
- **사진 촬영(모드 1)은 영향 없다** — OCR 모델이 번들이라 오프라인에서 그대로 된다.
  둘을 같은 오류로 묶지 마라

### ⑤ 카메라 권한 — 런타임 요청

`AndroidManifest` 에 선언만 돼 있다. **런타임 요청이 필요하다.**
⛔ `permission_handler` 같은 패키지를 쓰지 마라 — STT 때처럼 **네이티브에서 처리**하거나
`camera` 패키지가 제공하는 경로를 써라.

권한 거절 시: **거절됐다고 말해라.** 표본을 지어내거나 빈 화면을 보여주지 마라.

### ⑥ 업로드 — 기존 경로 재사용

`POST /api/app-media` 그대로다. **새 라우트를 만들지 마라.**
폼 필드는 `record_origin.dart` 의 `annotationFields()` 가 쓰는 것과 같은 이름이다
(`dateKey`·`capturedAt`·`ocrText`·`roadAddress`·`latitude`·`longitude`·`siteId`·`title`).

⚠ **`uploader`·`workerId` 를 보내지 마라.** 서버가 JWT 신원으로 강제로 덮는다(`app-media/route.ts:127-133`).
보내는 코드가 남아 있으면 다음 사람이 "앱이 귀속을 정한다" 고 오해한다.

⛔ **라이브 서버에 실제로 업로드하지 마라.** 모의로 붙여라. 실제 호출은 내가 태곤 님 확인 후 돌린다.

### ⑦ 사진첩 저장 — **이번엔 하지 마라**

원본은 업로드와 별개로 사진첩에도 저장한다. **저장소 권한이 필요하다.**
지금 `AndroidManifest` 에 저장소 권한을 넣지 않았다 — **필요한지 정해지지 않았다.**
**권한을 미리 늘리지 않는다.** 필요해지면 그때 따로 요청한다.
