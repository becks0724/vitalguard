
**`vgGapTap = 12` 는 규칙 `T-5` 가 "부족하다" 고 명시한 바로 그 값이다.**
실측 조준 편향이 **(3.3, 12.7) 크기 13.2dp** 이고, T-5 는 세로로 붙은 타깃 사이 간격을

**지금 실제 위반은 없다** — 네가 만든 화면은 전부 `16` 리터럴을 쓰고 있고 16 > 13.2 다.

**그래서 코드가 아니라 토큰이 함정이다.** 다음에 토큰을 믿고 세로로 쓰는 사람이 조용히 규칙을 깬다.

할 일:

- `vgGapTap` 에 **왜 16인지** 한 줄 주석(편향 13.2dp 초과).

### ② 세로로 붙은 탭 타깃 사이 간격은 토큰을 쓴다

**폰 레이아웃을 태블릿에 그대로 올린 것이다.** 실물에서 이렇게 된다:

- **날짜를 눌러도 화면이 안 변한다.** 그날 목록이 접힌 아래라 **사용자는 탭이 안 먹었다고 판단한다.**
  (내가 실제로 그렇게 오판했다. 태곤 님도 같은 걸 겪는다)
- `R-03`·`R-05` 에서 **주 실행 버튼(`펜으로 표시하기`·`주석 이어서 편집`)이 첫 화면에 온전히 안 보인다.**
  뷰포트 경계에 걸려 절반만 나온다. 스크롤해야 나타난다.
  **하드 클리핑이 아니라 배치 문제다** — 원인이 같다.

**처방: 가로에서 2단으로 간다.**
- `R-01`/`R-02` — **왼쪽 캘린더 · 오른쪽 그날 목록.** 날짜를 누르면 오른쪽이 즉시 바뀐다.
- **세로에서는 지금 1단을 유지해라.** `MediaQuery` 가로/세로로 갈라라.
  ⚠ **방향 고정은 불가다**(Android 16). 두 배치가 **실행 중에 서로 바뀐다는 전제**로 짜라.
- 기준값은 지어내지 말고 **실측을 써라**: 가로 `1385.4×865.9` dp / 세로 `865.9×1385.4` dp
  (`research/device-facts.md` 「★★ [관측] 앱을 실제로 띄워 잰 값」).

### ⑫ ★ **모의인데 "서버 전송 완료" 라고 말한다**

`record_editor.dart:625-631` 이 `sent` 하나로 문구를 고른다. **모의 게이트웨이도 업로드 성공을 돌려주므로
모의에서도 `서버 전송 완료` 가 뜬다.** 실기기에서 실제로 그렇게 떴다.

**이건 "모의 표지" 문제가 아니라 "상태 주장" 문제다.**
셸 배지는 화면 위쪽에 있고, 저장 결과 화면에서 사용자 눈은 큰 글씨 `서버 전송 완료` 에 간다.
**시연 중에 실제로 갔다고 믿는다.**

- `isMock` 일 때 **`모의 전송 완료 — 실제 서버로 보내지 않았습니다`** 처럼 **일어난 일을 그대로** 말해라.
- `기기 저장됨 · 서버 결과 불명` / `기기 저장됨 · 서버 미전송` 분기는 **잘 돼 있다. 건드리지 마라.**
- 이건 `N-1`(네트워크 필요 기능은 조용히 실패하지 않는다)의 짝이다:
  **일어나지 않은 일을 일어났다고 말하지 않는다.** 두 곳을 서로 참조시켜라.

### ⑬ 캔버스가 화면 가로의 42% 만 쓴다

`R-04` 는 **주석을 그리는 화면**인데 그림이 작다. 확대 버튼이 있지만 **기본 상태에서 더 크게 잡아라.**
⑪ 의 2단 배치와 함께 판단해라 — 캔버스는 2단으로 쪼개지 말고 **가로 전체를 써라.**

### ⑭ 색 선택 원의 **보이는 크기**가 21dp다

탭 영역은 56dp 라 규칙 위반은 아니다. 다만 **실측 조준 편향이 13.2dp** 인데 표적이 21dp 로 보이면
**장갑 끼고 조준하기 어렵다.** 사용자는 보이는 만큼만 누를 수 있다고 생각한다.
**아이콘 자체를 키워라**(탭 영역은 그대로 56 유지).

## 아직 안 끝난 것

- **손바닥 얹고 긋기**(`P-4`·`P-5` 팜 리젝션) — 태곤 님이 아직 안 했다. **결과 나오면 추가로 알려주겠다.**
- **손가락으로 긋기**(`P-4` — 안 그려져야 정상) — 마찬가지.
- **라이브 경로 실기기 검증** — ⑤~⑧ 을 끝내야 가능하다.

### ⑮ `R-04` 에 **`전체 지우기` 가 없다** — 실사용에서 바로 걸렸다

도구는 `펜`·`형광펜`·`사각형`·`지우개` 와 **되돌리기(1획씩)** 뿐이다.
`strokes.clear()` 는 `:161` 의 **불러오기 내부 호출 하나**이고 **사용자 버튼이 없다.**

태곤 님이 실기기에서 바로 막혔다 — 필압 시험 획이 남아 **팜 리젝션 시험을 할 자리가 없었다.**
내가 되돌리기를 3번 눌러 치웠다. **획이 20개면 20번이다. 장갑 끼고 현장에서 할 일이 아니다.**

- **`전체 지우기` 를 툴바에 넣어라.**
- ⚠ **확인 없이 지우지 마라.** 되돌릴 수 없는 파괴 동작이다.
  이건 `I-5`(확인 없이 저장하지 않는다)의 짝이다 — **확인 없이 버리지도 않는다.**
  ⚠ **`glove_screen.dart` 의 초기화 사고를 반복하지 마라** — 내가 초기화 버튼을 모드 전환 스위치
  바로 옆에 두는 바람에 태곤 님이 맨손 측정 데이터를 통째로 날렸다.
  **`전체 지우기` 를 `주석 저장` 이나 `되돌리기` 바로 옆에 두지 마라.**
