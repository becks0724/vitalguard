# 작업 지시 — P4 터치 실측 결과를 설계 문서에 반영

작성: Claude / 수신: 코덱스(astra) / 2026-09-12

## 배경

Flutter 진단 앱을 실기기(TB373FU)에 띄워 **터치 정확도**를 실측했다.
`research/device-facts.md` 의 「★★ [관측] 터치 정확도 — 맨손 vs 천」 절에 **원본 기록은 이미 끝냈다.**
이 지시는 **나머지 3개 파일에 그 결론을 반영**하는 일이다.

## 실측값 (이 숫자를 바꾸지 말 것)

측정: `app/vitalguard_field/lib/glove_screen.dart` · 타깃 40→48→56→64→72dp 순환 · 위치 난수 고정시드(7)

| 타깃 | 맨손 | 천(면95%) |
|---|---|---|
| 40dp | **2/4 (50%)** 오차 18.5 | 3/4 (75%) 오차 12.5 |
| 48dp | 4/4 (100%) 12.7 | 4/4 (100%) 13.1 |
| 56dp | 4/4 (100%) 11.5 | 4/4 (100%) 9.5 |
| 64dp | 4/4 (100%) 15.2 | 3/3 (100%) 14.3 |
| 72dp | 3/4 (75%) **69.1 ⚠이상치** | 3/3 (100%) 15.4 |
| 평균 오차 벡터 | **(3.3, 12.7)** 크기 **13.2** | (2.7, 7.7) 크기 8.1 |
| 접촉반경·압력 | **0.2 · 1.000** | 0.1 · 1.000 |
| 표본 | 20 | 18 |

**측정 조건의 한계 — 반드시 같이 적을 것**

- "천" 열은 **진짜 장갑이 아니다.** 장갑이 없어서 **면 95% 의류 원단을 손에 감싼 상태**로 쟀다(겹수·두께 미기록).
- 따라서 **현장 장갑을 대표하지 않는다.** 코팅장갑은 절연체라 **아예 안 될 수 있다**(가설).
- 표본이 크기당 3~4개다. `4/4=100%` 는 **"실패율 0%" 가 아니라 "4번 중 실패가 없었다"** 다.
- 72dp 맨손 69.1 은 이상치(반지름 36dp 인데 3/4 적중 → 빗나간 1회가 200dp 넘게 떨어짐 = 측정 사고).

## 결론 4가지 (이미 tab_plan.md 에 반영 완료 — 참고용)

1. **40dp 금지** — 맨손조차 50%. 48dp 부터 실패 없음. 56dp 최소는 유지할 근거 있음.
2. ★ **오차의 대부분이 "편향" 이다.** 맨손 오차 벡터 크기 13.2 ≈ 평균 오차 거리 11.5~15.2.
   랜덤이 아니라 **아래로 쏠린다.** 처방은 "타깃을 키워라" 가 **아니다** —
   히트박스를 아래로 옮기면 아래 항목과 겹쳐 오탭이 는다. 실제 처방:
   **세로로 붙은 타깃 사이 간격을 편향(약 13dp)보다 크게.** 현재 `vgGapTap = 12dp` 는 **부족**.
3. **편향은 천 때문이 아니다** — 맨손(12.7)이 천(7.7)보다 **크다.** 소재 무관 조준 특성.
4. **손가락은 압력·접촉면적을 보고하지 않는다**(둘 다 압력 1.000 고정, 반경 0.1~0.2).
   펜은 `0.041~0.917` 로 변한다. → **접촉 면적으로 장갑 착용을 자동 감지할 수 없다.**

추가 함의: 코팅장갑에서 터치가 안 되면 **펜이 유일한 입력 수단**이 된다.
펜은 자체 신호라 장갑과 무관하다. → **모든 핵심 동작에 펜으로 도달하는 경로**가 있어야 한다.

## ★ 규칙 ID 체계 — 어기지 말 것

`artifacts/design-constraints.md` 가 **정본**이다. 접두사:
`C`=캔버스(C-1~4) · `V`=색(V-1~5) · `T`=터치(T-1~4) · `P`=펜(P-1~3) · `I`=입력(I-1~3) · `N`=네트워크(N-1~4)

내가 한 번 틀렸다 — 잉크 규칙에 `N-` 을 붙여 네트워크와 충돌시켰다. **이미 고쳤다.**
새로 붙일 번호는 **기존 최대값 다음**이다:

| 새 ID | 내용 |
|---|---|
| **C-5** | 가로에서 키보드를 띄우는 흐름을 피한다 — 안전 높이의 **43.5%** 가 사라진다 |
| **T-5** | 세로로 붙은 타깃 사이 간격을 **편향(약 13dp)보다 크게**. `vgGapTap=12dp` 는 부족 |
| **T-6** | **모든 핵심 동작에 펜으로 도달하는 경로**를 둔다(코팅장갑이면 터치가 아예 안 될 수 있다) |
| **P-4** | **잉크는 `stylus` 만 그린다** — `touch` 로 그리면 손바닥 점이 남는다 |
| **P-5** | **`onPointerCancel` 로 취소된 획을 되돌린다** — 팜 리젝션은 **사후 취소**다 |
| **P-6** | **지우개는 화면 안 도구**로 — 펜에 **지우개 꼬리가 없다**(`invertedStylus` 표본 0) |

## 할 일 4가지

### ① `artifacts/design-constraints.md` — 정본에 새 규칙 추가

- **§1 캔버스**에 `C-5` 추가. 근거: IME 368.0dp / 가로 안전높이 811.8dp → 43.5%.
  기존 `C-2`(세로 26.5%)는 **지우지 말고**, 가로 수치를 **덧붙여** 갱신할 것.
- **§3 터치·파지**에 `T-5`·`T-6` 추가. `T-1` 은 `[가설]` → **`[관측]`** 으로 승격하고
  "40dp 금지" 를 명시. 위 실측표를 근거로 인용할 것.
- **§4 펜**에 `P-4`·`P-5`·`P-6` 추가. 근거는 `device-facts.md` 의 펜·팜리젝션 절.
- **§3 에 손가락 축 사실 추가** — 압력 1.000 고정 / 반경 0.1~0.2 → 장갑 자동감지 불가.
- 근거 등급은 이 문서의 기존 표기(`[관측]` `[계산]` `[가설]` `[미검증]`)를 그대로 쓸 것.
