## ① 잉크 벡터를 받는다 — `media_type = 'ink'`

**파일**: `app/api/app-media/route.ts`

잉크는 JSON 이다. **기존 업로드 경로를 그대로 쓴다** — 새 라우트를 만들지 마라.

- `EXT_BY_TYPE` 에 `"application/json": "json"`, `TYPE_BY_EXT` 에 `json: "application/json"` 추가.
- `:140` 의 `mediaType` 판정에 **`ink` 갈래**를 더한다. `application/json` 이면 `"ink"` 다.
- 잉크본은 **`annotationOf` 가 필수**다. 없으면 **400**. (사진은 지금처럼 없어도 된다.)
  - 폼 필드명은 기존 `pick(form, [...])` 관례를 따라 변형 몇 개를 받아라.
- `insertCalendarMedia` 에 `annotationOf` 를 실어라(이미 선택 필드로 만들어 뒀다).

### 검증은 최소로만

**잉크 JSON 의 내용 규격을 서버가 강제하지 마라.** 앱이 형식을 정하고 서버는 보관만 한다.
다만 두 가지는 본다 — 쓰레기가 들어오면 나중에 웹이 그리다 죽는다.

1. **JSON 으로 파싱되는가** (아니면 400)
2. **최상위에 `v`(형식 버전 · 정수)가 있는가** (없으면 400)

> `v` 를 요구하는 이유 — 웹이 잉크를 그리려면 필압 굵기 공식·형광펜 투명도 같은
> **렌더 규칙**을 알아야 한다. 규칙이 바뀔 때 옛 데이터를 그대로 그리려면 버전이 있어야 한다.
> 지금은 `v: 1` 하나뿐이다.

⚠ **크기 상한을 두어라.** 잉크 JSON 한 건의 크기를 **아무도 잰 적이 없다**
(`record_editor.dart:272` 가 점 수 제한 없이 `points.add`). 기존 업로드 상한이 있으면 그것을 쓰고,
없으면 **2MB** 로 막고 초과 시 413 을 줘라. **그 값을 보고해라 — 실측 뒤 조정한다.**

## ② 목록은 최신 잉크본 하나만 가리킨다

**파일**: `lib/db.ts` `listCalendarMedia`(`:4597`)

잉크본은 **버전을 쌓는다**(덮어쓰지 않는다 — 산업재해 기록이라 이전 기록이 사라지면 그게 위변조다).
그래서 한 원본에 `annotation_of` 가 같은 행이 **여러 개** 생긴다.

- 이미 넣은 `annotationId` 서브쿼리를 **가장 최신 한 건**으로 좁혀라
  (`created_at` 내림차순 · 동률이면 `id` 로 안정 정렬).
- 목록은 지금처럼 `WHERE m.annotation_of IS NULL` 로 **원본만** 준다. 그대로 둬라.
- **옛 버전을 목록에서 볼 길은 이번에 만들지 마라.** 저장만 해 둔다(프론트는 최신만 보인다 — 확정 사항).

## ③ 삭제 — 유예 10분 + 잉크본 동반 삭제

**파일**: `lib/db.ts` `deleteCalendarMedia`(`:4790`)

```
상수: MEDIA_DELETE_WINDOW_MIN = 10   // 신규 DB trg_media_delete_window 와 같은 값
```

1. **유예 밖이면 지우지 않는다.** `created_at` 이 10분보다 오래됐으면 삭제하지 말고
   **"유예 경과"를 호출자가 구분할 수 있게** 돌려줘라. 지금 반환형이 `… | null` 이라
   "없음"과 "거부"가 섞인다. **둘을 구분하도록 바꾸고, 호출자(라우트)도 함께 고쳐
   403 과 404 를 다르게 응답하게 해라.** 화면이 "왜 안 되는지" 말할 수 있어야 한다.
2. **원본을 지우면 그 잉크본도 같이 지운다.** 한 트랜잭션에서. 잉크본의 `storage_key` 들도
   같이 돌려줘 호출자가 스토리지에서 지우게 해라 — **지금 반환값이 하나뿐이니 목록으로 바꿔야 한다.**
3. 잉크본 **자체를** 지우는 호출(`annotation_of` 가 NULL 이 아닌 행)은 **유예를 적용하지 마라.**
   재편집으로 새 버전을 쌓는 것이 정상 경로이고, 잉크본 단독 삭제는 이번 범위 밖이다.

⚠ `created_at` 은 **TEXT** 다(`:974`). 비교 전에 `::timestamptz` 로 캐스팅해라.
캐스팅이 실패할 수 있는 옛 행이 있는지 **먼저 확인하고 보고해라.** 있으면 어떻게 다룰지 내가 정한다.
