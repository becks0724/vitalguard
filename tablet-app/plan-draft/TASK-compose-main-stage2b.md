## 2. 구현 지침
- 편집기 캔버스: `Canvas` + `pointerInput`/`awaitPointerEventScope` 로 **raw 포인터** 처리(`PointerType.Stylus` 만 그림, `Touch` 는 이동·확대). 압력은 `PointerInputChange.pressure`. 취소 이벤트(`changes.any { !it.pressed && … }` 및 `PointerEventType.Release`/cancel)는 활성 획을 확정하지 않고 버린다. 회전(`Configuration` 변경) 시 활성 획 확정·저장 — ViewModel 로 상태 유지.
- 렌더: 원본 비트맵 위에 획을 `android.graphics.Canvas` 로 그려 PNG 인코딩(원본 해상도). 큰 사진(4160px)도 OOM 없이 — `inSampleSize` 는 미리보기에만, 저장 렌더는 원본 크기.
- 저장 키·JSON 필드·문구는 원본 글자 그대로. `beforeLock` 훅은 `FieldCoordinator` 에 있는 것을 쓴다(없으면 추가).
- 새 라이브러리 금지(녹음은 `MediaRecorder`/`MediaCodec`, 재생은 `MediaPlayer`, STT 는 `android.speech.SpeechRecognizer`, 이미 원본 Kotlin 이 쓰는 API).
- 권한: `RECORD_AUDIO` 매니페스트 + 런타임 요청(거절 문구 원본대로).
