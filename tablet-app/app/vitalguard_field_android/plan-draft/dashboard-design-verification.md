# 전체 카드·상태 아이콘 디자인 — 1.2.1

사용자 첨부의 회색 유리 질감 대시보드를 기준으로 기존 Compose 앱을 수정했다. **반투명 카드·불투명 사이드바**, 나머지 카드 섹션의 동일 재질, 텍스트 비중을 줄이는 상태 아이콘 요청을 반영했다.

## 최종 변경

- 기상·작업자·가스·AED·경보·CCTV 홈을 실제 본문 폭과 글자 크기에 따라 3열/2열/1열로 배치한다. 좁은 화면은 경보를 먼저 보여준다.
- 상세·경보·설정·전송 이력·월간/주간 달력·사진/메모 첨부·펜 도구·CCTV 영역에 공통 GlassCard를 적용했다. 사이드바 alpha는 1.0, 기본 카드 배경은 흰색 alpha 36/255다.
- 사진·필기·영상에는 배경 투명도를 적용하지 않는다. 잉크/이미지 렌더링 코드는 그대로이며, 기존 CCTV 오래됨 표시는 유지한다.
- 배경은 Canvas의 중성 그라데이션·구조선·고정 입자다. 추가 이미지 다운로드, backdrop blur, 지속 장식 애니메이션, 새 의존성이 없다.
- 숫자는 고정 폭 숫자 기능과 크기/굵기로 구분한다. 한글은 기기 글꼴을 사용한다. 본문·보조 문구·버튼 글자는 가장 밝은 배경 중첩 지점에서도 대비 4.5:1 이상을 검사했다.
- 실제 정상/전체 작업자 수만 원형 비율로 표시한다. 누락된 값·미수신·단위 없음·오래된 자료·권한 없음·전체 현장 경보 범위를 유지한다. 가짜 예보/이력/점수는 만들지 않았다.
- 평상시 갱신은 카드 위치를 움직이지 않는다. 최초 수신/실패/오래됨/권한 안내는 상태에 맞춰 표시한다.

## 상태를 읽는 방식

| 상태 | 시각 요소 | 표시 방식 |
|---|---|---|
| 오프라인 | 끊긴 Wi-Fi | 짧은 상태명, 필요한 기기 보관 안내 |
| 수신 실패/주의 | 경고 삼각형 | 제목 + 다음 행동 한 줄 |
| 갱신 중 | 순환 화살표 | 이전 자료 유지 안내 |
| 오래됨/결과 불명 | 시계 | 현재 상태와 구분, 기존 재조회 조건 유지 |
| 권한 없음 | 자물쇠 | 역할/현장 배정 안내 |
| 수신/전송 완료 | 원 안의 체크 | 서버 확인 여부 문구 유지 |
| 수신 대기 | 수신함 | 없는 값을 0으로 만들지 않음 |

상단 긴 연결 설명은 아이콘과 짧은 문구로 바꾸고 **ⓘ 상태 자세히**에서 원래 안내 전체를 볼 수 있게 했다. 화면 읽기 도구에도 원래 상태 설명을 제공한다. 전송 이력의 안내와 작업/현장 ID는 **전송 안내 / 기록 정보**로 접고 펼친다. 위험한 결과 불명 상태의 확인/재시도 안내는 유지한다.
