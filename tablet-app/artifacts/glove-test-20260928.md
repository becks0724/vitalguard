# 실제 장갑 사용성 확인 — 2026-09-28

사용자가 실제 장갑을 가져왔다고 알려 기존 보류 항목을 재개했다.
대상: TB373FU / HA2HG0SD. 초기 탭 전환 안내 당시 주 앱은 Compose release 1.3.1/code6(b538b988). 후속 작은 아이콘·스크롤 결과 회신 당시 설치본은 1.3.3/code8이며, 각 수동 수행 시각은 별도 기록되지 않았다.

## 조건

- 장갑 종류: 사용자 표현은 노란 고무 코팅 목장갑. 첨부 사진도 노란 손바닥 코팅과 흰 편직 등판의 작업장갑을 보여 준다. 구체적인 고무 성분/제품 규격은 확인하지 않았다.
- 착용 손과 손가락, 건조/젖음 여부: 아직 기록하지 않음.
- 현재 실제 앱에서 기능 도달 여부를 먼저 확인한다. 과거 면 95% 옷 원단 측정과 구분한다.
- 자동 ADB 터치로 사람의 장갑 터치를 대신하지 않는다.

## 진행과 결과

| 순서 | 행동 | 기록할 항목 | 현재 상태 |
|---|---|---|---|
| 1 | 장갑을 끼고 설정 → 현장 5회 왕복 | 총 10터치의 첫 시도 성공 수, 재탭, 다른 항목 오작동 | 사용자 보고: 전부 반응, 10/10. 자동 계측 수치가 아닌 사용자 수행/보고 |
| 2 | 상단 오른쪽 안내 아이콘 열기·닫기 5회 안내 | 작은 시각 요소의 누락/오작동 | 사용자 보고 ‘잘됨’. 정확한 수행 횟수는 별도 회신 없음 |
| 3 | 대시보드 위아래 스크롤 3회 왕복 안내 | 시작 실패·끊김·의도치 않은 카드 열림 | 사용자 보고 ‘잘됨’. 정확한 수행 횟수는 별도 회신 없음 |
| 4 | 장갑을 낀 채 펜 사용 및 도구 선택 | 도구 도달·필기·원치 않는 입력 | 미실행 |

현재 1~3번은 사용자 수행/보고가 확인됐고 장갑을 낀 펜 사용은 미확인이다. 실제 장갑의 크기별 좌표 오차나 장기간 성공률을 이 짧은 기능 검사로 일반화하지 않는다. 사용자가 함께 지적한 작은 월간 달력 불필요 및 촬영·스캔 버튼의 큰 달력 가림은 별도의 레이아웃 수정으로 처리한다.
