### ★ 설계를 지배하는 제약 3가지

1. **셀룰러 없음**(`telephony` feature 자체 부재) → **끊김이 정상 시나리오**. 오프라인은 예외가 아니라 기본 설계.
2. **나침반 없음** → 지도에 방위를 못 그린다.
3. **통화·문자 불가** → 관제웹 SOS 모달의 통화 버튼을 그대로 옮길 수 없다.

### ★ P4 실측으로 추가된 제약 3가지 (2026-09-12)

4. **`SafeArea` 는 좌우 제스처 띠를 안 막는다.** `padding.left/right` 가 **0.0** 인데
   `systemGestureInsets` 는 **29.6dp** 다. 서로 다른 인셋이라 **직접 읽어야** 한다.
5. **가로에서 키보드가 화면의 43.5% 를 먹는다.** IME 368dp 는 방향 무관 동일한데
   안전 높이만 811.8dp 로 줄어서다. **가로일수록 키보드를 더 피한다.**
6. **팜 리젝션은 "차단" 이 아니라 "사후 취소" 다.** 손바닥이 일단 `touch` 포인터로
   **들어온 뒤** `PointerCancel` 로 거둬진다. 취소되는 건 `touch` 이고 **`stylus` 는 살아남는다.**
   → ⓐ **잉크는 `stylus` 만 그린다**(`touch` 로 그리면 취소 전 몇 프레임이 손바닥 점으로 남는다)
     ⓑ **`onPointerCancel` 로 획을 되돌린다** ⓒ **동시 접촉 2를 전제**로 짠다.
7. ★ **터치 오차는 랜덤이 아니라 아래로 쏠린다.** 맨손 평균 오차 벡터 **(3.3, 12.7)**,
   크기 **13.2** — 이게 평균 오차 거리(11.5~15.2)와 거의 같다. **오차의 대부분이 편향**이다.
   손가락이 타깃을 가려 위쪽 가장자리를 보고 조준하기 때문으로 보인다(원인은 [가설]).
   → 처방은 **"타깃을 키워라" 가 아니다.** 히트박스를 아래로 옮기면 아래 항목과 겹쳐 오탭이 는다.
     **세로로 붙은 타깃 간격을 편향(약 13dp)보다 크게** 둔다. `vgGapTap = 12dp` 는 **부족**.
   ⚠ **40dp 는 맨손조차 50%** 다. 48dp 부터 실패가 없었다(표본 3~4개라 "실패율 0%" 는 아니다).

8. ★ **STT 는 되지만 1순위를 믿으면 안 된다.** 온디바이스 한국어가 **네트워크 없이도** 돈다
   (`createOnDeviceSpeechRecognizer` · `ko-KR` · 비행기ON·WiFiOFF·netOFF 에서 오류 0건).
   그런데 **1순위는 5건 중 1건, 후보 포함은 5건 중 3건**이다.
   → **후보 5개를 보여주고 고르게 하면 정확도가 3배가 된다**(규칙 `I-4`).
   ⚠ **부정 표현이 사라진다** — `안전대 미착용` → `안전띠 적용`.
     **위반 기록이 정상 기록으로 뒤집힌다.** 확인 없이 저장하면 안 된다(규칙 `I-5`).
     (같은 문장이 오프라인에선 정확히 인식됐다. 표본 1회씩이라 원인은 단정 못 한다.)
   → **`sherpa-onnx`·ML Kit 은 필요 없어졌다.** 패키지 설치 요청 취소.

> 실증 사례 — 손글씨 언어팩 다운로드 버튼을 눌렀더니 **Wi-Fi 설정으로 튕겼다.**
> "네트워크 필요 기능이 조용히 실패하면 안 된다"가 이렇게 실증됐다.

### ⛔ D-2 는 2026-09-13 에 B안(벡터)으로 뒤집혔다 — 아래는 **폐기된 근거**다

> 태곤 님(09-13): *"사진 픽셀이나 크기 이런거 잘 맞춰서 원본 사진 1장 + 현장 안전 담당관이
> 메모한 것만 따로 띄워서 원본 사진 위에 호버링처럼 매칭 시키면 사진 1장 분의 크기를 줄일 수 있지 않나?"*

**무엇이 A안을 깼나** — 이유는 "다른 기기에서 열기"가 아니었다. **위변조 방지**다.
합성본은 원본과 잉크가 한 장으로 구워져 **무엇이 원본이었는지 증명할 수 없다.**
벡터로 나누면 원본 JPEG 이 그대로 남고, 잉크는 그 위에 얹히는 별도 데이터가 된다.
덤으로 **버전을 쌓아도** 사진이 중복 저장되지 않는다.

⚠ 다만 초판에 적었던 *"잉크는 수 KB"* 는 **틀렸다**(실측: 10획 59KB · 100획 590KB · 100획×400점 2.29MB).

#### D-2 를 A안으로 정한 이유

> 태곤 님: *"한 현장 하나에 한명의 현장 안전 담당관이 배치됨. 태블릿도 한 현장 하나당 한 태블릿."*

## 3. ★ 함정 — 다시 겪지 않으려고 적는다

### 3-1. 개발자 옵션 진입 경로가 표준과 다르다
`설정 → 태블릿 정보` 에 **빌드 번호가 없다.** **`소프트웨어 버전`을 7회 탭**해야 개발자 모드가 켜진다.

### 3-2. 레노버 OS 손글씨는 한글을 못 조합한다 (실측 기각)
`설정 → 펜 → 손글씨` 에 한국어 팩을 받아 켜고 시험한 결과:

| 쓴 글자 | 결과 | 실패 |
|---|---|---|
| 네 | `네` | 정상 |
| 이 | `ㅇ` | 중성 누락 |
| 버 | `뻐` | 자음 오인식 |
| 구 | `7ㄱㅜ` | **숫자 혼입** |
| 글 | `그리` | **종성 분리** |

전체 = **`네ㅇ뻐7ㄱㅜ그리`**. 설정 문구가 원인을 말한다 — *"**영어, 숫자 및 구두점 기호와 함께** 선택한 언어를 인식"*.
→ **요구사항 14 의 주력 수단으로 쓸 수 없다.** 대안은 ML Kit Digital Ink(한국어 `ko`·20MB·오프라인·무료)이나 **실측 전 확정 금지**.
→ 부작용: 손글씨를 켜면 **IME 가 기본 입력기로 승격**된다(Gboard 로 원복함). **앱은 IME 를 강제하지 않는다**가 규칙이 됐다.

### 3-3. peers 브로커가 메시지를 자주 삼킨다
`check_messages` 가 "No new messages" 인데 상대 화면에는 보낸 흔적이 있다.
→ **`cmux read-screen --scrollback`** 으로 직접 읽는다. 코덱스는 큐가 쌓여도 **자동 처리하지 않을 때가 있어** `cmux send` + `Enter` 로 깨워야 한다.

### 3-4. 분류기가 에이전트 기동을 막는다
`cmux new-workspace --command "codex -p astra"` 가 `[Create Unsafe Agents]` 로 차단됐다.
→ **태곤 님이 `!` 로 직접 실행**해야 한다. 우회하지 않는다.

### 3-5. LibreOffice 는 HTML→DOCX 에 필터를 명시해야 한다
```bash
soffice --headless --convert-to 'docx:MS Word 2007 XML' --infilter="HTML (StarWriter)" --outdir <dir> <file.html>
```
필터 없이 `--convert-to docx` 만 주면 `no export filter` 로 죽는다. pandoc 은 이 맥에 없다.

### 3-6. CSS `transform: scale` 은 레이아웃 공간을 안 줄인다
HTML 시안 축소에 `transform` 을 썼더니 하단이 잘렸다. **`zoom`** 으로 바꿔야 공간까지 줄어든다.

### 3-7. 웹폰트(Material Symbols)가 로드 실패하면 아이콘 이름이 글자로 노출된다
→ **인라인 SVG 스프라이트**로 바꿔 외부 의존을 없앴다. 각 아이콘에 대응하는 Flutter `Icons.*` 이름을 주석으로 남겼다.

### 3-8. ★ 합성 터치(`adb input`)로는 펜을 측정할 수 없다 — 오히려 판정을 오염시킨다

`adb shell input swipe` 는 **UP 이벤트에서 `pressure 0` 을 보낸다.** 그래서 `pressureMin 0.000`
이 기록됐고 **"진짜 필압이다 ✓" 가 잘못 켜졌다.** 그건 필압이 아니라 손가락이었다.

### 3-11. ★ LibreOffice 는 두 인스턴스가 동시에 못 돈다 — 병렬 작업의 함정

클로드와 코덱스가 **각자 `md2docx.py` 를 돌리다 겹쳐서** LibreOffice 가 **4연속 크래시**했다
(2026-09-12 13:35~14:26). "soffice 응용 프로그램이 예기치 않게 종료되었습니다" 다이얼로그가
`다시 열기` 를 눌러도 계속 떴다.

크래시 스택이 원인을 정확히 말해 줬다:
```
HIServices  _RegisterApplication  →  abort (SIGABRT)
termination: byProc=soffice, byPid=16973   ← 다른 soffice 가 죽였다
```
LibreOffice 는 **한 프로필을 두 인스턴스가 동시에 쓰지 못한다.**

**고친 방법** — `tools/md2docx.py` 에 두 겹:
```python
LOCK    = /tmp/md2docx.soffice.lock    # flock 직렬화(180초 대기 후 안내하고 종료)
PROFILE = /tmp/md2docx-lo-profile      # 이 도구 전용 프로필
soffice -env:UserInstallation=file:///tmp/md2docx-lo-profile --headless ...
```
동시 실행 시험으로 **둘 다 성공 · 크래시 0건** 확인했다.

- **`soffice` 를 직접 호출하지 말 것.** 반드시 `md2docx.py` 를 거쳐야 락이 걸린다.
- 좀비가 남았으면: `pkill -f 'MacOS/soffice'` + `rm ~/Library/Application\ Support/LibreOffice/4/.lock`
  (지우기 전 `.~lock.*` 파일로 **열린 문서가 없는지** 먼저 확인할 것)

**교훈: 둘이 같은 도구를 쓰면 도구에 락을 넣어야지, 서로 안 겹치게 조심하는 걸로는 안 된다.**

**2차 재발(같은 날 15:04) — 락이 있는데도 또 죽었다. 원인 3개가 겹쳐 있었다:**

1. **락이 공유되지 않았다.** `tempfile.gettempdir()` 은 **프로세스마다 다른 경로**를 준다
   (내 값 `/var/folders/s3/…/T`, 코덱스 샌드박스는 또 다름). **서로 다른 락 파일**을 잡았다.
   → 락은 **작업공간 고정 경로**(`tools/.md2docx.lock`)에 둔다.
2. ★ **한글 경로가 LibreOffice 를 죽인다.** `-env:UserInstallation=file://…` 은 **URL** 이라
   **한글·공백이 인코딩되지 않아 깨진다.** 1번을 고치면서 프로필도 작업공간으로 옮겼다가
   `rc=-6` `RuntimeException` 으로 죽었다(내가 만든 회귀).
   → **프로필은 반드시 ASCII 경로**(`~/.md2docx-lo-profile`). 락과 프로필의 요구가 다르다.
3. ★★ **스크립트가 거짓 성공을 보고했다.** `docx 가 존재하는지` 만 보고
   **`새로 만들어졌는지` 는 확인하지 않았다.** soffice 가 죽어도 **이전 docx 가 남아 있으면**
   "✓ 변환 성공" 을 찍었다 — md 는 15:03 인데 docx 는 14:31 인 채로.
   → 변환 전 **mtime 을 기록**하고 갱신 여부를 검사한다. 실패하면 `rc`·`stdout`·`stderr` 를 전부 뱉는다.
4. `soffice` 는 **래퍼라 자식을 남기고 먼저 반환**한다. 락을 놓기 전에 `pgrep` 으로 종료를 기다린다.

**교훈 둘:**
- **"파일이 있다" 를 성공으로 보지 마라.** 갱신 여부를 확인해야 한다.
  이건 `조회 0행 ≠ 정상 0건` 과 같은 부류의 착각이다.
- **코덱스 샌드박스는 `dart analyze`(SDK 캐시)·`adb`(소켓)·`soffice`(앱 등록)를 전부 막는다.**
  → **빌드·설치·실기기 측정·docx 변환은 클로드 담당**으로 고정한다. 지시서에서 아예 빼라.

## 7. 지켜야 할 원칙 (문서에 박아둔 것)

- **등급 없는 단정을 쓰지 않는다** — `[관측]/[계산]/[문서]/[확정]/[가설]/[미검증]`
- **`조회 0행`을 `정상 0건`으로 표시하지 않는다**
- **서버가 주지 않는 수치를 화면에 만들어내지 않는다**
- **상태는 색 + 모양으로 말하고 글자를 덧붙이지 않는다**(모양이 곧 라벨)
- **경보 목록 행 탭 = 확인 처리로 만들지 않는다** — 상세에서 명시적 1회
- **오프라인에서 대응 확인을 예약하지 않는다** — 누가 언제 확인했는지가 안전 기록이다
- **"로컬 저장됨" ≠ "전송 완료"**
- **결과 불명이면 재전송이 아니라 서버 상태 재조회가 먼저**
- **펜 작업 중 레이아웃이 변하면 안 된다** — 경보 스트립 슬롯을 항상 예약
- **앱은 IME 를 강제하지 않는다**
- **md 가 정본이고 docx 는 생성한다** — 사람이 둘을 따로 고치면 반드시 어긋난다
- **잉크는 `stylus` 만 그린다** — `touch` 로도 그리면 팜 리젝션 취소 전 몇 프레임이 손바닥 점으로 남는다
- **`onPointerCancel` 을 반드시 처리한다** — 팜 리젝션은 차단이 아니라 **사후 취소**다
- **인셋은 런타임에 읽는다** — `29.6` `368.0` 같은 관측값을 상수로 박지 않는다
- **`SafeArea` 를 믿지 않는다** — 좌우 제스처 띠는 `systemGestureInsets` 에만 있다
- **핵심 동작을 펜 버튼·모서리 제스처에 걸지 않는다** — OS 가 선점한다(실물 확인)
- **관리자가 적는 기록과 서버 판정을 섞지 않는다** — 색도 같이 쓰지 않는다(코덱스 지적)
- **계측 코드를 먼저 의심한다** — 숫자가 이상할 때 기기 탓하기 전에 내 측정 로직을 본다
- **세로로 붙은 타깃 간격은 조준 편향(약 13dp)보다 크게** — 오차는 랜덤이 아니라 아래로 쏠린다
- **측정 조건을 숫자와 같이 적는다** — "장갑"이 아니라 "면 95% 옷 1겹"이라고 써야 나중에 쓸 수 있다
- **STT 결과를 한 줄로 확정하지 않는다** — 후보를 보여주고 고르게 한다(1순위 1/5 → 후보 3/5)
- **확인하지 않은 값을 안전 기록으로 만들지 않는다** — STT 는 부정을 삼켜 판정을 뒤집는다
